# 板 vs 共面真实物体迁移实验（80 cm 档，2026-09-02）

## 结论

同一帧内，**三个模型对"板"和对"与板共面的真实物体表面"所需尺度的比值 = 1.00 ±1%**：

| 模型 | 盒面（共面） | 手机屏（斜靠、近似共面） | 支架底座（共面） |
| --- | --- | --- | --- |
| DA-V2 | 1.000（IQR 0.010） | 0.995（0.012） | 1.050（0.019） |
| UniDepth V2 | 0.993（0.008） | 0.999（0.004） | 1.006（0.011） |
| Depth Pro | 1.002（0.008） | 1.002（0.004） | 1.019（0.005） |

（比值 = 物体区所需尺度 / 板区所需尺度，14 帧中位数；1.0 = 完全可迁移）

→ **"板上拟合的距离校正模型可以直接用于同一画面里的真实物体"这一前提成立**：模型每帧的尺度误差是
**整帧全局的**（对板 0.66–1.08 逐帧大摆，但同帧内板↔盒面比值恒为 1.00），所以"场内已知尺寸线索定尺"
在原理上也成立。底座区域比值略偏（DA2 1.05），源于区域较小且在画面边缘，不作为可靠性依据。

## 采集设置

- 板 + 手机（带支架）都靠在同一显示器包装盒正面（唯一公共平面）；摄像头固定、Focus 293 锁定、gain 0 / WB 5000 锁定。
- 用户口径 80 cm；**板位姿解算平面距离 0.797–0.808 m（14 帧，中位 0.804 m）**——比手持板采集稳 5 倍。
- 共采集 31 帧：前 14 帧有效（板+物体同帧）；**后 17 帧板不在画面**（场景变更），已剔除。
- 每一帧的"真值平面"由板位姿给出，盒面/底座区域同平面（板厚 2–4 mm 与手持倾角 7–10° 是残差来源，但
  14 帧重投影 RMS 全部 < 0.8 px，平面距离离散 < 1.5 %）。

## 后续建议

1. 距离模型（若仍要全局拟合）应以"每帧全局尺度"视角构建：用板区定帧尺度 → 应用于全帧，误差 ±1–3 %；
   这比"距离→尺度曲线"稳健，因为逐帧尺度方差（±10 %）主要来自图像内容而非距离。
2. 手机作为倾斜目标的近似值也在表内（0.995–1.002），说明小角度倾斜（≈8–10°）对全局尺度结论无实质影响。
3. 后 17 帧"板消失"提醒：正式采集时板/物体要固定在场，避免中途变更场景。
