# 深度模型基准对比（Depth Anything V2 Metric vs UniDepth V2，2026-09-02）

## 结论

在我们 44 帧板位姿真值评测集上，**UniDepth V2（ViT-S14，137 MB）把原始米制误差从 DA-V2 的 +67 % 中值
压到 +12 % 中值**，且在 0.9 m 处接近零偏差（-4.5 %）。帧内自洽性两者相当（所需尺度 MAD 0.1–0.4 %）。

## 各距离原始相对误差（(预测-真值)/真值，板区中位数）

| 距离 | DA-V2 Metric Small | UniDepth V2 ViT-S | **Depth Pro（新增）** |
| --- | --- | --- | --- |
| 0.4 m（4 帧） | +68.8 % | +29.3 % | **+3.0 %** |
| 0.6 m（7 帧） | +45.5 % | +9.3 % | **-4.9 %** |
| 0.7 m（20 帧，含 A/B 两会话） | +69.4 % | +12.8 % | **-2.9 %** |
| 0.9 m（4 帧） | +55.3 % | -4.5 % | **-7.2 %** |
| 1.2 m（8 帧） | +78.4 % | +8.4 % | **+24.0 %** |
| 全部（中值） | +66.7 % | +11.9 % | **-2.8 %** |

Depth Pro 追加说明：官方权重 1.9 GB（HF apple/DepthPro，SHA256 3EB35CA6…），fp16 @1536 推理
**峰值显存 3.97 GB、稳态 0.76 s/帧**；输入使用我们标定后的 fx（f_px），输出即米制深度。
**0.4–0.9 m 区间误差 ±7 % 以内（多数 ±3 %），几乎无需距离校正**；1.2 m 一档 +24 %
（与 DA-V2 在同档同样变差，指向固定焦点下 1.2 m 微糊/目标过小，是采集条件问题而非模型问题）。

- 距离档内所需尺度离散：DA2 ±1.0–2.5 %；UniDepth ±0.6–4.6 %（0.7 m 档最大，因为 A/B 两个采集会话
  在这档有额外的 8–10 % 系统差：B 会话板放得更远（0.754–0.762 m vs 0.674–0.719 m），且两个模型都同样变差，
  指向**固定焦点下远一点/微糊**或采集状态差异，而非模型随机性）。
- 推理速度（RTX 5070 Laptop，4K→模型输入）：UniDepth 首帧 0.56 s，稳态中位 **0.03 s/帧**（含预处理外推理），
  实时可用；DA-V2 baseline 同机约 7–9 FPS 端到端。
- 许可：DA-V2 Apache-2.0（可商用）；**UniDepth V2 CC-BY-NC-4.0（仅科研，商用不行）**；
  Metric3D v2 权重 CC0、代码 BSD-2（可商用），但官方推理依赖 mmcv（Windows 编译成本高），
  onnx-community 的 ONNX 导出输出语义与公开预处理不一致（量化 log 尺度，无法线性还原为米），
  本轮未完成其评测——作为"可商用候选"留待后续用官方 torch 推理重跑。

## 评测方法（可复现）

- 数据集：43 帧（本轮 44 有效帧）全部已保存的标定采集（0.4/0.6/0.7/0.9/1.2 m 五档 + 锁 gain/WB 的 A/B 会话），
  真值 = ChArUco 板位姿给出的逐像素光轴深度（与深度模型无关）。
- 对每帧：同一板区 mask、同一真值，分别取 DA-V2（保存的深度数组）与 UniDepth（本地权重 + 我方 K′ 内参输入）
  的板区中位数比较。
- 不确定度：板位姿重投影 RMS < 0.8 px；本对比评价的是"同一输入下模型原始输出的偏差"，不是世界坐标系精度。

## 建议下一步（决策点）

1. 若接受科研用途：**把 UniDepth V2 ViT-S 接进实时管线**（替换 DA-V2 metric），用我们已有的单参考标定流程
   在目标工作区（如 0.6–0.9 m）做一次 2–3 距离标定，预期归一后 ±3 % 量级；0.4 m 一档偏差 (+29 %)
   需要在该档单独校正或换用更贴近近距的标定。
2. 若需要可商用模型：投入 1–2 小时跑通 Metric3D v2（torch，绕过 mmcv：手动实例化模型+官方 canonical 预处理），
   在同一集上复评；它是许可干净的候选。
3. 无论哪个模型，"板标定 vs 真实目标"的对照实验仍待做（板上结论 ≠ 真实物体结论）。
