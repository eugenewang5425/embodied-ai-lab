# 60 cm 单参考点距离标定结果（2026-09-02）

## 结论

在板面中心真值 0.610 m（投影中心基准，板位姿解算）处，Depth Anything V2 Metric Hypersim Small
预测 0.914 m：**原始米制输出高估约 46.7%**。单参考点拟合的乘性尺度为

```
scale = 0.6817   （z_true = scale * z_pred；同一帧板区 MAD 0.36%）
```

拟合后该帧板区相对残差 MAD 0.53%（RMS 4.3 mm），说明偏差在板平面上高度一致，是纯尺度偏移；
但这是"拟合并评估同一帧"，**不是独立验证**，`metric_accuracy_validated = false` 保持不变。

## 限制与下一步

1. 尺度是单点值，未验证：需要在其他距离（建议 40 cm、90 cm）各按同样流程保存一帧并记录实测距离，
   用 60 cm 点拟合、其余点做 holdout 报告相对误差。
2. 若 3 点显示尺度随距离变化（近距/远距非线性），再改用 `z_true = a*z_pred + b` 三点拟合并留档验证。
3. 板区内残差 0.5 % 说明"模型输出如何随角度变化"在该视场内一致；要区分"输出是 Z 还是欧氏距离"
   需要更大倾角或离轴目标的对照点，当前数据不足以判断。
4. 不含人员/移动目标、运动模糊等其他情况的标定；不用于机器人避障/碰撞决策。
