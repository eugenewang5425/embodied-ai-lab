# 第二十一课补充：停车门限越小，小车就越准吗？

这是对上一课问题的单变量对照，不是第二十二课，也不增加新的学习阶段。问题来自：为什么控制器把估计距离降到 2 cm 就停，而不是一直降到零？

## 1. 先看运动，再看结论

在项目目录运行：

```powershell
uv run python -m embodied_learning.threshold_demo
```

默认近目标、轮子＋地标定位、样本 #0、暂停、0.25×。同一张图中蓝色为 2 cm，橙色为 1 cm，紫色为 0.5 cm。

1. 点“播放”，看三个独立实验的小车一起接近。前期位置重合，是因为这时门限还没影响动作，不是少画了一辆车。
2. 点“接近目标时”，跳到 2 cm 组首次尝试停车前 1 s，暂停并放大。再点“播放”，观察蓝车开始停车后，其他车怎样继续运动。
3. 点“下一次重新调整”，查看某辆车刚停下、估计又离开门限、重新运动的时刻。右侧停车计时归零，重新调整次数增加。
4. 点“看最终结果”，比较实际车轴中心、结束时间，以及“实际通过／实际停偏／超时”。
5. 点“远目标超时例”，明确切换到远目标、融合定位中下一个 0.5 cm 超时的样本，并从接近目标处暂停；不是重新抽噪声或改变门限。所有样本仍可手动选择。

绿色圈是固定半径 **3 cm 的真实验收范围**；局部视图的三条彩色虚线圆才是 **2 / 1 / 0.5 cm 的估计停车范围**。实心点代表实际车轴，同色空圈代表估计位置。车头箭头和点标记是符号，不是局部放大后的车身大小。可以取消“估计空圈”，先只看实际运动。

三条曲线属于三个独立实验，不是同一物理环境中三辆车的相互作用。每辆车到达或超时后，本回合结束，画面只保持最后状态，不再接收观测或恢复控制。

## 2. 只改变什么？

| 项目 | 三组设置 |
| --- | --- |
| 唯一改变 | 估计停车门限 2 cm / 1 cm / 0.5 cm |
| 真实验收 | 仍为车轴中心半径 3 cm；没有跟着缩小 |
| 到达判定 | 估计在各自门限内，零轮速保持 0.4 s |
| 最长时间 | 40 s；超时发出终止零轮速，不能算完成到达 |
| 控制、动力学 | 同一比例控制与限速、同一二维理想运动学 |
| 定位与噪声 | 上一课同一标定、右轮噪声、地标观测间隔和噪声 |
| 目标与种子 | 近、远目标各 20 个种子，分别比较纯里程计和地标融合 |

总共 `3 × 2 × 20 × 2 = 240` 回合。比较停车门限时，应固定界面中的目标、定位方法和样本号。切换定位方法是在看另一组门限实验，不能把定位改善都归因于门限。

配对的是相同时刻的噪声抽样；门限开始影响动作后，真实轨迹及理想测量会改变，因此完整传感器读数不必相同。

没有修改默认的 2 cm 控制器。实验批处理入口只新增可选 `config` 参数，用同一仿真函数运行三个门限，不维护三套控制代码。没有加入卡尔曼滤波、积分控制、避障、刹车动力学或 ROS 节点。

## 3. 三种结果不能混为一谈

- **实际通过：** 完成自己的到达判断，且最后 0.4 s 的实际位置始终在 3 cm 圈内。
- **实际停偏：** 宣布到达，但实际位置没通过上述验收。
- **超时：** 40 s 内没完成自己的到达判断；即使此时实际在绿圈内，也不算任务完成。

“重新调整一次”的定义很窄：控制状态从“停车等待（零轮速）”变成“前进或转向”。它不是地标更新次数，不是所有转向次数，也不是控制器计算次数。终止命令不计为一次新调整。

停车计时统计已经完成的零轮速区间：进入停车状态的瞬间是 0.00 s，而不是先记一帧 0.04 s。

| 近 / 轮子＋地标 | 1 cm | 20 / 0 / 0 | 0.706 cm | 12.594 s |
| 近 / 轮子＋地标 | 0.5 cm | 20 / 0 / 0 | 0.496 cm | 17.208 s |
| 远 / 只靠轮子 | 2 cm | 5 / 15 / 0 | 7.095 cm | 23.004 s |
| 远 / 只靠轮子 | 1 cm | 5 / 15 / 0 | 6.767 cm | 24.080 s |
| 远 / 只靠轮子 | 0.5 cm | 5 / 15 / 0 | 6.651 cm | 24.964 s |

| 远 / 轮子＋地标 | 1 cm | 13 / 3 / 4 | 1.795 cm | 30.706 s |
| 远 / 轮子＋地标 | 0.5 cm | 7 / 0 / 13 | 1.774 cm | 36.236 s |

所有均值均包含本组全部 20 回合，包括超时回合的 40 s 和该时刻位置，不是仅成功回合的均值。“平均时长”不是估计超时以后还要多久才能完成。

三个不同发现：

1. 近目标融合组：缩小门限确实降低了平均实际距离，但平均时长从约 10.9 s 增到 17.2 s。
2. 远目标里程计组：门限缩小不能修好定位，实际通过始终只有 5/20。
3. 远目标融合组：0.5 cm 虽没有“宣布到达但实际停偏”，却有 13/20 超时，不能把零停偏包装成可靠到达。

重新调整次数也不一定单调增大：远目标融合三组平均为 0.85 / 2.30 / 1.50 次。更严格的组可能长时间都进不了停车范围，而不是不停进入再退出，因此只看这个次数会漏掉问题。

这只是这些模型与种子的有限样本比较，不能证明总体最优门限或硬件停车精度。本实验没有选择并替换默认参数。

## 5. 一个可直接看到的例子

“远目标超时例”从默认样本 #0 首次点击会进入 **远目标、融合定位、样本 #1**：

- 2 cm：23.60 s 宣布到达，认为还差 1.879 cm，实际差 3.856 cm，属于停偏。
- 1 cm：35.12 s 宣布到达，实际差 0.994 cm，通过。
- 0.5 cm：40 s 超时；实际差 1.923 cm，虽然在绿圈内，但估计还差 2.675 cm，没完成自身到达判断。

这说明“估计距离尽量小”和“实际位置尽量准、及时完成任务”是相关但不同的要求。不能单凭一个样本决定最佳门限。

## 理论对应（Embodied-AI-Guide）

在 [Embodied-AI-Guide](https://github.com/TianxingChen/Embodied-AI-Guide) 的地图里，本补充课属于（4）Algorithm 篇·Robot Navigation 与（6）Control 篇·控制理论基础共同关心的工程问题：**门限设计权衡**。导航与控制系统里到处是这类常数——到达半径、超时时间、重规划触发阈值——指南不会替你选数值，本课用 240 个回合展示选门限时应该看哪些数字：通过数、停偏数、超时数、平均实际距离、平均时长，缺一不可。

三个发现各有理论名字。近目标融合组门限 2→0.5 cm，平均实际距离 1.146→0.496 cm，平均时长 10.922→17.208 s：**精度用时间购买**，更严的门限触发更长的进圈与调整过程。远目标融合组 0.5 cm 门限：0 次停偏、13/20 超时——**零停偏不等于可靠到达**，把"没有 A 类失败"说成"没有失败"，是指标口径的经典陷阱。远目标里程计组三档门限都是 5/20、平均距离 7.095/6.767/6.651 cm 几乎不动：**门限修不了估计误差**，通过率由定位分布决定，而不是由停车决心决定。

远目标超时例 #1 把机制摆到明处：0.5 cm 组 40 s 超时，实际只差 1.923 cm（在 3 cm 绿圈内），估计却一直差 2.675 cm。当估计误差的分布宽度大于门限之间的差距，能否完成"自身的到达判断"就由分布而不是门限决定——此时该修的是估计（观测间隔、异常观测、停止策略），不是把门限改得更苛刻。重新调整次数 0.85/2.30/1.50 的非单调是同一机制：更严的组可能长时间进不了自己的门限，而不是反复进出。

"平均时长包含超时回合的 40 s"这类口径问题，对应（5）Infrastructure 篇·Benchmarks 的通用原则：先定义"谁被平均、失败怎么计"，再看数字。本课刻意没有替默认控制器选"最优门限"——240 个有限样本也选不出来；它提供的是下次改门限前必须回答的检查清单。

## 思考题

1. 近/融合组门限从 2 cm 收到 0.5 cm，平均时长 10.922→17.208 s 且三组都无超时；远/融合组 0.5 cm 平均时长 36.236 s 却含 13/20 超时。两组"变慢"的构成一样吗？
   提示：第 3 节三种结果的定义与第 4 节"平均时长包含超时回合"的口径说明。
2. 远/融合 0.5 cm 组 0 次停偏、13 次超时。为什么讲义坚持"不能把零停偏包装成可靠到达"？超时回合里实际位置已在 3 cm 绿圈内（如样本 #1 实际差 1.923 cm），判为失败合理吗？
   提示：第 3 节超时定义"即使此时实际在绿圈内，也不算任务完成"；想一想任务验收与估计状态是两个视角。
3. 远/里程计组三档门限通过率都是 5/20，平均最终距离 7.095/6.767/6.651 cm 几乎不动。为什么门限缩小修不好这组数据？决定它通过率的是哪个环节？
   提示：第 4 节发现 2，回看上一课纯里程计的估计误差来源。
4. 远目标超时例 #1：0.5 cm 组实际差 1.923 cm、估计差 2.675 cm。估计与实际之间约 0.75 cm 的间隙由什么造成？如果这个间隙不变，把门限改成 0.25 cm 会发生什么？
   提示：第 5 节与上一课的地标观测间隔、估计误差分布。
5. 重新调整次数 0.85/2.30/1.50 为什么不单调？如果只看"重新调整次数"这一个指标，会对哪一组门限产生误导？
   提示：第 4 节末段"更严格的组可能长时间都进不了停车范围"与"重新调整一次"的窄定义。

## 7. 到这里先停

本补充实验的学习验收：解释为什么门限更小，可能实际更准，却也可能更慢甚至超时；以及为什么纯里程计误差不能靠缩小门限消除。

如果下一步改方法，应先定位“估计抖动、观测间隔、终止策略”中哪一个在限制任务，再只改一个变量；不把本实验变成持续堆叠新框架。
