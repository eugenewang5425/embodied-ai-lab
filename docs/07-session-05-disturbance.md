# 第五课：被推一下之后——从稳定到抗扰动

这节不学新的控制算法。我们只把一个理想条件拿掉：机器人不再只面对安静的环境。

## 1. 先看，再解释

打开已经保存的第一个随机案例（seed=100，不是挑选表现最好的一次）：

```powershell
uv run python -m embodied_learning.teaching_demo --push-results results/lqr_push_2026-09-02 --seed 100
```

保持“叠加所有 R 曲线”开启，先选“真实倾角”，再看“控制输入 u”。默认暂停、0.25 倍速，展示原始 10 秒记录的前 8 秒。
黄色竖条标出外力持续的区间；顶部列出推力方向、大小和时间。右侧将电机的控制输入/执行器力与外部推力分开显示。
查看其他保存案例只改 `--seed`，本轮可用 100–119。相同 seed 下，三个 R 的推力完全相同；窗口只回放，不生成新随机数。

先观察三个时段：

1. 推之前：杆已经竖直、小车居中，电机几乎不用出力。
2. 推的时候：外力改变运动状态；控制器并不知道推力计划，只能根据新的状态响应。
3. 推停止后：外力已经归零，但位置、角度、速度还没恢复，电机仍可能继续动作。

核心问题：**为什么“外力归零”不等于“系统立即回到原位”？**
联系 GIS：当前位置与运动趋势是不同信息。力影响加速度，速度和位置又随时间积累；撤去扰动不会自动撤销已经发生的运动。

## 2. 只增加一种机制

初态是严格平衡点 `[0, θ*, 0, 0]`，不同时随机初态。控制器仍是原来的 `u=-K(s-s*)`，Q、模型、步长、输入限幅不变；每个 R 的 K 只在名义模型上计算一次，扰动期间不重新设计。

我们把外部推力直接加入 MuJoCo 的小车广义力，与电机输入分开；它以 N 为单位，不再乘 gear=100。每个控制步重新赋值，推力结束后明确写回零。
这一接口对应 MuJoCo 的用户外力项，参见[官方动力学说明](https://mujoco.readthedocs.io/en/stable/computation/index.html#general-framework)。它进入真实非线性仿真，而不是仅在画面上移动小车。

本轮协议预先固定为：

- 每个回合 10 秒，控制间隔 0.04 秒；
- 一次水平推力，持续 0.20 秒（5 个控制间隔）；
- 推力开始时间从 2–3 秒的控制网格均匀抽取；
- 左右方向随机，幅值在 30–80 N 均匀抽取；
- 使用种子 100–119，共 20 个外力方案，三个 R 共用同一套方案；
- 每个 R 另跑一次严格平衡点的无扰动对照，确认不是系统自己漂移。

这只是人为定义的测试分布，不是从真实机器人测出的环境统计。传感噪声、通信延迟、摩擦变化和模型误差尚未加入，所以只能说“增加了一种现实因素”，不能说已经实现真实机器人验证。

## 3. 实测结果

2026-09-02，在上述协议下：

| R | 完成 10 秒 | 推后恢复稳定 | 恢复时间中位数（从外力结束起算） |
| --- | ---: | ---: | ---: |
| 0.1 | 20/20 | 20/20 | 1.76 s |
| 1 | 20/20 | 20/20 | 2.20 s |
| 10 | 20/20 | 20/20 | 2.84 s |

“恢复”要求位置、倾角、线速度、角速度同时进入上一课的容差，并一直保持到记录结束，且连续保持不少于 2 秒：`[0.02 m, 0.01 rad, 0.02 m/s, 0.02 rad/s]`。
失败案例不会被伪装成提前完成，恢复时间记为 null；如果以后出现失败，中位数只对恢复者统计，必须同时阅读恢复数。

这次三个 R 都能应付测试范围内的推力，但恢复速度不同。20 次都成功不意味着任意大小、任意持续时间的外力都能扛住，也不意味着 R 越小越好。
还有一个重要的反例：seed=100 下，R=0.1、1、10 的实际输入绝对峰值分别约为 **0.803、0.826、0.894**，这次反而略有增大！R 较大的控制器允许更大的状态偏离，后续纠偏也可能产生较大的瞬时输入。R 惩罚的是优化目标中的输入平方，不是强制每一步或每个场景的峰值更小；不能照搬上一课偏移初态的排序。
下一步该问的是：“任务允许多大偏移、多长恢复时间、多少输入？”有具体要求后，才能判断选哪个 R。

## 4. 为什么现在用 LQR，不急着上复杂模型？

当前只有 4 个状态、1 个输入，执行时不过是几个乘法加法；LQR 主要帮助我们系统地选择全状态反馈增益，并表达状态误差与输入的取舍。它不是神经网络，也不需要训练数据或 GPU。
项目旧 PD 只看杆角度和角速度；这不代表所有 PD 或串级 PD 都无法回中心。我们研究的是反馈结构、权重与适用条件，而不是证明越复杂的名字就越好。

现在增加外力，是因为“安静时能站稳”已经不足以区分方案；并没有出现需要 RL、大模型或新仿真平台的证据。
完成这一课的观察与解释后，控制基础再单独检查传感噪声；随后进入双关节机械臂，把你已有的坐标和空间几何基础接进来。
若要研究多个姿态实现同一末端目标，再增加第三个关节；若要研究抓取，再逐项加入接触与摩擦。详见[学习路线中的复杂度约束](01-learning-roadmap.md)。

## 5. 复现与验收

完整复现（目录必须尚不存在）：

```powershell
uv run python -m embodied_learning.experiments.lqr_disturbance --output results/lqr_push_my_run
uv run python -m embodied_learning.teaching_demo --push-results results/lqr_push_my_run --seed 100
```

本轮证据位于 `results/lqr_push_2026-09-02/`：

- `summary.json`：固定条件、A/B/Q/K、版本与模型哈希、每个种子的外力与恢复指标；
- `trajectories.npz`：每步真实状态、电机输入、实际施加外力、完整计划外力与结束标志；失败截断时不会把尚未施加的外力计成已执行；
- `comparison.png`：预先指定 seed=100 的真实倾角与控制输入曲线。

测试覆盖外力 N 与电机 gear 的区别、推后清零、无扰动回归、种子复现、配对公平性、恢复时间起点/保持时长/失败判定，以及回放只读与曲线单位。
