# 导航补强登记：第69课第七、八轮

2026-10-01，基线`ecb9fe3`。补齐先前承诺的两轮导航工作；72—73课机械臂首批独立保留。本文件在开发与正式运行前登记，正式批次不调参。

## 共同平台与评分

沿用第六轮55×44cm、最高58cm的真实部件，8kg平面MuJoCo接触、物理500Hz/控制10Hz、限力伺服、排队预测和执行端保护。零额外余量，允许轻擦；轻擦仍须单点力≤40N、压入≤5mm、连续接触≤0.5s，不能靠提高阈值算成功。实际距终点<25cm、世界平移和角速度均<0.01才通过；误报单列。

位姿精确为受控条件。控制只读先验、估计位姿和当前/过去雷达与米制深度；真实盒体仅用于生成传感器、物理与评分。RGB仅重渲染，没有新增视觉定位。超时统一90秒，允许实际减速尾段，不瞬间清零速度。原六轮代码、数组和阈值不覆盖。

## 第八轮：通过观测更新错误的局部地图

两组共享10cm三维占据单元、同一固定0.2m/s上限、同一0.2s排队和0.5s静止观测准备：①只加障碍，旧障碍永远保留；②证据更新，新增端点与清除明确看空的旧单元。两组均在当前通行图重新规划，所有组的近障保护始终启用。

证据组只清除被相机当前视野覆盖、3×3邻域深度射线均穿过其中心且保留12cm距离预算的单元；须连续三帧，遮挡/无效/命中使计数归零。解析传感器的`valid=False且depth恰为8m`专指已测量但量程内无命中的射线，显式启用它作为有限范围空闲证据；NaN、其他无效值和外部相机默认不清除。雷达命中保守写作整个车身高度内的柱，单层雷达无回波不能删除其他高度障碍。深度地面不写作障碍，远超车身高度的障碍不参与本轮通行。没有按时间过期删除，没有读取真实障碍来更新地图。

开发试跑记录：第八轮初版将解析量程外未命中与数据无效一并拒绝，移走墙虽清除了1197个体素，仍无路。正式前将量程内空闲语义显式化并加已知答案测试；不把这一改变归因于实际相机失效被解决。第七轮正常速度开发桥接逐数组复现第六轮（计算墙钟除外），低速开发也到达。

这是有限分辨率的观测地图修正，不是整图SLAM形变修正或定位纠正。先验三维盒体属于输入，可能错误；实际盒体不传给控制器。

开发种子0；正式种子20/21/22×两地图组×以下六条件，共36回合：

1. 新增箱体：先验未标，实际存在。
2. 移走挡路箱体墙：先验跨通道占据，实际已移走。
3. 箱体向侧面错位90cm：旧位置需要清除，新位置需要加入。
4. 正确箱体：检验是否错误清除仍存在的障碍。
5. 移走低路障墙：雷达平面穿过，仍须深度证据，不能把无回波等同全车无障碍。
6. 被前方箱体遮挡的旧箱体：保留遮挡后的占据，检验不可观测区域不能随意清除。

每帧保存通行地图、增删单元数量与证据、实际执行和传感器；地图误差仅在评分端对照真实占据。初始图与当前图分别展示，禁止在早期帧展示最终图。失败后不无限等待/重试，无路在共同准备期之后终止。
