# 第69课第十一轮登记：发现新障碍后，能否绕行到达？

2026-10-01，基线9abe189。修正实验方向：第十轮横贯通道且已在先验中的低墙/横杆，只作为不能通过的负例保留。不能用它们的拒绝结果证明选路有效。

## 问题与对照

12×12m街区，起点(1.5,6)，终点(10.5,6)。新障碍均不在先验地图中，足印为x=5.6–6.4m、y=5.4–6.6m，两侧留有通道。四条件：14cm低路障；42–56cm悬空杆（车身上部会碰）；1m普通箱体（雷达可见的阳性参照）；75–89cm高杆（高于58cm整车，应可从下方直行）。前两项要求发现后绕行，后两项区分普通探测与不必要绕行。

两组仅改变控制器可用的传感器：仅32cm高平面雷达；同雷达＋320×240米制深度。两组都存档RGB-D/雷达以便复盘，但雷达组在进入证据地图前将深度替为NaN/无效，后续规划、排队保护、执行保护均只能使用这张地图产生的点。不允许以可视化中的深度偷偷保护雷达组。RGB为按真实位姿重渲染，没有参与控制或定位。

## 固定条件

开发首版8回合保留在`results/navigation_bypass_development_v11`。融合组低路障、悬空杆、普通箱体均在绕行途中遭`footprint_start_blocked`，实际未接触。逐帧重建低路障失败状态发现：只用连续观测点检查身体可行，只用栅格的完整方块检查却拒绝。冻结正式前，两组共同采用同一表示修正：原先验尚未清除的格子保留完整范围，新观测只以其连续米制坐标约束身体，不再把10cm存储格子重复当作整块实体。新点仍供搜索、规划与全部保护使用，未降低车身/安全阈值。此修正与两组传感器差异分别说明；本轮配对只隔离深度作用，不声称单独量化表示修正收益。

修正后开发8回合保留在`results/navigation_bypass_development_v11_metric`：深度组低路障/悬空杆均绕行到达，高杆两组均直行到达；普通箱体雷达组到达，深度组85.94N接触中止。该表示仍是待验证候选，不据开发成绩宣布安全完成。正式保留普通箱体条件和失败，不继续选择性调参；整批结论必须同时报告收益与接触退步。

沿用第九/十轮路线进度、规划、三帧空闲确认、12cm深度预算、10cm格子、限力伺服、500Hz实际接触、10Hz控制、0.2m/s上限、0.2s请求排队、0.5s静止准备、90s超时。55×44cm身体、最高58cm，零额外余量；允许轻擦仍须≤40N、≤5mm、连续≤0.5s。真实距目标<25cm并实际平移/角速度均<0.01才通过。精确位姿是受控条件，不是定位成绩。仅控制计算计时，仿真计算时仍不后台积分，不能称实时10Hz。

## 可达性与留出

正式前对固定绕行折线(1.5,6)→(2.5,7)→(6.9,7)→(6.9,6)→(10.5,6)，按1cm平移、每拐点181个朝向采样独立检查真实身体各部件与真实盒体；直行链也独立检查。要求前三项直行会碰而绕行采样间隙为正，高杆直行间隙为正。这是离线几何检查，不能替代连续几何证明或动力学到达，绝不传入控制器。

开发只用种子0：四条件×两组8回合；正式前若需修改则记下原因。正式种子29/30/31，四条件×两组，共24回合。只验证同一布局的噪声重复，不能称未见街区泛化。正式后不调参，保留成功和失败。

## 验收与停止

报告逐条件真实到达、接触力/持续时间、距离/耗时、首次发现/路线偏移；雷达看不见时允许真实物理碰撞并按原阈值中止，不删掉失败。独立逐2ms重放力与接触、逐帧重建方法对应地图、核对冻结源码/协议/数组哈希；验证雷达组无深度输入。固定选例为种子29的低路障/悬空杆/普通箱体/高杆。复用一键同步窗口展示真实运动、相机、三维、雷达点、当前目标/地图/统计，注明深度是否参与控制。补充变量、原理、结果含义、思考题、局限与复现，然后停止。
