# 第三十三课：Go-Explore 画地图过崖——山顶被找到并入档，路还是没修通

本课执行 docs/34 D-2026-09-06-02"四种过崖方式"计划的最后一试。第 32 课的示教空投
把"到达直立区"变成评估常态（33/60 回合首达）却依然 0/60 稳不住——策略"到过"山顶，
但"到过"不可复算：同一个状态下一次再也进不去。本课换用 Go-Explore（Ecoffet et al.,
2021）的方案：把到过的好状态**存档**，并动用一个物理机器人没有的特权——在仿真里
**set_state 直接重置返回**档案态，在山顶上继续探索。两阶段：

```text
阶段一（档案探索）：选格 → set_state 返回该格成员状态 → 种子化随机探索 N 步 → 重新分格入档
阶段二（鲁棒化）：把"下方初态 → 稳定尾段"的档案轨迹跨格串成教师数据 → BC → 不做状态重置的闭环评估
```

结果一半是本系列四课里最亮眼的正向结论：**稳定尾段区域被找到、被捕获、被存档**
——第 29–32 课从未有任何策略在山顶住满 2 s，本课档案探索用 27 万步做到了 417 次；
另一半是如实入库的负结果：**BC 鲁棒化的策略 0/20**，历史性 0→1 仍未出现——地图
找到了山顶，开环克隆修不出上山的路。见 §2、§3。

## 1. 原理与协议

- **两个失败模式（Go-Explore 的诊断）**：detachment——好的状态到过就被遗忘，因为
  智能体回不去；derailment——试图"原路返回"的尝试本身会把好状态撞坏。仿真里的
  对策是绕过而不是修复：粗粒度格子存档 + 状态直接重置返回。这正是第 32 课示教的
  反面：空投把"怎么走"塞进损失函数，Go-Explore 把"到过哪"存进档案。
- **返回是仿真特权，如实入册**：返回用的是 gymnasium MuJoCo 的 `set_state(qpos,
  qvel)`（第 29–32 课管线内部一直用它做初始化，但从未用它当探索工具）。真实系统
  没有这个特权——原文的 robustification 正是为补这个而设计的，本课的负结果恰好
  落在这个环节上（§3）。
- **格子与成员（参数入 protocol）**：格子 =（杆角 bin × 车位 bin）= 12 × 6 = 72 格；
  杆角用相对参考的包裹角（α ∈ [−π, π)，多圈原始角不影响格身份），车位用
  [−2.4, 2.4] m。每格存一个**最优成员**（完整 4 维状态 + 它的来路），准则按字典序：
  ① 成员末态离稳定判据更近——`max(|x|/0.02, |wrap(α)|/0.01, |v|/0.02, |ω|/0.02)`
  （第 7 课稳定容差的归一化误差，≤1 即身处稳定带内）；② 从精确下方初态起的拼接
  步数更短（返回代价）；③ 更早创建（完全确定）。
- **选格规则**：优先从未被选过的格，否则在最少被选的格里经种子流均匀抽一个
  （偏好新格/稀疏格的确定性版本）。
- **探索动作（本课唯一新增手工旋钮，如实声明）**：均匀随机 ±3（全权限）叠加
  **第 7 课平衡 LQR 保持层**——|α|<0.3 rad 且 |ω|<2 rad/s 切入、|α|>0.5 rad 释放
  （第 7 课抓取/释放滞回，逐字复用）；**没有能量整形、没有摆起策略**。纯随机不叠
  策略的情形本记录不覆盖（§5）。每段 ≤150 步（6 s），共 6000 段；预算上限 8 分钟
  墙钟只是封顶，实际步数预算固定在先（确定性），实测墙钟 8.5 s。
- **稳定带捕获判据**：某段从档案态出发、末态连续 ≥2 s 落在四项容差内直到段尾，
  且用第 7 课 `recovery_metrics` 对截断轨迹复核通过——即"山顶上的稳定区"被找到。
  捕获格标记为稳定带格。
- **阶段二**：把最早捕获的 8 条轨迹沿父链跨格拼接成完整教师轨迹（下方初态 → 随机
  泵能 → LQR 抓取 → 稳定尾段）。拼接在物理上严格成立：每个 (s, a) 都是真实执行过
  的转移，父链按成员对象冻结（格子后来被替换也不影响已拼好的链），守卫第二项用
  全新环境逐位重放验证。BC 复用第 32 课目标（策略均值头 MSE + 手写 Adam）与
  第 28 课训练形状：8 条 4,912 对，300 轮、批 256、lr 1e-3。评估：**不做状态重置**
  的精确下方初态闭环，20 个随机回合（第 29 课动作流）+ 1 个均值动作回合，第 7 课
  `recovery_metrics` 逐字复用。
- **种子流**：选格 [master, 8100]、探索动作 [master, 8200]、BC 初始化 [master,
  8300]、BC 打乱 [master, 8400]；评估与基线沿用第 29 课流（[master, 2000, s]）。
- 预算：阶段一 6000 段 × ≤150 步（上限 90 万步，实测 270,416 步、墙钟 8.5 s）；
  阶段二墙钟 2.5 s；合计 11.5 s（8 分钟上限的 2.4%）。

## 2. 实验检查

### 2.1 返回保真守卫：双逐位（本课的管线正确性证明）

set_state 往返（含 3 圈原始角的多圈状态）逐位一致；从全新环境逐位重放一条拼接
路径切片的 8 步动作，状态**逐位一致**（`bitwise_identical_set_state /
bitwise_identical_stitched_replay` 全 true）。因此阶段二的教师数据是真实物理轨迹，
阶段一的一切差异都来自探索机制本身而非实现缺陷。

### 2.2 阶段一：覆盖 72/72，稳定带在 7.9 万步被捕获，此后随时可重返

| 指标 | 值 |
| --- | --- |
| 档案覆盖率 | **72/72 格（100%）** |
| 首次入档"直立带"（\|α\| ≤ 0.3 rad 的格） | **8,992 步**（第 29–32 课：评估从未/一次/常态但从未稳住） |
| 首次捕获稳定带（≥2 s 尾段入档） | **79,183 步**（第 2195 段，格 (6,3)，尾段 3.56 s） |
| 捕获总次数 | **417 次**（保留最早 8 条作教师） |
| LQR 保持层步数占比 | 27.3% |
| 段失败计数 | 出界 5,410 段、超速 0、超时 0 |

覆盖曲线的形状是本课的机制证据：前 500 段就铺满下方格（53/72），然后平台期——
随机泵能靠档案把"最高到过的杆角"一格一格往上顶（61/72 时停在 7.2 万步附近），
一旦直立带中央出现小 ω 成员，LQR 立即抓取，捕获在 2,500 段内爆发到 184 次。热图
按成员离稳定带距离着色后，山顶稳定区是一块清晰的亮斑（成员误差低至机器精度）——
**"山顶有稳定区"这件事从来不是问题，问题是怎么带着对的能量与姿态到那里**。
另一个观察：选格规则会把访问次数抹平（末端每格被选约 83 次），所以热图改按成员
误差着色，访问均衡本身入册。

### 2.3 阶段二：BC 背熟了教师（末/初 4.8%），闭环 0/20

8 条教师轨迹（460–889 步/条，共 4,912 对）训练的 BC 策略：教师 MSE
**1.861 → 0.089**（末/初 0.048，2.5 s 训练墙钟）——示教被牢牢记住。但闭环评估：

| 检查 | 结果 |
| --- | --- |
| 随机策略 20 回合（第 7 课口径） | **0/20** |
| 失败形态 | **出界 20/20**（超速 0、超时未稳 0） |
| 直立首达（过程指标） | **11/20（55%），中位 9.0 s** |
| 均值动作回合 | 首达 10.0 s，随后出界终止 |
| 精选失败案例 | 评估种子 0：max\|x\| = 2.4197 m 触界，峰值力 300 N |

### 2.4 四方对照（第 7 课口径，下方初态闭环）

| 方式 | 课 | 回合 | 成功 | 直立首达 | 一句话 |

## 3. 机制定位：地图为什么能找到山顶，路为什么还是不通

1. **档案把"到过"变成"可复算"，探索问题就此终结**。第 29 课的探针证明从下方静止
   出发纯噪声 20 回合 × 20 s 无一高过水平；本课同一随机动作流，靠"存档 + 重置"在
   9 千步内把直立带放上档案、7.9 万步内捕获稳定带。detachment/derailment 在仿真里
   被精确消除——Go-Explore 的机制主张按原文兑现。
2. **0→1 卡在鲁棒化，而且卡得非常有信息量**：BC 学生 11/20 首达直立区（55%，与
   空投持平）——它确实从随机泵能段学到了"把能量泵上去"的平均方向；但 20/20 出界
   ——随机教师的动作在闭环里没有纠错来源，第 28 课的复合误差在 RL 语境下第三次
   重演（第 30 课残差 bang-bang、第 32 课 BC 残差、本课随机教师均值）。开环回归
   给不了"在山顶待得住"的闭环不变量，这条结论现在有了四面证据。
3. **教师本身是随机的**：泵能段动作是均匀噪声，它在任何状态上的均值≈0——BC 能
   学到的只是"这些状态下平均别乱动"加上 LQR 保持段（那部分它学得很好，均值动作
   回合能首达就是保持段在起作用）。真正的路（哪一步该往哪打）只存在于"这段噪声
   的具体实现"里，克隆均值天然拿不到。原文的对策是从初始态学一个**能到达每个
   档案格的策略**（reset-free 的 go 策略 + 在山顶上的 explore 策略交替），本课的
   BC 只覆盖了"go"的开环影子——如实登记为未做项。
4. 四课合并的问题收缩至此：第 29 课缺梯度 → 第 31 课给了梯度但缺姿态 → 第 32 课
   给了姿态先验但缺闭环精度 → 本课补齐了"到过且可复算"，剩下的缺口被精确钉在
   **"闭环纠错"**（DAgger 式在线纠正 / 以档案为起点的策略梯度微调）。

## 5. 本课不能说明什么

- **探索动作叠了 LQR 保持层**（本课唯一新增手工旋钮，0.3/2.0/0.5 阈值取自第 7 课）：
  纯随机不叠策略的情形未覆盖；没有这层，捕获大概率不会发生（但"找到直立带"仍由
  档案机制完成，与这层无关）。
- **鲁棒化只做了最弱的 BC**：没有做原文的 go/explore 交替、没有 DAgger/策略梯度
  微调、没有对随机教师的任何去噪处理；0/20 不构成对"档案 + 鲁棒化"完整范式的
  否定，只否定"开环克隆随机教师"这一条路。
- **格子/成员准则/选格规则是单点手工选择**（12×6、误差优先、新格优先），未做网格
  敏感性；更细的格子可能让 frontier 更平缓，也可能让返回噪声占比更高。
- 20 回合有限样本计数；单任务、单名义 MuJoCo 模型、无噪声/延迟/质量误差。
- 第 29/32 课对照数字引自其正式记录，未在本课重跑；捕获判据的 2 s 尾段必须延伸到
  段尾（≤6 s），更长的保持验证由第 7 课口径的闭环评估承担。

## 8. 自审：效果与目的是否达成

- 目的 1（档案探索找到并捕获稳定尾段区域）：**达成**——覆盖 72/72、首达直立带
  8,992 步、稳定带 79,183 步首次捕获、417 次；返回保真守卫证明"重返"逐位成立。
  这是四课里第一次有"策略系统"在山顶满足第 7 课稳定判据。
- 目的 2（BC 鲁棒化实现 0→1）：**未达成**——0/20、出界 20/20；但首达 11/20 与空投
  持平，说明泵能行为部分转移；负结果如实入库，机制归因（随机教师均值不含路线
  信息、开环无纠错）有三课的交叉证据。
- 目的 3（四种过崖方式收官）：**达成**——四方式画满（✗/◐/◐/◐），缺口收缩到闭环
  纠错，"稳定带可入档可重返"成为下一课任何方法的现成起点（档案本身是本课的
  持久资产）。
- 局限如实声明（§5）；随机探索 + LQR 保持层的叠加写入 protocol，未隐藏。
