# 第十九课：观测怎样解出位置，又怎样与里程计融合？

本课只增加一个估计规则：**观测到来时重置位姿，间隙中用编码器继续推算**。沿用第十八课的小车、三条路线、三个已知地标、20 个种子和相同读数，不新增传感器、自由度、ROS 节点、控制器或卡尔曼滤波。

## 1. 先划清边界：我们的观测不是摄像头识别

这里实现的是一个理想化的“测距 + 测角传感器”，不是摄像头、图像识别或真实 LiDAR 扫描。仿真器知道真实场景，才能生成测量；**定位器不知道小车真值**。

```text
仿真场景的真实小车位姿 + 地标坐标
    → 计算传感器到地标的几何距离、相对角度
    → 加入测距/测角噪声
    → 三组 (地标编号, 距离, 方位角) 读数
    → 定位器：结合事先已知的地标地图，解算小车位姿
```

三个地标世界坐标（单位米）为 P1=(0, 1.6)、P2=(2.6, 1.0)、P3=(1.6, -0.9)。我们假设传感器已经知道读数对应 P1、P2 还是 P3，没有实现识别和匹配。

测量每 2 s 到来一次，每次观测三个点。传感器装在车体前方 0.12 m、左侧 0.04 m，相对车体朝向偏转 +30°。目前无视野范围、遮挡、最远测距、掉帧与延迟限制。

噪声是各次、各地标独立的零均值高斯量：测距标准差 σr=0.01 m，测角标准差 σβ=0.01 rad≈0.573°。**标准差不是最大误差，不能写成“最多 ±1 cm”。**

### 仿真器怎样生成读数

先由真实车体位姿和安装位姿得到传感器世界位姿 (t_s, θ_s)。世界点 P_i 在传感器系中的坐标为：

`q_i = R(θ_s)^T (P_i - t_s)`

然后生成 `r_i = ‖q_i‖ + ε_r`，`β_i = atan2(q_iy, q_ix) + ε_β`。这里的 β 相对**当前传感器朝向**，不是地图北向；车体转动和安装的 +30° 都在 θ_s 里。

## 2. 解算逻辑：把两组同名点对齐

可以用 GIS 控制点配准理解，但这里**只求旋转和平移，不求缩放**。

1. 把每个读数变成传感器局部直角坐标：`z_i=(r_i cos β_i, r_i sin β_i)`。
2. 现在知道“局部点 z_i 对应地图点 P_i”。寻找一组 R、t，让三个局部点同时尽量贴合地图点：最小化 `Σ ‖R z_i + t - P_i‖²`。
3. 求出的 t 是传感器的位置，R 对应传感器的朝向。
4. 反算车体：`θ_b=θ_s−30°`，`t_b=t_s−R(θ_b)[0.12, 0.04]^T`。

为什么不直接减去世界 X 的 0.12、Y 的 0.04？因为安装偏移定义在车体坐标系里，小车转向时偏移向量也会转动。

### 可选公式：实际代码如何求 R、t

分别求两组点的重心 z̄、P̄，再中心化得到 z̃_i、P̃_i。用：

```text
a = Σ (z̃_ix P̃_ix + z̃_iy P̃_iy)
b = Σ (z̃_ix P̃_iy − z̃_iy P̃_ix)
θ_s = atan2(b, a)
t_s = P̄ − R(θ_s) z̄
```

这就是当前代码使用的二维刚体最小二乘配准。已知对应关系下，两个不同位置的点可约束二维刚体变换；本课固定使用三个分散的地标提供冗余。

三点共同拟合可以分摊读数噪声，但不保证无偏、最优或精确。测角误差变成位置误差时与距离有关；等权点集拟合没有显式处理这种方向、距离相关的不确定性。表中的“配准残差”是点与点是否吻合，**不是小车定位误差，更不能证明控制点坐标正确**。

## 3. 系统误差和随机噪声分别怎样处理

| 误差来源 | 本课如何处理 | 仍然不能做什么 |
| --- | --- | --- |
| 右轮读数固定多报 2% | 重用第十六课独立测量段拟合的 c≈0.980392 | 不能把所有系统误差都当成一个比例 |
| 编码器每步随机噪声 | 标定后仍存在；定期引入地标位姿限制长时间的累计漂移 | 重置位置不等于知道每一步噪声，更没有在线重标定编码器 |
| 地标测距、测角噪声 | 三点配准；本课直接用解出的带噪声位姿重置 | 没做时间滤波、异常值剔除或可靠度加权；一次坏观测可以使估计变差 |
| 地图坐标、传感器安装、测距比例若有系统偏差 | 本课假设这些参数准确，没有模拟或校正它们 | 多次平均、重置位置都不能自动消除错误参考基准 |

编码器公式尤其直观：`raw = 1.02 × true_increment + ε`，标定后 `c × raw ≈ true_increment + cε`。固定多报的部分被校正了，随机项还在。

统计时也要区分：

- 有符号误差向量的均值 `mean(Δx, Δy)` 用于观察系统性偏移；有限 20 次样本接近零不证明严格无偏。
- 每次误差距离 `sqrt(Δx²+Δy²)` 永远非负，其均值描述平均偏离多远，不能通过正负抵消。
- 例如第十七课标定组的直行终点平均误差距离仍是 2.52 cm，不能因为有符号均值较小就说“每次只有毫米级误差”。

重复、独立、零均值的测量可以通过合适的平均降低随机散布，但机器人在运动，不能把不同时刻的位置直接平均冒充当前的位置。运动预测和测量可靠度需要一起考虑，才是后续滤波的问题。

## 4. 本课的融合规则：先预测，再校正

每 0.04 s 读取两个编码器的**测得增量**，结合轮半径与轮距推算车体位移和转角。与第十五课使用同一积分公式，但从最近的融合位姿继续推算。

```text
t=1.96 s：上一融合位姿
    ↓ 加上本次编码器测得的运动（1.96 → 2.00 s）
t=2.00 s：预测位姿（校正前）
    ↓ 此时收到地标读数；解算车体位置与朝向
t=2.00 s：融合位姿 = 地标解算位姿（校正后）
    ↓ 从这个新起点，继续积分下一小段轮子读数
t=2.04 s：新的融合位姿
```

不仅重置 x、y，也校正朝向，否则之后仍会沿错误方向累计位移。角度校正走最短角差，例如 +179° 到 −179° 是 +2°，不是 −358°。编码器累计计数不清零，只使用相邻差值，避免重复计算此前走过的路。

这是最简单的“到观测时完全相信观测”的基线，不是卡尔曼滤波，也不保证每次校正都改善。它改变的是**位置估计**，不会让真实小车瞬移，也没有给电机施加纠偏动作。

## 5. 三组同条件结果与反例

正式记录：`results/mobile_fusion_2026-09-03/`。每条路线 20 次、基础种子 0，与第十八课逐数组一致的真值、里程计和观测保持结果；融合共用同一份编码器和地标读数。

以下统一比较“全程平均位置误差距离”：每次先对 frame 1..steps 求平均，再对 20 次取平均；不混用终点值、观测时刻值和全程值。

| 路线 | 纯里程计 | 纯观测保持 | 重置＋里程计 | 使瞬时位置误差变大的更新数 |
| --- | ---: | ---: | ---: | ---: |
| 直行 12 s | 0.978 cm | 19.642 cm | 0.803 cm | 70 / 120 |
| 方形 24 s | 1.089 cm | 13.478 cm | 0.901 cm | 121 / 240 |
| 长直行 32 s | 3.822 cm | 19.933 cm | 1.938 cm | 168 / 320 |

如何解读：

- 纯观测保持的全程误差大，是因为两次观测之间估计没动、车却继续走；不是传感器每次都测错 20 cm。
- 融合填上了这个时间空隙；定期绝对定位又截断了里程计长期累积的历史影响。
- 观测噪声仍会传入融合，某次重置反而可能更差，尤其短时预测本来已经较准确时。
- 所有路线终点恰好是观测时刻，融合位置必然等于该次观测位置。因此终点融合/观测的平均误差同为 0.83、1.12、6.57 cm；**不能靠终点证明融合优于纯观测**，必须看观测间隙。
- 本组结果不证明重置策略普遍优于里程计，或满足某个实车定位精度。长直行离地标更远，观测误差也会增大。

## 6. 打开慢放，按因果顺序看

在项目目录的 PowerShell 中：

```powershell
uv run python -m embodied_learning.fusion_demo --results results/mobile_fusion_2026-09-03
```

默认暂停、0.25×、直行、样本 #0。先停在第一个页面，点“下一次观测”：

1. **观测怎样解出位置**：看三组真实记录的测距、测角、局部坐标和配准残差；下面分别显示传感器位姿和扣除安装偏移后的车体位姿。两次观测之间表格注明是上次读数。
2. **三种方法同图慢放**：紫色里程计、灰色观测保持、橙色融合；它们是同一台车的三种估计，不是三辆车。蓝色只用于表示仿真真值。
3. 在观测时刻，看下方“校正前 → 校正后”的真实误差评价与位姿修正量；单步到下一帧看编码器接续。
4. 取消“显示纯观测保持”，可重新缩放纵轴看清紫橙差异，不改变数据。位置误差非负，朝向误差保留正负。
5. 点“看一次校正变差”：按当前样本跳到一个真实反例；按钮使用真值找教学案例，**定位算法不使用真值选取或拒绝更新**。

曲线为完整录制结果，游标标当前帧；地图只画已播放的轨迹与观测点。算法不使用未来观测，没有轨迹平滑回看。

## 停止点

现在先能解释三件事：读数怎样变成位姿；标定与位姿重置有什么不同；为什么融合不能保证每次更准。不要为了让本组曲线更漂亮立刻叠加复杂滤波。

此后可进入已安装的 ROS 2，学习如何把“编码器、观测、定位”组织成消息与节点，并明确坐标系。若具体任务要求使重置跳变或异常观测成为问题，再比较加权、异常值处理与状态滤波。此课不自动推进到这些阶段。
