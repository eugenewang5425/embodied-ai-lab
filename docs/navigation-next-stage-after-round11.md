# 第十一轮后：先解释接触，再扩大验证

2026-10-01。第十一轮把先验已知的封路负例换成先验未知、两侧可绕的新障碍；正式结果见[第六十九课第十一轮讲义](69-reachable-obstacles-round11.md)。未完成的事项仍保留，不把新点地图候选当作已验收的安全方案。

## 1. 优先分离普通箱体接触与悬空杆误拒

冻结每次失败前后各1s的深度、雷达、连续点、存储格子、实际/估计身体、规划折线与跟踪请求。沿存档重建，逐项回答：最先约束身体的点在哪；规划允许的线段是否实际撞物；跟踪是否偏离线段；3mm深度/5mm雷达噪声、10cm合并和未见侧面分别造成多大缺口。真值只诊断与评分，不能喂给运行中的控制器。

开发首版完整格子拒绝、连续点候选接触，说明“更不保守”不是安全改进的充分条件。下一批先选一种有测量依据的观测范围/误差表示，再登记单变量对照；暂不同时改速度、转向和地图删除。保留低路障、悬空杆、普通箱体、高杆四类，防止只修箱体却重新漏掉高度障碍。

正式前冻结开发种子0、候选源码与阈值；新噪声种子从32/33/34开始另登记，并加入至少两个未用于开发的足印/位置布局。停止条件同时包含到达、重接触、误拒与耗时。若接触未改善，就保留负结果，不让候选进入能力组合。

## 2. 再接位姿误差与遮挡

只有安全候选通过，才单独改变±2cm横向误差、±1°朝向误差，再接遮挡/坏深度。观察投影偏到哪里、真实障碍是否误删、车身是否碰撞。位姿误差不能用窗口重渲染的真实相机位置遮掩；RGB是否参与定位单独说明。

原第九/十轮遮挡起点拒绝仍未由本轮验证解决。本轮新障碍绕行不能替代遮挡和错误旧地图的成绩。

## 3. 实际计算延迟，然后组合69—71

感知、地图、搜索、执行保护、存档分别计时。先做独立物理时钟与请求采样时间/完成时间/有效期：计算未完成时车仍继续物理运动，本地保护读新观测并能减速，过期结果不能重新驱动车。不能把显式0.2s排队等同于真实端到端延迟。

上述门槛通过后，才将70的到点判据、71的有限恢复迁移到最新55×44cm真实接触平台，分别比较原规则、联合判据、联合＋有限恢复。之后接视觉位姿与连续RGB-D；机械臂视觉抓取仍独立推进，不能替代导航验收。
