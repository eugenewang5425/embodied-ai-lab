# 第69课第二轮预登记：固定足印与规划，只改变路径跟踪

日期：2026-09-30；起始提交：5330118。承接第一轮窄路0/9的真实失败。

## 问题与控制变量

原跟踪器只追35cm前视范围外的路径点，可能切过曲线内侧。第二轮比较原矩形足印组与利用路径切线、曲率和横向误差的跟踪组。身体55×44cm、各边6cm外扩、米制观测、规划搜索和路线保留规则、0.6m/s速度上限、加减速、10Hz采样、近场刹停保护、25cm真值到点及停车要求全部保持。

唯一处理因素为跟踪器。暂不合并70/71的到点与恢复，不引入真值控制，不更换定位器，不缩小安全余量。精确轮里程计仍是受控条件。

## 开发、冻结与正式批次

1. 开发只使用窄路/普通箱体/种子0；保留每次预试的源码与轨迹，记录失败后修改的原因。
2. 冻结后运行开阔/街区/窄路 × 普通箱体/低路障/悬空杆 × 种子0、1、2 × 两种跟踪，共54回合。旧组27份数组须与第一轮矩形组逐位一致。
3. 再检查未参与开发的种子3、4，覆盖窄路三种障碍、两组，共12回合。该检查只检验新噪声实现，不称为新环境泛化。
4. 保留拒绝测试：小于外扩车身宽度的窄口、只检查端点会漏掉的转身角落。到达提升必须同时满足无新增碰撞、原有18个成功回合无退化。

## 必须记录与验收

- 每帧真实/估计位姿、实际动作、雷达与深度、当前规划、目标、保护触发原因；新控制器的切线、曲率、横向/朝向误差及未限幅角速度。
- 单独记录旧/新组相对当前计划的偏差；以相同固定几何定义事后计算，不把定位误差当路径跟踪误差。
- 实体最小间隙、外扩足印与先验/真实地物的关系、制动帧数与次数、完成/未完成、全部失败回合。
- 每次规划及控制墙钟耗时的P95、P99与最大值；播放流畅不能证明实时能力。
- 图、讲义、变量表、思考题、复现命令和窗口同步更新。原记录不覆盖。历史档案按当时保存的源码快照核验；当前实现另做基线逐位对拍。
- 测试先跑几何/控制/记录已知答案，再跑受影响导航与窗口完整选择集、quick、Ruff。只有出现跨模块风险时才扩大到历史慢层，避免重复运行不相关的第53课稠密求解。

## 停止点

若跟踪修改仍无法通过，报告真实失败并定位；需要改变速度、路线或安全表示时，先另立对照，不能把多项修改合成同一个“跟踪收益”。

## 预试后追加的独立因素（正式批次之前）

预试1（切线/曲率反馈）与预试2（几何纯追踪）均在6秒、约3.38米处停止。种子0预试2的当前车身仍可通行；但旧路线保留把当前位置(4.811,5.355)直连前视点(5.140,5.316)，这一条新弦线被先验墙拒绝。此时相对旧折线的横向偏差仅约0.13毫米。去掉全部观测点仍被拒绝，说明不是增加雷达噪声导致。

因此在正式批次前追加“路线保留”因素：保留最近线段起点之后的原折线，不把前视目标当作裁剪起点。实际位姿仍需足印可行，距原线最多5厘米，剩余每段仍需通过相同足印检查，否则重新调用原规划器。5厘米是允许继续沿用路线的接近阈值，不是减小障碍余量。

此时拟将正式设计改为2×2：旧保留＋旧跟踪、旧保留＋圆弧曲率跟踪、保留原曲线＋旧跟踪、保留原曲线＋圆弧曲率跟踪（其中跟踪候选最终由下一段冻结为切线反馈）。固定27场景组合共108回合，留出两种子窄路共24回合。其余控制变量和验收不变；明确区分跟踪收益、路线保留收益及其交互。两次失败预试均保留在本地独立目录。

最终候选冻结：预试3的“纯追踪＋保留曲线”仍在7秒失败；预试4改回预试1相同的切线/曲率反馈，与保留原曲线结合后16.4秒到达、零碰撞。正式四组的跟踪因素因此固定为**旧角度比例跟踪 / 切线曲率反馈**，不使用纯追踪候选。角度增益2/s、横向修正系数2/s、归一速度0.6m/s；原35cm前视点仍决定前进/原地调整，速度上限和刹停保护不变。此后不根据正式批次或留出种子结果调参。

执行完成后的结果和局限另见[第二轮讲义](69-footprint-tracking-round2.md)，以上保留登记与候选选择的先后过程。
