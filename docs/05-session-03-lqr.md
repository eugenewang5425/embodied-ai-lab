# 第三课：杆扶住了，车为什么还要管？

日期：2026-09-02。范围：倒立摆全状态反馈，不进入机械臂、视觉或强化学习。

## 1. 今天先理解一句话

**“杆没倒”不等于“小车停在该停的位置”。**

可以想象你用手托住一根竖直的棍子：为了防止它倒，你会一直移动手。
如果只顾棍子的角度，手可能越移越远。机器人同样需要同时关心姿态、位置和速度。
这也对应 GIS 中的一个区别：对象朝向正确，并不代表它处于指定坐标。

上一课 PD 只使用两个状态。本课把四个状态都纳入目标：

| 状态 | 想达到什么 | 为什么需要它 |
| --- | --- | --- |
| 小车位置 x | 回到轨道中心 0 m | 不能一直漂走 |
| 关节角 θ | 让杆物理竖直 | 不能倒下 |
| 小车速度 v | 降到 0 m/s | 经过中心但高速冲过去不算停稳 |
| 关节角速度 ω | 降到 0 rad/s | 接近竖直但仍快速转动不算稳定 |

这里暂时直接读取仿真器状态，相当于理想传感器。以后才研究如何从带噪声的传感器估计状态。

## 2. 为什么不能给每个状态随便加一个“往回拉”的系数？

小车和摆杆通过关节连在一起：小车加速，会改变摆杆倾斜；为了扶杆，又得移动小车。
所以它们不是四个独立问题。上一课粗扫“减去位置、速度”的规则没有解决问题，不代表位置反馈无用，而是不能独立猜符号和增益。

新演示的共同初态是：小车偏右 0.20 m，杆相对真实竖直偏 0.05 rad，两种速度都是 0。
LQR 一开始让车略微继续向右，到约 0.255 m，再返回中心。这是为了调整杆的倾斜和运动方向。
**短暂远离位置目标，并不一定是控制错误，要看整个系统随后怎样运动。**

看 `results/lqr_2026-09-02/comparison.png` 左上角：红色旧 PD 一直漂到轨道边缘；蓝色 LQR 返回中心。
图中红色 × 表示失败，此后没有数据，不把重置后的轨迹接在一起。

## 3. LQR 是什么？暂时不用背推导

LQR = Linear Quadratic Regulator，线性二次调节器。

- **线性**：只在竖直平衡点附近，用简单线性关系近似运动。
- **二次**：把误差平方后计入代价，较大的误差受到更重处罚。
- **调节器**：根据现在的误差持续计算控制输入。

我们先告诉它：偏离目标有多不好、过大的控制输入有多不好。
然后它利用运动模型，系统地计算一组相互配合的反馈系数。
这不是神经网络，也不是靠奖励试错训练的强化学习。

把四个状态写成一列 `s = [x, θ, v, ω]`，目标为 `s*`，误差 `e = s - s*`：

```text
预测下一步：e_next ≈ A @ e + B @ u
每一步代价：e.T @ Q @ e + u.T @ R @ u
控制规律：  u = clip(-K @ e, -3, 3)
```

符号含义：`A` 描述各状态如何随时间相互影响，`B` 描述输入如何改变状态；
`Q` 是状态误差的权重，`R` 是输入大小的权重；求解得到的 `K` 才是控制器系数。
权重要考虑 m、rad、m/s 等不同单位，不能只凭数值大小跨单位比较。

本课固定教学权重 `Q = diag(10, 100, 1, 1)`、`R = 0.1`，未在验证种子上调参。
对本地模型求得：

```text
K ≈ [-2.70969, -17.48424, -3.10075, -2.71167]
```

这里 `u = -K @ e`，不要把外面的负号漏掉，也不要把这些系数直接移植到另一台机器人。
求解采用 SciPy 的离散 Riccati 方程；数学推导可选读 [MIT LQR 课程](https://underactuated.mit.edu/lqr.html)。
函数接口见 [SciPy solve_discrete_are](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.solve_discrete_are.html)。

## 4. 先校准目标，再谈控制

本次核对原始 MJCF 发现两处早期课程简化需要纠正：

1. **输入不是直接的牛顿值。** 执行器 `gear=100`，输入 `u=1` 时，MuJoCo 的 `qfrc_actuator[0]` 为 100 N。因此动作范围 `[-3,3]` 对应本模型执行器水平力 `[-300,300] N`。它不是小车净受力，净运动还受重力耦合、阻尼和约束影响。参见 [MuJoCo gear 定义](https://mujoco.readthedocs.io/en/stable/XMLreference.html#actuator-general-gear)。
2. **关节角为零不是严格竖直。** 杆端点有 0.001 m 的横向偏置、高度为 0.6 m。
   由质心位置计算真实平衡角：`θ* = -atan2(0.001, 0.6) ≈ -0.001666665 rad`。
   在 `[0, θ*, 0, 0]`、零输入下，仿真加速度为零；在全零状态下，加速度不为零。

这有点像 GIS 里先校准坐标基准：如果目标零点本身有偏置，再努力降低“数值误差”也不等于达到物理目标。
旧 PD 保留 `θ=0` 的算法作基线；新 LQR 改用真实平衡点。因此这是“旧控制方案 vs 完整新方案”，不能将全部改善归因于 LQR 求解器本身。
这两点只校正旧结果的物理解释，没有重写历史结果。

## 5. 怎样让数学模型和仿真对应？

- 仿真物理步长 0.02 s，每次动作持续两个物理步，控制间隔是 0.04 s。
- 对真实的两步 RK4 仿真函数做中央差分，得到离散 `A`、`B`；不能误用单个 0.02 s 的模型。
- 每次差分新建仿真数据，避免上次运行残留影响结果。
- 在真实 MuJoCo 非线性环境中验证，不只在自己拟合的线性模型里验证。
- 线性闭环 `A-BK` 的最大特征值模约 0.946574，小于 1；它支持局部线性稳定性判断，不等于全局保证。

本课未修改环境物理参数、终止角阈值或 PD 参数；只添加 LQR 方案和更长的同条件测试。

## 6. 实测结果

同一批种子 0–19，最多 1000 步，即 40 秒，失败就结束，不重置续算：

| 方法 | 完成 40 秒 | 平均回合长度 | 最后达到居中稳定条件 |
| --- | ---: | ---: | ---: |
| 随机动作 | 0/20 | 6.85 步（约 0.27 s） | 0/20 |
| 旧角度 PD | 0/20 | 280.3 步（约 11.21 s） | 0/20 |
| 全状态 LQR | 20/20 | 1000 步（40 s，上限） | 20/20 |

同一 LQR、不改权重，额外种子 20–39：20/20 完成，20/20 最后稳定。
默认初始噪声很小，这 40 次不能代表任意初态。

“完成”严格要求最后一步也未失败；时间上限截断 `truncated` 不是物理失败 `terminated`。
“稳定”要求在结束前至少连续 2 秒，并保持到回合结束：

```text
|x| ≤ 0.02 m；|θ - θ*| ≤ 0.01 rad；|v| ≤ 0.02 m/s；|ω| ≤ 0.02 rad/s
```

额外的 20 cm 偏移演示：LQR 在约 **2.56 秒**进入以上范围并保持到 40 秒；旧 PD 在 **8.08 秒**失败。
新方案在理想仿真终态误差接近数值精度，不代表真实机器人拥有相同精度。
不同策略失败时间不同，所以输入 RMS 不直接用于宣称节能；平方输入代价也不是机械能。
