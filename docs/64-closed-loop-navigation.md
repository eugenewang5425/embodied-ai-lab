# 闭环导航对照——修正协议下的四组定位来源对照

> v1（诊断版）的五处接线错误（PF 单位 25× 偏小、扫描时序错位、运动噪声固定
> 5 cm/步、权重递推缺失、真值代为宣布到达）已全部修正并有专属接口测试。
> 修正后四组 **零接触帧**、不可达 **12/12 安全拒绝**、A/B **12/12 到达**、
> C/D 各 **11/12 到达 + 1 次规划放弃**。

## 1. 修正协议（v2）相对 v1 的五处修复

| # | v1 问题 | v2 修复 |
| --- | --- | --- |
| 1 | PF 把每步轮增量（rad）当速度（rad/s）→ 前进预测少 25× | 增量÷DT→速度→GEOMETRY.body_velocity |
| 2 | PF 传播只给平移加偏差，转向未加 | B/PF 读取同一份带偏差测量 |
| 3 | 扫描在运动前获取，但用于更新运动后的粒子 | 传播→扫描→测量→控制→执行 |
| 4 | 每步固定 5 cm 噪声（不管实际运动量） | 按运动比例（α×|ds|+基值） |
| 5 | 真值距离<20 cm 即自动宣布成功 | 估计连续 10 帧在门内才宣布，评分核对真值 |

权重递推：posterior ∝ prev_w × likelihood，ESS < N/2 触发 systematic resampling。

## 2. 任务推导

4 个可达任务由避障图连通域四象限几何推导 + 1 个不可达任务（床面足迹内，
激光切片可通但机体高度带被占）。**所有任务进入同一导航入口**：不可达任务
也由规划器实际返回 no_path，评分器根据任务标签分类。

## 4. 关键发现

1. **全组零接触帧**：修正 PF 接线后，C/D 的估计不再跳变到障碍附近——
   v1 的大量的接触帧是接线错误的产物，不是 PF 的固有缺点；
2. **不可达 12/12 安全拒绝**：先验避障图 + 规划器正确判定床面足迹不可达；
3. **C/D 各 1 次规划放弃**：PF 估计短暂偏移到规划器无法找到路径的位置——
   这是 PF 在特征稀疏区域的已知局限（与 v1 的机理一致但幅度大幅缩小）；
4. **B = A**：2% 偏差在 1-2 m 短任务上累积 ~2-4 cm，不足以导致碰撞或超时；
5. 方法论：v1 的五处接线错误**各自都能改变结论**——修正后必须重新评估，
   不能从有接线问题的结果中推导新的算法机理。

## 5. 边界

- 单房间、单噪声幅度（1 cm 传感 / 2% 轮偏差）；60 回合为首轮修正验证；
- 避障图来自完整三维几何（先验参考）；单层激光盲区不变；
- D 组建图阶段为预定路线的运动学回放（非估计驱动闭环建图），如实标注。
