# 闭环导航对照——修正协议下的四组定位来源对照

> 照片房间从开环回放升级为闭环导航。修正了 v1 的评估目标错误、PF 单位错误、
> 权重递推缺失和运动噪声不匹配后，四组定位来源在同一个物理房间里跑出干净、
> 可复现的结果：**A/B/C/D 全组 0 接触帧，不可达 12/12 安全拒绝，C/D 各 11/12
> 到达（唯一失败是 1 次规划放弃）**。

## 1. 闭环结构

每步按固定顺序执行（不回放预存坐标）：

```text
真实位姿 → MuJoCo 射线感知(0.18 m, 64 线, +1 cm 噪声)
        → PF 传播(轮增量/DT → 速度) + 递推测量更新
        → A* 规划（估计位姿出发，先验避障图上）
        → 路点跟踪 + 激光安全停（v ≤ 0.15, |ω| ≤ 1.2）
        → 真实位姿按指令运动学推进 + MuJoCo 接触检查
```

v1 的五个接线错误（PF 单位 25×偏小、扫描时序错位、运动噪声固定 5 cm、
权重递推缺失、真值代为宣布到达）在 v2 全部修复；各修复有专属接口测试。

## 2. 任务推导

任务由避障图连通性**几何推导**（非手工挑选）：

- **可达**：机器人可达连通域内四个象限各一个目标 + 起点→象限中点（共 4 任务）；
- **不可达**：床面足迹内一个点——激光切片（0.18 m）可通但机体高度带
  （0.03–0.34 m）被床面/床架占据，先验避障图正确判定无路。

**所有任务进入同一导航入口**：不可达任务也由规划器实际返回 no_path，
评分器根据任务标签分类为正确拒绝（不按标签预写结果）。

## 3. 实测（修正协议，72 回合 = 5 任务 × 4 组 × 3 种子）

| 组 | 到达 | 放弃/拒绝 | 接触帧 | loc_mean (m) |
| --- | --- | --- | --- | --- |
| A 真值 | **12/12** | 0 | **0** | 0.005 |
| B 里程计 | **12/12** | 0 | **0** | 0.005 |
| C 参考图 PF | **11/12** | 1 wrong_give_up | **0** | 0.016 |
| D 自建图 PF | **11/12** | 1 wrong_give_up | **0** | 0.017 |
| 不可达拒绝 | – | – | – | **12/12** ✓ |

四组全部 **零接触帧**；C/D 各有 1 次规划放弃（PF 估计偏移到规划器无法
从该位置找到路径的区域），其余 11/12 到达。

## 4. 与 v1 的差异

| 项目 | v1（buggy） | v2（修正后） |
| --- | --- | --- |
| PF 单位 | 增量当速度 → 前进预测少 25× | 正确（增量/DT → 速度） |
| 权重递推 | 每步覆写旧权重 | 递推（后验 ∝ 先验 × 似然） |
| 运动噪声 | 固定 5 cm/步 | 按运动比例（α=0.10） |
| 到达判定 | 真值距离 < 20 cm 即自动成功 | 机器人按估计宣布 + 评分核对真值 |
| 不可达拒绝 | 按标签预写 | 规划器实际返回 no_path |
| 传感噪声 | 未注入 | 实际注入（σ = 1 cm） |
| 接触帧 | 529/606（大量碰撞） | **0**（全组零接触） |

## 5. 边界

- 单房间（3.4 × 3.8 m）、4 目标、3 传感种子；无动态障碍或布局扰动；
- 避障图仍来自完整三维几何（先验参考）；单层激光无法发现高于激光的床梁；
- C/D 各 1 次规划放弃是 PF 估计在特征稀疏区域的短暂偏移导致（下轮可
  通过重规划频率或全局重定位恢复）。
