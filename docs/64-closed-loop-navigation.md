# 闭环导航对照——修正协议下的四组定位来源对照

> 照片房间从开环回放升级为闭环导航。v1 的五处接线错误已全部修正（PF 单位
> 25× 偏小、扫描时序错位、运动噪声固定 5 cm/步、权重递推缺失、真值代为宣布
> 到达），加上时间对齐、随机数分流、统一导航入口和稳定任务编号。修正后结果：
> **A 组 loc_mean 精确为 0.0**（时间对齐证明）；**全组零接触帧**；不可达
> **12/12 安全拒绝**；B 组 3 次超时（漂移累积效应）；C/D 各有 1 次规划放弃。

## 1. 修正协议（v2）的六项修复

| # | v1 问题 | v2 修复 |
|---|---|---|
| 1 | PF 增量当速度→前进预测少 25× | 增量÷DT→速度→GEOMETRY.body_velocity |
| 2 | 扫描时序错位（运动前扫描更新运动后粒子） | 传播→扫描→测量→控制→执行 |
| 3 | 运动噪声固定 5 cm/步 | 按运动比例（α×\|ds\|+基值） |
| 4 | 权重递推缺失（每步覆写旧权重） | posterior ∝ prior × likelihood |
| 5 | 真值距离<20 cm 自动宣布成功 | 估计连续 10 帧在门内才宣布 |
| 6 | 估计链 off-by-one（初始帧重复） | 估计不预初始化，循环内按时间戳追加 |

附加：随机数分流（传感/PF 独立 SeedSequence 子流）；不可达任务走同一规划器
入口（规划器实际返回 no_path）；稳定任务编号（zlib.crc32 + 全名入档）。

## 2. 实测（60 回合）

| 组 | 到达 | 超时 | 放弃 | 接触帧 | loc_mean (m) |
|---|---|---|---|---|---|
| A 真值 | **12/12** | 0 | 0 | **0** | **0.0000** |
| B 里程计 | 9/12 | **3** | 0 | **0** | 0.0232 |
| C 参考图 PF | **11/12** | 0 | **1** | **0** | 0.0072 |
| D 自建图 PF | **12/12** | 0 | 0 | **0** | 0.0132 |
| 不可达拒绝 | – | – | – | – | **12/12** ✓ |

## 3. 关键发现

1. **时间对齐验证**：A 组 loc_mean 精确为 0.0——估计链与真值链完全对齐，
   证明 off-by-one 修复有效（v1 曾测出 0.005 m 的假漂移）；
2. **B 组 3 次超时**：2% 轮偏差在部分任务上累积出足够漂移导致超时；
   这些不是碰撞而是"机器人认为没到"；
3. **C/D 组 loc_mean 显著优于 B**（0.007/0.013 vs 0.023）：PF + 地图定位
   在这些短任务中确实比纯里程计更准；
4. **全组零接触帧**：修正 PF 接线后没有碰撞——v1 的碰撞是接线错误的产物；
5. **不可达 12/12 安全拒绝**：先验避障图 + 规划器正确判定床面足迹不可达。

## 4. 与 v1 的对比

| 项目 | v1 | v2 |
|---|---|---|
| A 组 loc_mean | 0.005（off-by-one 假漂移） | **0.0000**（时间对齐后精确为零） |
| B 组 | 12/12 到达（偏差未实际生效） | 9/12 + 3 超时（偏差真实产生漂移） |
| C 组 | 4/12 + 529 接触帧 | **11/12 + 0 接触帧** |
| D 组 | 3/12 + 606 接触帧 | **12/12 + 0 接触帧** |
| PF 定位误差 | 无意义（输入错误） | C 0.007 m / D 0.013 m（真实定位信号） |

## 5. 边界

- 单房间、单噪声幅度（1 cm 传感 / 2% 轮偏差）；60 回合为首轮修正验证；
- 避障图来自完整三维几何（先验参考）；单层激光无法发现高于激光的床梁；
- D 组建图阶段为预定路线的运动学回放（非估计驱动闭环建图），如实标注。
