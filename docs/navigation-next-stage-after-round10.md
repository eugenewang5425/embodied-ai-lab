## 2. 第十一轮候选：遮挡场景到底在哪一层误拒？

先固定第十轮320×240、低速和身体。开发只用现有失败回合；冻结诊断/候选后使用新种子29/30/31及两个未用于开发的布局。

当前证据具体到：第九轮修复组遮挡种子23、第十轮两组遮挡种子26，最终均为 `footprint_start_blocked`；实际全程最小身体间隙约7.85/8.50cm（只评分）。因此优先审查起点占据，不能笼统归为搜索预算不足，也不能仅凭真值间隙就直接解除保护。

工作顺序：

1. 冻结每个失败前后的原观测、地图与路径。分别列先验格子、观测格子、连续点对起点身体的限制，指出哪个单元/点、哪个车身部件首先触发拒绝。
2. 只在离线评分端与真实盒体比较，区分位姿偏差、射线噪声、10cm取整和过去点记忆。控制候选仍只能读观测。
3. 若确认重复格子膨胀造成误拒，只选一种表示修正；不同时改规划器、安全阈值与地图清除。实际新障碍是负例，不能靠过滤掉真障碍救回任务。
4. 开发阶段先解决可解释的一类错误，再登记正式条件和停止点；无改善则保留结果，进入受观测约束的有限恢复，而不是无限调阈值。

报告真实到点/误报、拒绝阶段、最小真实间隙、接触力与时间、额外恢复时间；旧失败记录不覆盖。连续格子与点约束的一致性应有已知答案小场景。

## 3. 第十二轮候选：增加像素后，错误位姿会不会误删真障碍？

先固定第十一轮裁决采用的表示；若它未通过，沿用冻结第十轮。需要同时包含先验未知的新增14cm路障、悬空杆、窄物体、遮挡后物体和移走旧墙。第十轮真低墙/横杆已在先验中，不能替代未知新增负例。

建议按单因素设置精确位姿、±2cm横向偏差、±1°朝向偏差，随后另加深度坏点/失效；不把多种误差混成一个“恶劣组”。新种子与新布局在正式前登记。真值仅评分，不用于清除确认、候选选择和恢复。

观察三类量：观测投到哪里、旧障碍为何被删/保留、实际身体是否通过。若真障碍误删或重接触出现，先改证据预算或暂停清除；不能仅用平均到达提高通过门槛。

## 4. 实时执行门槛：计算期间机器人仍要运动

当前控制字段在传感器生成后计时，未覆盖射线生成/物理/写盘；失败规划单次约8.6s，仿真没有在这段墙钟中后台积分。先把感知、地图、规划、执行保护、存档分别计时，再选择固定单机预算。

建立独立物理时钟与带采样时间/完成时间/有效期的控制请求。规划尚未完成时执行端继续限力运动或依据最新观测停车，不冻结世界；允许丢过期请求、限制队列、保留终止原因。对照显式固定0.2s排队与实际计算延迟，避免重复计算同一延迟。

测试长计算、传感器失效、突发积压、转弯刹停；比较真实到达、过期停车、碰撞和端到端p95/最大时延。只有这些通过，才讨论“实时10Hz”。

## 5. 再组合69—71，之后接视觉与机械臂

先统一55×44cm身体、接触物理、相机/雷达、25cm真实到点线、世界速度停稳和允许轻擦口径。迁移70的到点判断与71的有限恢复，按同输入比较原规则、联合判据、联合＋有限恢复，明确重试次数和新增时间。不沿用旧25cm半径平台的成功率作为新平台结果。

再接连续RGB-D同步与视觉位姿：RGB是否参与定位、米制深度如何得到、坐标外参如何标定分别验收。65课滤波失稳与62跨场景门槛仍独立保留。机械臂74课的RGB-D抓取可复用相机坐标工具，但不替代导航验证。

停止点按每批登记；完成诊断/受控对照/真实重放/窗口图文检查后汇报，避免用更复杂模型掩盖接口错误。
