# 具身智能学习路线

这条路线优先建立一条主线，不同时铺开过多框架。时间是有效学习与实验时间的粗略估计，不是截止日期。

| 阶段 | 核心问题 | 仿真实验 | 验收产物 | 预计投入 |
| --- | --- | --- | --- | --- |
| 0. 环境与实验规范 | 怎样保证实验能复现？ | MuJoCo/Gymnasium 自检 | 锁定依赖、运行命令、环境报告 | 1–2 小时 |
| 1. 动力学与反馈控制 | 状态、动作、力和运动如何关联？ | 倒立摆：随机、PD/PID、LQR | 曲线、参数、稳定时间和失败分析 | 8–12 小时 |
| 2. 运动学与机械臂 | 末端位置、路径与电机如何联系？ | 已实现平面 2R：FK/IK、Jacobian、时间安排、PD 与动力学前馈 | 配对轨迹、误差与边界证据 | 10–15 小时 |
| 3. 移动机器人系统 | 传感器、坐标系和节点如何组成机器人？ | 先做轻量差速车与坐标/里程计实验，再按需加入 ROS 2、LiDAR 和 TF | 坐标转换与运动闭环；后续 launch、地图与导航日志 | 15–25 小时 |
| 4. 三维感知与空间智能 | 如何从图像/深度恢复空间结构？ | 相机模型、深度、点云、位姿变换 | 点云可视化与误差分析 | 15–25 小时 |
| 5. 机器人学习 | 策略怎样通过数据或奖励获得？ | Reacher/推物：RL 或模仿学习 | 训练曲线、评估脚本、基线对比 | 20–35 小时 |
| 6. 综合项目 | 如何闭合感知—决策—控制？ | 移动机器人语义/目标导航 | 演示、指标、复现文档与复盘 | 30–50 小时 |

## 当前进度回顾（2026-09-03）

主线仍是“反馈控制 → 机械臂 → 移动机器人与坐标系 → 三维感知 → 机器人学习”，没有改为一直调试同一台机械臂。

| 位置 | 已有可复现产物 | 还不能由程序通过代替的学习验收 |
| --- | --- | --- |
| 第一阶段：倒立摆 | PD/LQR、多 R、扰动、测量噪声、倒下后的摆起与扶稳 | 解释状态/动作、反馈为何同时响应扰动，以及局部控制的适用范围 |
| 第二阶段：机械臂基础收尾 | FK/IK、Jacobian、25 条路径、8/4/2 秒对照、第十三课前馈＋PD | 区分几何可达、规划获准、实际执行；解释前馈/反馈/限幅，不能把模型内结果当硬件精度 |
| 当前第三阶段：移动机器人 | 第十四课坐标变换；第十五课里程计偏差；第十六课独立标定、冻结路线验证与错误测距基准反例；第十七课标定后逐区间噪声的重复统计 | 区分真实运动/读数/估计；解释标定与验证分离、错误基准的影响，以及系统偏差与随机分散的统计分离，不把均值当单次精度 |
| 后续：三维感知与机器人学习 | 主线课程尚未推进至此；独立 monocular-depth 目录不等同于本课程阶段验收 | 先有坐标、尺度、状态估计与基线，再谈策略学习与综合任务 |

第十三课是本阶段最后一个必做机制对照：只加模型前馈，原 PD 和任务不变。完成讲义中的三问后，回到第三阶段，不再为追求更漂亮的误差数字持续调增益。第十二课桌面交互验收曾受置前失败限制，仍在其讲义中标明；实验数据与 UI 验收分开记录。

与 GIS 的连接：第十四课的世界/车体/传感器坐标转换，第十五课的位姿累积误差与地标落图误差，是已有空间知识到机器人系统的直接桥梁。这里是局部平面上的旋转和平移，不是经纬度投影。先理解运动、转换与估计误差，再引入多节点软件组织。

第十五课组合回归曾有 Tk 初始化失败，历史证据保留。第十六课前采用真实窗口测试进程隔离，所有断言仍执行且失败向上传播；282 项全量连续两次通过，加入新课后 313 项全量连续两次通过。此为工程隔离方案，不宣称 Tcl 底层根因已确定。见[第十六课验收及边界](18-session-16-encoder-calibration.md)。

第十六课教学改版：针对“看不出标定价值、曲线与上一课重复”的反馈，改成对照测量→点击求系数→换路线验证三页；明确旧曲线对应关系，灯杆落图降为默认隐藏的辅助信息。只改呈现，不重跑或覆盖既有实验，改版后 315 项全量重复通过。

第十七课已在固定标定后加入种子化逐区间噪声（σ=0.008 rad），把同一条路线重复 20 次：固定标定组 20 次平均终点偏差仅毫米级但标准差约 2.5 cm（直行）与 1.2 cm（方形），未标定组均值仍为 18.65 / 15.70 cm。结论是固定 c 消除了系统偏差、无法消除随机分散；是否引入外部观测或滤波由任务要求决定，不自动加卡尔曼/SLAM。第十七课后 331 项全量连续通过两次，Ruff 通过（61 个文件）。见[第十七课](19-session-17-random-noise.md)。

## 主线知识结构

```text
空间与坐标系
    ↓
刚体运动学与动力学
    ↓
反馈控制与状态估计
    ↓
机器人传感器与 ROS 2 系统
    ↓
视觉、深度、点云与建图
    ↓
强化学习 / 模仿学习
    ↓
感知—决策—控制闭环
```

## 与 GIS 背景的连接

- GIS 坐标参考与机器人 TF：共同核心是坐标系、变换和误差传播。
- 遥感影像与机器人视觉：共同核心是成像、几何、特征和空间推断。
- 空间数据库/地图与 SLAM：共同核心是空间表示、查询、更新和不确定性。
- 路径分析与机器人导航：从静态空间规划进一步进入动态、带控制约束的规划。

## 暂时不并行展开的内容

- 不同时安装多套大型仿真器。
- 不在基础控制实验完成前直接训练大规模策略。
- 不先追求人形机器人、视觉语言动作模型或复杂数字孪生。
- 不把“能打开软件”当作完成，必须留下可复现的实验指标。

## 复杂度必须服务于当前问题（2026-09-03 更新）

升级前回答三个问题：现有方法在什么指标上不足？缺少哪一种物理/信息机制？加入它后怎样做同条件验证？没有具体答案就不升级框架，也不把随机性、自由度和渲染逼真度一起提高。

| 顺序 | 新的学习问题 | 最小仿真变化 | 方法与停止边界 |
| --- | --- | --- | --- |
| 已完成实验（第五课） | 平衡后被推，能否恢复？ | 现有倒立摆加入配对、可复现的随机外力 | 保持原 LQR；看失败率、恢复时间、输入峰值 |
| 已完成实验（第六课） | 观察到的状态不准会怎样？ | 固定 R=1，单独比较 0×/1×/3× 测量噪声 | 已生成真实状态/读数/动作证据；先理解指标，再按任务需要学习估计，不自动添加滤波器 |
| 已完成实验（第七课） | 倒到下方后怎样重新回到直立？ | 独立全转动杆、延长轨道、下垂初态和强推力，仍为 2 自由度 | 能量摆起与 LQR 切换；同时展示恢复成功和超限失败，不引入 RL 或大型平台 |
| 已完成实验（第八课） | 关节怎样共同决定末端位置？ | 平面双关节机械臂，49 个几何核验姿态、三个固定到达案例 | 已实现 FK/解析 IK/关节 PD；窗口区分几何直接设姿态与力矩驱动慢放 |
| 已完成实验（第九课） | 同一终点，怎样让末端沿直线走？ | 同一 2R、固定直线；只给终点/关节插值/Jacobian 三组对照 | Jacobian 生成参考，原关节 PD 驱动力矩；分别记录路径/时间误差，静态探针解释奇异方向 |
| 已完成实验（第十课） | 换一批路径后还可靠吗？ | 24 条有种子路径、1 条固定奇异反例，75 次配对回合；整条线先做几何检查 | 控制器不变，区分参考误差/执行误差/末尾持续达标；保留失败，不把抽样成功率泛化 |
| 已完成实验（第十一课） | 几何可达，为什么局部算法起步不了？ | 同一 2R、原清单、逐点解析 IK 参考；原两方法轨迹逐数组一致 | 奇异初态可起步并通过路径验收，同时保留中途偏离增大、速度规划上限等边界 |
| 已完成实验（第十二课） | 同一路径能不能走得更快？ | 原 25 条路径比较 8/4/2 秒，原 8 秒数组完全一致 | 分开规划拒绝、未饱和的跟踪偏差、实际力矩截断；保留原门限与 3 秒停留 |
| 已完成实验（第十三课） | 没有饱和，为何仍需误差来推动反馈？ | 原 25 条路径全部固定 4 秒，只比较 PD 与模型前馈加 PD | 通过数 13/25→25/25，保留一次起步截断；精确模型结果，不推广为硬件鲁棒性 |
| 已完成实验（第十四课） | 两轮如何产生运动？车上的坐标如何转到地图？ | 五种理想无侧滑运动、世界/车体/传感器变换与错误映射反例 | 解析终点核验、固定地标几何一致性和独立慢放；已知位姿，不是定位、反馈或力矩仿真 |
| 已完成实验（第十五课） | 由轮子转动估计的位置为什么逐渐偏离？ | 真值与编码器估计分离；右轮比例偏差 0/1/2%，同一真实直行与方形 | +2% 直行 2.4 m 位置误差 19.40 cm、朝向 9.17°；报告完整误差，不把短暂下降当纠偏 |
| 已完成实验（第十六课） | 已知的误差类型，能否先用简单方法修正？ | 四段新测距数据拟合 c≈0.980392，冻结旧直行/方形验证；另加测距偏大 1% 的反例 | 理想基准可消除固定比例误差，错误基准仍留 9.69/7.72 cm；不硬填真实偏差，不称为硬件精度 |
| 已完成实验（第十七课） | 固定比例正确了，为何每次仍可能偏不同？ | 同一条真值路线重复 20 次；右轮逐区间叠加 N(0, 0.008 rad)，公共随机数三组对照（无噪声/标定/未标定） | 均值和标准差分开偏差与分散：标定组均值毫米级、单次 std 2.5/1.2 cm；未标定组均值 18.65/15.70 cm 不被噪声抵消；先证明固定 c 的不足，再讨论外部信息 |
| 下一课（决策） | 要“一次就准”，缺的信息从哪里来？ | 先讨论任务要求，不直接改代码 | 若需厘米级定位才引入外部观测/滤波；否则保持现状进入多传感器坐标与 ROS 2 基础 |
| 真正需要增加自由度时 | 同一个末端目标怎样选择不同姿态？ | 从平面 2R 升到平面 3R | 研究冗余与关节限制，不仅为了画面更复杂 |
| 操作任务阶段 | 触碰、推物或抓取是否可靠？ | 接触、摩擦、质量偏差逐项加入，再考虑三维物体 | 先验证力学与简单控制；固定方法的失败证据支持后再考虑学习策略 |

当前倒立摆已有 **2 个自由度、4 个状态分量、1 个驱动输入**；二维双关节机械臂通常仍为 2 自由度，但有 2 个驱动，并引入末端任务与关节空间的映射。不能把状态维数、驱动数或“画面变成 3D”当成自由度增加。
“真实性”首先是与任务相关的力学、感知误差和可核验参数，不是更精致的贴图。每个小实验结束后进入下一项原理，不把教学窗口扩展成通用仿真平台。

第六至十七课实验已完成，但不把“程序跑通”等同于学员已理解。第十四课已转入移动机器人基础；第十六课增加固定比例标定和独立验证；第十七课在标定后加入逐区间随机噪声并把重复路线统计分成偏差与分散两部分，没有把电机加速、力矩、随机噪声或打滑伪装成已实现。详见[第十六课](18-session-16-encoder-calibration.md)与[第十七课](19-session-17-random-noise.md)。未知负载、3R 冗余、接触与学习策略按具体任务需要择期研究，不作为机械臂阶段的无限扩展。
第十七课已经给出固定标定无法解决的随机分散（单次不可预测，只能用分布描述）。滤波、延迟、打滑和 SLAM 按具体证据择期加入；是否引入外部观测由任务精度要求决定，不自动加卡尔曼或 SLAM。只有在简单模型与修正不足时才升级复杂度，需要多节点通信时再引入 ROS 2。
