# 第八课：两个关节角，怎样决定机械臂末端的位置？

## 先抓住这次的主线

倒立摆主要在控制“角度、位置与速度”；这次把任务改成：**把手臂末端送到世界坐标中的一个点**。

```text
给定末端目标 (X*, Y*)
        ↓ 逆运动学 IK：根据几何算角度
目标关节角 (q1*, q2*)
        ↓ 关节 PD：根据角度误差和速度算力矩
两个电机力矩 (τ1, τ2)
        ↓ MuJoCo：惯性、耦合与阻尼决定运动
真实关节状态 → 正运动学 FK → 当前末端位置
```

这里复用已经学过的 PD，不需要强化学习，也不需要为这个小任务安装新仿真器。这一课暂时不做末端直线轨迹、Jacobian 控制、碰撞、随机目标或传感器噪声。

## 1. 先用窗口动手

在 `D:\项目\具身人工智能` 运行：

```powershell
uv run python -m embodied_learning.arm_demo --results results/arm_reaching_2026-09-02_v2
```

窗口有两页：

- **① 几何探针：角度 → 坐标**。拖动两个关节角，看肘点与末端坐标。滑块直接设置 MuJoCo 姿态，只用于几何核验，不是电机控制过程。
- **② 动力学慢放：坐标 → 关节目标 → 电机**。读取保存的真实运动轨迹；默认暂停、0.25×，支持单步 0.02 s、时间轴和三个案例切换。

先在第一页依次点 `0°, 0°`、`0°, 90°`、`90°, 0°`。不要先背公式，先确认下面三个位置：

| q1 | q2 | 末端 X | 末端 Y | 你应该看到什么 |
| --- | --- | --- | --- | --- |
| 0° | 0° | 70 cm | 0 cm | 两根杆沿 X 正方向伸直 |
| 0° | 90° | 40 cm | 30 cm | 第一杆向右，第二杆向上 |
| 90° | 0° | 0 cm | 70 cm | 两根杆一起向上伸直 |

然后回答：**为什么最后一行 q2=0°，第二根杆却不是水平的？**

## 2. 坐标和“相对角度”

这台机械臂在水平 XY 平面内转动，界面是俯视图：X 向右，Y 向上；绕 +Z 逆时针为正。基座固定，第一杆长 0.4 m，第二杆长 0.3 m。

- q1：第一根杆相对于世界 X 轴的角度。
- q2：第二根杆相对于第一根杆的角度。
- 因此第二根杆在世界坐标中的方向是 **q1+q2**。

类比 GIS：一个点在局部坐标系中的位置，不等于它在世界坐标系中的位置。第二杆的局部坐标系会随第一杆一起旋转，所以不能把 q2 直接当成世界方向。

两自由度不等于两个状态分量：真实动力学状态是 `[q1,q2,dq1,dq2]`，共四个量。本任务有两个独立关节电机；倒立摆也是两个自由度，却只有一个小车驱动。这是驱动结构和任务变化，不是“画面更复杂所以自由度更多”。

## 3. 正运动学 FK：从角度算位置

把两根杆分别在世界 X、Y 轴上的投影相加：

```text
X = 0.4*cos(q1) + 0.3*cos(q1+q2)
Y = 0.4*sin(q1) + 0.3*sin(q1+q2)
```

程序内部角度用弧度，窗口显示度；输出坐标用米，界面同时换算成厘米。

固定 q1 只改 q2，肘点不动，末端绕肘点转；固定 q2 只改 q1，整条手臂围绕基座转。先观察这两种运动，就能理解公式中为什么一个方向是 q1、另一个是 q1+q2。

已对 `[-180,-90,-45,0,45,90,180]°` 的两两组合共 49 个姿态核验基座、肘点和末端：解析坐标与 MuJoCo 的最大差异约 `2.26e-16 m`。这是两个计算结果在浮点精度上的一致，**不是机器人硬件精度**。

## 4. 逆运动学 IK：从位置算角度

现在反过来，给定 X、Y，求 q1、q2。最小的解析方法来自三角形几何：

```text
c2 = (X²+Y²-L1²-L2²)/(2*L1*L2)
q2 = +acos(c2) 或 -acos(c2)
q1 = atan2(Y,X) - atan2(L2*sin(q2), L1+L2*cos(q2))
```

这里 `atan2` 会考虑所在象限。两种 q2 符号通常对应不同的肘部姿态，但末端位置相同；在完全伸直或完全折叠的边界，两支可能合并为同一种姿态。

这一模型没有关节角限位和碰撞，因此几何可达区是半径 **10–70 cm 的圆环**：

```text
|L1-L2| <= sqrt(X²+Y²) <= L1+L2
```

70 cm 以外太远；10 cm 以内则因为两杆不等长，即使折叠也够不到。程序会拒绝不可达目标，而不是偷偷把目标投影到可达边界。

正/逆运动学、2R 圆环可达区和多解的参考讲解见 [Modern Robotics：Inverse Kinematics of Open Chains](https://modernrobotics.northwestern.edu/nu-gm-book-resource/inverse-kinematics-of-open-chains/)。

## 5. 算到了角度，不等于已经到达

IK 只输出一个目标关节姿态，不负责真正移动机械臂。这一步由熟悉的 PD 完成：

```text
τ = clip(Kp*角度误差 - Kd*关节角速度, -0.25, +0.25) N·m
Kp = [12, 8]
Kd = [2, 0.6]
```

角度误差取最近一圈；两个关节分别计算力矩，再由 MuJoCo 模拟相互耦合的运动。

这次输入是 **关节力矩 N·m**，不是旧小车的水平力 N。模型电机传动系数为 1，所以输入数值就是关节力矩，不再乘旧模型的 100。模型参数含义参考 [MuJoCo XML Reference](https://mujoco.readthedocs.io/en/stable/XMLreference.html)。

第一版较大的微分增益与较高电机上限在离散控制下产生抖动，6 秒后仍约有 14.7 mm 末端误差，未通过验收；调试时换到另一姿态也出现过过快运动。因此最终使用上面的参数和较小力矩上限。参数适用于这个明确质量、惯量和采样周期的教学模型，不是通用最优参数。

早期未通过的记录保留在 `results/arm_reaching_2026-09-02/`；**当前应使用 `_v2` 目录**。没有删除或改写早期记录。

## 6. 三个固定案例及真实验收

共同初态 `q=[-40°,80°]`，初速度为零；每个案例运行 6 s。A=(35,30) cm，B=(35,-30) cm。

| 案例 | 验收结果 | 从开始到稳定的时间 |
| --- | --- | --- |
| 目标 A，q2 取正的逆解 | 成功 | 2.70 s |
| 同一个目标 A，q2 取负的逆解 | 成功 | 4.26 s |
| 目标 B，q2 取正的逆解 | 成功 | 2.52 s |

稳定不是“路过目标点”：要求末端误差 ≤2 mm、每个关节目标误差 ≤0.01 rad、每个关节速度 ≤0.02 rad/s，三项持续至记录结束且至少保持 0.5 s。没有物理或数值失败才算成功。

这是理想已知模型上的三个确定性教学案例，不是任意位置、任意负载下的成功率证明。无噪声时最后误差可以非常小，不能据此宣称真实硬件具有相同精度。

请在第二页比较目标 A 的两种姿态：**末端目标相同，但关节角、经过的路径和达到稳定所需时间不相同。** 这就是为何 IK 的多解需要选择，而不仅仅是“把一个公式算出来”。

## 7. 物理范围与数据对齐

- 水平面内两转动关节、固定基座，重力沿 -Z；不产生平面内的重力关节力矩。
- 两连杆质量分别 1 kg、0.7 kg，胶囊形状半径 0.025 m；惯量由形状与质量生成。
- 关节阻尼 `[0.1,0.08] N·m·s/rad`，转子附加惯量 `[0.01,0.005] kg·m²`。
- 物理积分步长 0.002 s，RK4；每 10 步更新控制，即 0.02 s / 50 Hz。不是倒立摆的 0.04 s。
- 没有关节角限位、碰撞、自碰撞、外力、噪声、载荷或轨迹规划。末端几何可达不意味着存在安全的真实路径。
- 每步后检查非有限状态、MuJoCo 数值警告以及 `abs(dq)>20 rad/s`；6 秒观察结束不等于物理失败。

保存的 `states` 与 `points` 有 N+1 行，`torques_nm` 有 N 行。`torques_nm[k]` 作用在 `[k*dt,(k+1)*dt)`，之后得到 `states[k+1]`。MuJoCo 在最终关节位置上重新前向计算 `site` 坐标，避免末端位置比关节状态落后一拍。

窗口“几何探针”使用直接设置关节姿态；“动力学慢放”读取真正执行力矩后产生的运动，二者明确分开。静态科学图在 `_v2/comparison.png` 中。
