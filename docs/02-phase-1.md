# 第一阶段：从状态到反馈控制

## 阶段目标

在本地运行一个可视化的 MuJoCo/Gymnasium 环境，理解状态、动作、奖励、终止条件和反馈控制，并用数据判断控制器是否有效。

## 学习顺序

### 1. 仿真环境接口

- `reset`：建立初始状态。
- `step`：施加动作并推进一个时间步。
- observation：智能体能获得的信息。
- action：控制器或策略对环境施加的量。
- reward：用于评价策略的标量信号，不等同于完整任务目标。
- terminated / truncated：任务终止与时间截断的区别。

### 2. 物理与控制概念

- 位置、速度、加速度、力/力矩。
- 开环控制与闭环控制。
- 误差、比例项、微分项和积分项。
- 连续时间直觉与离散仿真步长。
- 稳定性、超调、稳态误差和控制代价。

### 3. 三个递进实验

1. **随机动作基线**：确认环境接口与记录流程正确。
2. **PD/PID 控制**：直观看到反馈如何改变系统行为。
3. **LQR 或学习策略**：与手工控制器比较假设、指标和适用范围。

## 必须记录的指标

- 每回合累计奖励；
- 角度/位置误差；
- 达到稳定区间所需时间；
- 最大超调；
- 控制输入幅值或能量；
- 至少一个失败案例及原因。

## 验收标准

- 一条命令可运行 headless 自检并正常退出；
- 一条命令可打开可视化仿真窗口；
- 固定随机种子后结果可以重复；
- 生成结构化指标文件和至少一张曲线图；
- PD/PID 控制结果优于随机动作基线；
- README 中记录从零复现所需命令。
