# 第一阶段：从状态到反馈控制

## 阶段目标

在本地运行一个可视化的 MuJoCo/Gymnasium 环境，理解状态、动作、奖励、终止条件和反馈控制，并用数据判断控制器是否有效。

## 学习顺序

### 1. 仿真环境接口

- `reset`：建立初始状态。
- `step`：施加动作并推进一个时间步。
- observation：智能体能获得的信息。
- action：控制器或策略对环境施加的量。
- reward：用于评价策略的标量信号，不等同于完整任务目标。
- terminated / truncated：任务终止与时间截断的区别。

### 2. 物理与控制概念

- 位置、速度、加速度、力/力矩。
- 开环控制与闭环控制。
- 误差、比例项、微分项和积分项。
- 连续时间直觉与离散仿真步长。
- 稳定性、超调、稳态误差和控制代价。

### 3. 三个递进实验

1. **随机动作基线**：确认环境接口与记录流程正确。
2. **PD/PID 控制**：直观看到反馈如何改变系统行为。
3. **LQR 或学习策略**：与手工控制器比较假设、指标和适用范围。

## 必须记录的指标

- 每回合累计奖励；
- 角度/位置误差；
- 达到稳定区间所需时间；
- 最大超调；
- 控制输入幅值或能量；
- 至少一个失败案例及原因。

## 验收标准

- 一条命令可运行 headless 自检并正常退出；
- 一条命令可打开可视化仿真窗口；
- 固定随机种子后结果可以重复；
- 生成结构化指标文件和至少一张曲线图；
- PD/PID 控制结果优于随机动作基线；
- README 中记录从零复现所需命令。

## 理论对应（Embodied-AI-Guide）

在 [Embodied-AI-Guide](https://github.com/TianxingChen/Embodied-AI-Guide) 的章节体系里，本阶段落在 Control 篇：随机基线与 PD/PID 属于 6.2.1 经典控制的内容，LQR 属于 6.2.2 现代控制·最优控制的入口。同时，本阶段反复使用的 reset/step/observation/action/reward 接口，对应 Infrastructure 篇 Simulators 的最基本抽象；“固定种子、先基线后对照、记录失败案例”的验收方式，则与 Infrastructure 篇 Benchmarks 的评测纪律同源。

三个递进实验的数据给这条路线标了刻度：随机动作在 300 步里跑满 59 个回合、平均每回合约 5.08 步；换成与状态相关的 PD 后，同样 20 个种子下成功率从 0% 升到 100%，但小车在 200 步内漂移约 0.634 m；再把四个状态全部纳入二次代价的 LQR，则 20/20 完成 40 秒。这正是“按单误差出力”走向“按代价函数权衡多个目标”的过程，也解释了为什么本阶段要求同时记录误差、稳定时间、超调和输入幅值——单一指标分辨不出“杆没倒但车漂走”这类结果。

边界同样要写进地图：本阶段全部结果来自 MuJoCo 理想仿真，状态由仿真器直接给出，不涉及 Hardware 篇 Sensors 的读数误差、延迟与标定；也不进入 Algorithm 篇的 Robot Learning、VLA 等方向。理想仿真里得到的稳定性结论，不能直接当作真实硬件的精度或可靠性承诺。

## 思考题

1. 随机基线平均每步奖励 0.8033，而 PD 之后成功率 100%；但把测试窗口从 200 步延长到 500 步后，PD 全部在 265～306 步之间失败。“成功率 100%”这句话缺了什么限定语才完整？
   提示：对比第二次实验讲义“这还不是完整控制”一节中 200 步与 500 步两组数字。
2. 本阶段要求记录“控制输入幅值或能量”。第二次实验里随机动作输入 RMS 为 1.75075、PD 为 0.03053，为什么讲义提醒这不能当作能量效率比较？以后自己定义指标时应注明什么？
   提示：第二次实验对比表下方的统计时长说明，与第三课“平方输入代价也不是机械能”一句。
3. LQR 换到种子 20–39 仍然 20/20 完成。如果据此宣布“任意初态都稳定”，你会用哪个实验数据反驳？
   提示：第三课“默认初始噪声很小，这 40 次不能代表任意初态”；再对照第七课 +600 N 场景的结局。
4. 验收标准要求“至少一个失败案例及原因”。旧角度 PD 在 20 cm 偏移演示里 8.08 秒失败、长期评估平均 280.3 步且小车漂移约 1.004 m：从这两个数字推断，失败的根源更可能在哪个状态上？还需要什么数据才能坐实这个推断？
   提示：第三课第 6 节偏移演示与第二次实验“这还不是完整控制”一节。
