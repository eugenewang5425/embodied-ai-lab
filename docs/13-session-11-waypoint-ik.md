# 第十一课：换参考算法，不换电机

上一课发现：机械臂完全伸直、末端位于 `(0.70,0) m` 时，要求沿直线收到 `(0.50,0) m`，局部 Jacobian 参考一直停在原地。两个电机力矩全为零。这不是电机不足，而是参考生成没有起步。

本课只加一个方案：**沿规定路径逐点求解析 IK，再交给原来的关节 PD 执行。** 仍是 2R、两个电机、每个 ±0.25 N·m，没有增加随机推力、噪声或自由度。

三种方案颜色固定：橙色是关节角插值，绿色是局部 Jacobian，紫色是逐点解析 IK。下图默认显示偏离线段的距离；橙圆是当前规定点，橙叉是终点。

1. 播放逐点 IK：肩部和肘部同时小幅转动，末端逐步向左收回。

## 这与第八课直接用 IK 有什么不同？

第八课只对最终目标求一次 IK；现在对路径上的每个时刻求 IK。

| 方法 | 先规定什么 | 中间参考怎样产生 |
| --- | --- | --- |
| 关节角插值 | 初始和最终关节角 | 两个角度按平滑进度变化，末端未必走直线 |
| 局部 Jacobian | 末端路径与速度 | 根据当前参考姿态的局部速度关系，逐步积分关节参考 |
| 逐点解析 IK | 每个时刻的末端坐标 | 每个规定坐标直接求对应关节姿态，再保持相邻解连续 |

可以借用 GIS 中路线采样的直觉：不只告诉系统最终站点，而是先列出沿路线的中间点。区别是，机器人还要把每个中间坐标转换成关节姿态，并由电机真正执行。

我们的离线参考序列是：

```text
按同一个 8 秒平滑时间表生成末端点 p[0], p[1], ...
    ↓ 每隔 0.02 秒对该点求解析 IK
得到关节参考 q_ref[0], q_ref[1], ...
    ↓ 选择同一正肘角分支，跨 ±π 时保持连续
参考速度[k] = (q_ref[k+1] - q_ref[k]) / 0.02
    ↓ 原 PD：角度误差 + 速度误差
两个电机输出力矩，MuJoCo 推进实际运动
```

速度是提前规划好的有限时间区间平均值，不是当前瞬间的精确导数；没有使用未来的真实传感状态。实际机械臂只在初始复位时设置 qpos，之后始终由力矩驱动，绝不直接改成 IK 解。

## 为什么这次能从伸直状态起步？

当 `q=(0,0)` 时，Jacobian 的 X 速度行是零。当前局部算法想沿 X 方向修正，却求出两个关节速度都是零，因此参考姿态永远留在这里。

逐点 IK 不问“在当前瞬间怎样产生这个 X 速度”，而是问“稍后这个更靠内的位置，对应怎样的弯曲姿态”。它可以给出接下来的一小步姿态，然后由 PD 驱动。

实际保存的头三个参考点为：

| 参考时刻 | 肩部角度 | 肘部角度 |
| --- | ---: | ---: |
| 0 s | 0 rad | 0 rad |
| 0.02 s | -0.0002583 rad | +0.0006027 rad |
| 0.04 s | -0.0007292 rad | +0.0017014 rad |

这没有让奇异 Jacobian 突然变成可逆矩阵，也不意味着电机能够瞬间沿任意方向运动。它绕开了“只用当前一阶速度映射生成参考”的停滞；真实运动仍存在惯性、跟踪滞后和短暂路径偏差。

## 固定反例的真实结果

沿用原验收：完整运行 11 秒；移动期 0–8 秒最大偏离有限线段 ≤2 mm；运动结束后到记录末尾连续至少 0.5 秒满足末端误差 ≤2 mm、每关节误差 ≤0.01 rad、速度 ≤0.02 rad/s。

| 方法 | 最大偏离线段 | 时间跟踪误差 RMS | 停稳 | 路径验收 |
| --- | ---: | ---: | --- | --- |
| 关节角插值 | 7.670 mm | 27.562 mm | 通过 | 未通过 |
| 局部 Jacobian | 0 mm（原地不动） | 125.227 mm | 未通过 | 未通过 |
| 逐点解析 IK | 1.342 mm | 0.446 mm | 通过 | 通过 |

逐点 IK 的两个电机峰值约为 `0.03848、0.02592 N·m`，均远低于 ±0.25 N·m。几何参考误差接近浮点精度，但真实末端在起步阶段仍有约 1.34 mm 偏差；不能把“逆解准确”说成“真实控制没有误差”。

`overview.png` 左上角为了看清细微偏差，X/Y 比例不同，已在 Y 轴标明纵向放大；教学动画仍使用等比例 XY 几何。

这里都是“路径与停稳同时通过”的计数。共 75 个回合；这是对已知问题集的回归验证，不是独立未知测试集上的成功率。

保留的关节插值/Jacobian 两种方法，对每条路径都逐数组核对了实际状态、实际末端点、力矩、规定点、关节参考与参考速度，和第十课已保存数据完全相等。一旦发现不一致就中止比较，不用容差掩盖基线变化。

### 不能得出“解析 IK 在所有方面更好”

近伸直组，“每条路径最大偏离”的中位数为：Jacobian 约 0.509 mm，逐点 IK 约 1.090 mm。逐点 IK 虽然让关节终态更快达到要求，但中途实际偏离可能更大。其中 near_extension_01 达到 1.891 mm，已经接近 2 mm 门限。

这也说明不应该立即缩短动作时间、增大负载或宣布足够鲁棒。控制余量需要另行验证。

## 三个实现边界

1. **分支不能乱跳。** 本课固定正肘角分支；初态若不在这个分支就拒绝，不在 t=0 偷偷换姿态。角度跨越 ±π 时取连续表示，避免差分速度出现 2π 跳变。
2. **参考速度不能无限大。** 沿用 1 rad/s 的参考规划上限。逐点 IK 若超过上限，明确拒绝该计划，不只把速度剪短、却继续跳到原位置参考。本批最大参考速度约 0.432 rad/s，没有触发拒绝；DLS 原有速度缩放也未触发。
3. **解析解是模型相关的。** 当前平面 2R 恰好有简单解析 IK。这不是任意机械臂都能直接套用的方法，也没有解决障碍物、关节限位、碰撞、噪声或未知负载。

另有一个自动测试：从 `(0.100001,-0.3)` 到 `(0.100001,+0.3) m` 的直线几何上可达，但在当前 8 秒安排下，逐点 IK 的参考速度超过规划上限，因此被拒绝。它不计入上述 25 条路径的通过率，提醒我们“可达”仍不等于“按此速度可执行”。

## 学习停止点

请尝试解释：“为什么同样两个电机，上一种参考让它不动，另一种参考却能收回来？”以及“为什么几何参考误差几乎为零，真实末端仍会偏离？”

下一步可以只改变动作时间，例如保持同一路径、同一控制器，比较 8 秒、4 秒与 2 秒：观察参考速度、所需力矩与路径误差，区分算法可达和电机可执行。暂不增加第三个关节，也不换大型仿真平台。
