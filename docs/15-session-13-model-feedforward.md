# 第十三课：提前出力，再修正误差

本课作为机械臂基础阶段的收尾实验。上一课发现：4 秒动作里，25 条路径都没有力矩截断，却只有 13 条通过路径门限。现在不加大电机、不调 PD、不改轨迹，只加入**模型前馈**。

## 先理解区别

原 PD 每步都在工作，但主要根据“关节角和速度偏离参考多少”来算力矩。要让有惯性、阻尼的连杆运动，单靠这套反馈往往需要出现一定误差来产生相应的力矩。

前馈则根据事先规划的姿态、速度、加速度，以及已知机械臂模型，提前估计力矩。实际运动还有误差，所以原 PD 仍保留。两者是一起工作，不是“前馈做完再启动 PD”。

类似你提前知道一个物体的重量，抬起前就估计该用多大力；拿起来以后仍根据实际感觉调整。这个比喻解释“预估＋修正”，并不表示本课水平机械臂需要抵抗抬升重力。

| 概念 | 输入 | 输出 |
| --- | --- | --- |
| 逆运动学 IK | 想让末端到哪个坐标 | 对应的关节角 |
| 逆动力学 | 想要的关节姿态、速度、加速度 | 模型预测的驱动力矩 |
| PD 反馈 | 参考与实际状态的差异 | 纠正误差的力矩 |

MuJoCo 的逆动力学接口由位置、速度和预先设置的加速度计算力；输出 `qfrc_inverse` 包含所需的驱动与外加广义力。[官方接口说明](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-inverse)、[计算流程](https://mujoco.readthedocs.io/en/stable/computation/index.html#inverse-dynamics)

## 本课的控制结构

```text
总请求力矩 = 模型前馈 + 原 PD 修正
实际施加力矩 = clip(总请求力矩, -0.25, +0.25) N·m
```

前馈在独立的模型计算数据中，读取整段预定参考，不接触实际仿真状态。真实机械臂复位后只通过电机力矩运动；没有把它的位置直接设置成 IK 解，也没有偷偷施加额外外力。

当前无接触模型的运动方程可写为：

```text
M(q) × ddq + b(q,dq) = 电机力矩 + 被动力
```

因此参考状态处的前馈为 `M(q_ref) × ddq_ref + b(q_ref,dq_ref) − 被动力(q_ref,dq_ref)`。这里包含惯性、运动耦合和关节阻尼补偿。机械臂在水平 XY 平面运动，静止时绕这两个关节的重力力矩为零；不能把本次收益解释成“重力补偿”。这是当前模型的结论。[MuJoCo 方程与力的分类](https://mujoco.readthedocs.io/en/stable/computation/index.html#general-framework)

前馈不读实际姿态，PD 才读实际状态；所以这是**参考轨迹逆动力学前馈＋关节 PD**，不是在实际状态上进行反馈线性化的 computed-torque 控制，也不是神经网络或机器人学习。

## 单因素对照如何保证

- 使用第十二课同一份清单的全部 25 条路径，顺序不变；统一 4 秒动作＋3 秒停留。
- 原机械臂、质量、惯量、电机 ±0.25 N·m、PD 增益、0.02 秒控制周期、1 rad/s 规划上限均不变。
- 两个控制器的末端规定点、关节参考和速度参考完全一致。
- 原 PD 的状态、末端、力矩及全部原有参考数组，与第十二课保存的 4 秒记录逐数组完全相等；否则中止比较。
- 保留原 2 mm 路径门限，以及末尾连续至少 0.5 秒的末端、关节角和关节速度门限。不筛掉失败样本。

这里的最终停稳允许发生在后面的 3 秒内，不等同于严格在第 4 秒就停稳；报告继续单独保存第 4 秒的末端误差。

## 实验结果

| 方法 | 内部路径 | 近伸直路径 | 固定伸直反例 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 原 PD | 11/12 | 2/12 | 0/1 | 13/25 |
| 模型前馈＋原 PD | 12/12 | 12/12 | 1/1 | 25/25 |

50 个回合都完整运行、最终停稳，没有物理异常终止。每条路径的移动期最大偏离都降低了，但这只是已知任务集、精确模型条件下的结果，不代表真实机械臂或未知任务必然如此。

具体例子：

| 路径 | 原 PD 最大偏离 | 前馈＋PD 最大偏离 |
| --- | ---: | ---: |
| 原清单首条 `interior_00` | 0.875 mm | 0.042 mm |
| `near_extension_01` | 5.671 mm | 0.497 mm |
| `singular_inward` | 3.628 mm | 0.812 mm |

首条路径的肩部 PD 修正力矩 RMS 从 0.02360 N·m 降为 0.000310 N·m：大量预期的出力由模型提前提供，反馈需要纠正的部分减少了。**这不是电机总力矩或能耗降低同样比例**，因为前馈本身也在出力，本课没有进行能耗评估。

### 前馈不会突破电机上限

固定伸直反例的起步控制区间，肩部合计请求约 -0.276 N·m，实际施加 -0.250 N·m，发生一次 0.02 秒的截断。原 PD 同一任务没有饱和。加前馈后误差更小且通过验收，但它没有消除力矩限制，也没有保证每个瞬间更“省力”。

本批其余 24 个前馈回合未发生截断。所有结果均保留。

## 数值实现的边界

速度仍沿用上一课的有限区间平均参考。新增的加速度采用离线前向差分：

```text
ddq_ref[k] = (dq_ref[k+1] - dq_ref[k]) / 0.02
末尾补一个零参考速度
```

这不是处处精确的连续时间导数；奇异起点尤其不能假定关节轨迹任意光滑。前馈使用的是已知完整计划，不是未来真实传感数据。有限差分、零阶保持和实际积分都会留下误差，实际控制仍需验证。未测试去掉 PD 的纯前馈，不宣称纯前馈也能达到同样结果。

前馈与真实仿真使用相同的名义模型，没有未知负载、参数偏差、噪声、碰撞或电机延迟。因此这是“模型准确时有什么收益”的基线，不是模型失配下的鲁棒性证明。后续若任务需要，再单独研究质量误差，不在本轮同时改变条件。

## 理论对应（Embodied-AI-Guide）

在 [Embodied-AI-Guide](https://github.com/TianxingChen/Embodied-AI-Guide) 的地图里，本课对应（6）Control 篇·控制理论基础中"反馈与前馈分工"这一经典结构：前馈负责可预测的部分，反馈负责剩下的部分。它也是机器人学导论（6.3.2 运动学与动力学）的直接应用——逆动力学把 M(q)、b 从课本质变成每 0.02 秒出一个数。与 6.2.2 现代控制（最优控制）的区别也值得记住：LQR 是从优化问题反解增益，本课是按模型逐点算力矩，两者不是同一回事。

收益的数字结构比"25/25 对 13/25"更有理论意义：`interior_00` 的肩部 PD 修正力矩 RMS 从 0.02360 N·m 降到 0.000310 N·m（约 76 倍），最大偏离从 0.875 mm 降到 0.042 mm。反馈被"减负"到只需处理模型没算准的部分——这正是该结构在模型精确时的理论预期。表中两条近伸直/伸直例子在原 PD 下误差最大（5.671 mm 与 3.628 mm），收益也最明显（0.497 mm 与 0.812 mm）：这些位形正是单靠误差驱动反馈最难及时出力的地方。

前馈没有突破电机上限：固定伸直反例起步合计请求 -0.276 N·m、实际 -0.250 N·m，发生一次 0.02 s 截断。"模型补偿 + 反馈修正"不改变执行层的物理约束——前馈甚至让某个瞬间的合计请求更大（它提前出了更多力），只是误差变小让整体通过验收。理论推论是：该结构降低的是跟踪误差，不是对执行器容量的需求；模型失配时前馈跟着错，那是 6.2.3 先进控制（自适应、鲁棒方法）要处理的另一半问题。

本课刻意区分"参考轨迹逆动力学前馈 + PD"与 computed-torque 反馈线性化（后者用实际状态计算 M(q)、b，属于 6.2.2 的思路），也刻意不做"纯前馈"实验：在模型精确、无负载、水平面重力力矩为零的条件下，25/25 只是"模型准确时有什么收益"的基线，不能外推到真实机械臂。（4）Algorithm 篇里各类学习方法输出的动作序列，最终也要接受这一层执行可达性的检验；先用显式模型把收益来源拆干净，将来才不至于把模型收益误记到学习方法头上。

## 思考题

1. 肩部 PD 修正 RMS 从 0.02360 N·m 降到 0.000310 N·m（约 76 倍）。为什么讲义强调"这不是电机总力矩或能耗降低同样比例"？前馈自己出了多少力，去哪里看？
   提示：慢放 `singular_inward`，右侧四行依次是模型前馈、PD 修正、合计请求、实际施加。
2. 固定伸直反例起步：前馈 -0.203、PD 修正 -0.073、合计 -0.276、实际 -0.250 N·m。为什么加了前馈反而出现原 PD 没有的截断，这一回合却通过了验收？
   提示：比较两方案在起点之后 1 秒内的误差曲线，思考"瞬时请求更大"与"跟踪误差更小"是否矛盾。
3. 若真实机械臂的质量比模型大 20%，预计本课哪些数字先失效？"25/25"还能直接照搬吗？
   提示："数值实现的边界"一节与验收三问的第 3 问；想想前馈算错的部分由谁兜底。
4. 本课为什么专门澄清"这不是重力补偿"？如果同一台臂在竖直平面运动，前馈表达式里的哪一部分会新增不能忽略的分量？
   提示：`M(q)·ddq + b(q,dq) = 电机力矩 + 被动力`中，b 与"被动力"在水平面、竖直面各包含什么。
5. "未测试去掉 PD 的纯前馈"这句限制说明了什么？理论上前馈在什么条件下可以单独工作，本课缺了哪些条件？
   提示：前馈不读实际状态；想想初态误差、模型误差、外部扰动分别由谁处理。
