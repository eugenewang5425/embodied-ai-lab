# 第三十六课：DAgger 在线纠错——教师逐帧标注学生的状态分布，历史性 0→1 仍未出现

本课执行 docs/34 D-2026-09-06-03 序列的"先 DAgger"路线与 docs/26 第五节下一步第 1 项，
回答第 35 课留下的问题：**在线纠错是否是缺失的那一块**。预算探针（docs/40 §11.3）已排除
"训练量不够"：奖励曲线 65 万步后平线（斜率 −7e-07）、翻倍预算首达 0→30% 但首次成功从未。
文献 DAgger（Ross, Gordon & Bagnell, RSS 2010, "Reducing Off-Policy Learning to Imitation
Learning"）的标签是**在线聚合专家示范（aggregated expert demonstrations）**：每轮在
**当前策略**自己走到的状态上请专家出手，把（学生状态，专家动作）聚合进来训练——直接攻
第 32 课定位的复合误差（离线照抄对答案学不出闭环手感，8×2000 对示教的单步残差 ≈9–15 N
力偏差，给不出 ≥2 s 稳定所需的 ±0.01 rad/s 闭环不变量）。

**先说结论的形状**：DAgger 在线纠错**也没有实现 0→1**——两档（w_BC=10 在线纠错 与 w_BC=0
纯在线微调对照）× 3 种子 × 6 轮，**每轮末 20 回合下方初态评估全部 0 成功**（18 个轮-种子组合
共 0 次），末轮合计 0/60，首次成功从未。但过程的分解是**本课最有价值的产出**：① 纠错数据把
"直立区可达性"从 0 拉到 5/60（种子 0 第 4–6 轮 3/6/5 次首达、均值动作回合仍然从未进入直立区）；
② w_BC=0 对照 0/60 首达 0/60——**起作用的确实是纠错数据，不是"在线微调"**；③ 失败形态首次
分化出"超时未稳"占 5/60（纯微调档 55 出界+5 未稳 vs 纠错档 60/60 出界）。"离线（32）与在线
（36）的数据都给了"之后，阶段 5 的结论收敛为：**到顶（先验/数据密度层面）与稳住（闭环精度
层面）是独立瓶颈，而±0.01 rad/s×2 s 的验收在本课表示与目标函数下没有出现**——下一步
ACT/扩散类更强表示的优先级上升（见 §9）。

## 1. 原理：DAgger 在线聚合 vs 离线 BC / DAPG 的复合误差论证

**标记定义（Ross et al. 2010）**：DAgger 维护聚合数据集 D，每轮 t：π_t 自测 → 在每个 π_t
访问的状态 s 上询问专家 π* 的标签 → D ← D ∪ {(s, π*(s))} → π_{t+1} =
argmin E_{s~d_{π_t}} ‖π(s) − π*(s)‖。与第 28 课 BC 和第 32 课 DAPG 的两点本质差别：

1. **数据分布随策略演化**。BC/DAPG 的 (s,a) 来自**教师自己的轨迹**（教师状态分布 d_{π*}）；
DAgger 的 (s,a) 来自**学生自己的轨迹**（学生状态分布 d_{π_t}）——复合误差（compounding
error，Ross 2010 的定量论证：单步误差 ε 与视界 T 下，离线 BC 开环执行误差按 ε·T² 积累）
正是"学生越不像教师，教师离线轨迹覆盖不到学生犯错状态"这个错配。DAgger 的聚合在每一轮
重新从学生分布采样标签，让协变量偏移（covariate shift）不随轮次增长。

2. **"你说的这步应该怎么走" vs "照抄我给你看的一整段"**。第 32 课已证明后者不行
（开环回归≠闭环不变量）。DAgger 的纠错信号是状态依赖的：学生走到哪里，教师就在那里
给出**当前状态下的正确动作**——等价于把教师的反馈策略当成一个可查询的 oracle，逐步
"校准"学生。

**本课落地的具体化**（记录在 protocol）：
- 教师 = 第 7 课 HybridSwingupController（能量整形+LQR 滞回，模式内 hp 状态）
  ——**零样本 20/20、稳定中位 4.76 s**（本课重新复验，见 §2）。
- 学生 = 第 29 课 PPO 栈（5→64→64 ReLU 高斯策略 + 价值网，纯 numpy 手写）
  与第 32 课 BC 正则目标：L = L_PPO + w_BC · MSE(μ_θ(s), a_教师)。
- 每轮：学生 8 条并行 rollout（**精确下方初态 + 第 32 课同款抖动** ±0.15 rad / ±0.3 rad/s /
  ±0.10 m，记录原始状态序列与学生会采取的 a_t）→ 教师逐帧标注（每回合专用控制器实例
  按记录顺序重放状态，其 kick/energy/LQR 滞回模式沿被标注的状态流演化——在线教师）
  → D_r = D_{r−1} ∪ {对}（数据聚合，全部轮次保留）→ 15 次 PPO+BC 更新
  （minibatch 480、BC minibatch 256、lr 按总更新数退火、w_BC 轮内恒定）。
- **w_BC 调度**：w_BC 初始 = 10.0（第 32 课强锚档）线性跨轮退火到 0.0（每轮恒定，
  轮 0 为 10.0 → 轮 5 为 0.0）；末轮 w=0 是"交接点"（handover），最后一轮的数据只在
  纯策略梯度下训练——如实记录。
- **数据演化特性**（与"随策略演化"直接对应）：标注数据集规模随轮单调增长
  种子 0：362 → 714 → 1452 → 2165 → 2866 → **3730** 对；种子 1：178 → 1378；
  种子 2：297 → 3769；每轮新增帧数（聚合）837 / 992 / 1362 / 1632 / 1970 / 2084——
  学生回合越存活越长、被标注的帧越多（数据量与学生能力互锁）。

## 3. 实验检查

### 3.1 教师复验与数据质量：20/20、标注自洽、零丢弃

复验 20/20（稳定中位 4.76 s、20 次重复逐位一致——确定性控制器的同款形式校验）；
标注质量闸门通过；每轮第 1 回合重标注逐位一致（6 轮 × 3 种子 = 18 次全 True）；
非有限 drop 计数全部为 0。共 8,877 对 (s, a_教师)（三种子全部轮次聚合）全部来自一个已验证的教师。

### 3.2 每轮评估演化（头条：成功率/首达/首成）

| 轮（w） | 种子 0 成功/20 | 种子 1 | 种子 2 | 首达（种子 0） | 首达（1/2） | 数据集（种子 0） | BC MSE（种 0 轮内） |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 0（初值） | 0 | 0 | 0 | 0 | 0/0 | — | — |
| 轮 1（w=10） | 0 | 0 | 0 | 0 | 0/0 | 362 | 4.59→4.13 |
| 轮 2（w=8） | 0 | 0 | 0 | 0 | 0/0 | 714 | 4.58→4.26 |
| 轮 3（w=6） | 0 | 0 | 0 | 0 | 0/0 | 1452 | 4.37→3.89 |
| 轮 4（w=4） | 0 | 0 | 0 | **3** | 0/0 | 2165 | 3.96→3.41 |
| 轮 5（w=2） | 0 | 0 | 0 | **6** | 0/0 | 2866 | 3.40→3.34 |
| 轮 6（w=0） | 0 | 0 | 0 | **5** | 0/0 | 3730 | 3.26→3.13 |

- **成功率：18 个轮×种子×20 回合全部 0，末轮 0/60，首次成功从未** —— 0→1 未出现。
- **直立首达的分化是本课最清楚的信号**：种子 0 在第 4–6 轮评估中 3/6/5 次进入 |α|≤0.3 rad
  （首达时刻 2.8–5.1 s），其余种子全 0；末轮合计 5/60。对照 w=0 档首达全程 0/60。
- **均值动作回合从未进入直立区**（全部 None）：即随机评估中的"到达"依赖采样噪声（σ≈1），
  策略均值路径不包含教师的平稳抓取→稳定路径——**到达靠运气、稳定无路径**。

### 3.3 教师标注分布：学生状态上的教师指令

| 量 | 轮 1 | 轮 3 | 轮 6 |
| --- | --- | --- | --- |
| 帧数（3 种子聚合） | 837 | 1362 | 2084 |
| 标注均值（3 种子平均） | +0.004 | +0.039 | +0.081 |
| 标注 σ | 2.26 | 2.34 | 2.28 |
| 饱和占比（\|a\|≥2.99，即 ≈300 N） | **3.9%** | **5.3%** | **10.8%** |

标注分布呈**±2.5–3 双峰 + 中段平缓**（见演示①右下图）：教师对学生状态的强纠正指令
（±300 N 档）占 4%→11%，轮间走高——学生到达直立区附近后，教师以"最重的纠正"
把状态往稳定区拉，说明学生状态分布与教师闭环轨迹的残差在其中段依然显著。

### 3.4 w_BC=0 对照与失败形态：纠错数据有效，纯微调无效（但活法不同）

| 档 | 末轮成功率 | 末轮首达 | 末轮失败形态 |
| --- | ---: | ---: | --- |
| DAgger（w=10） | 0/60 | **5/60** | 出界 **60/60**，超速 0，超时未稳 0 |
| 纯微调（w=0） | 0/60 | **0/60** | 出界 55/60，超时未稳 **5/60** |

- **w=0 档什么都没有发生**（首达 0/60、成功 0），说明"在线微调"本身不值一文——
  6 轮内的差异全部来自教师标注（数据生效的证据）。
- 失败的"活法"首次分化：纯微调档出现 5 例**活满 30 s 但从未稳定**（种子 2，其回合跑了
  58,860 环境步），而 DAgger 档 60/60 全部出界——教师锚把学生的泵动学得激进，
  在边界附近"够不着"稳定区；纯微调学生"变乖"（活着）但同样稳不住。**两种路径殊途同归：
  都不具备 ±0.01 rad/s 的稳定尾段。**
- 训练目标收敛：总损失 46–58 → 0.15–1.35（末轮 w=0 时只剩 PPO 项）；BC 残差均值
  （三种子聚合）5.11 → 3.62，且**每个轮内都在下降**（如种子 0 轮 1 4.59→4.13）——
  纠错目标本身被正常优化，不是训练发散。

### 3.5 假设裁决

**主假设（在线纠错能否 0→1）不成立**：DAgger 6 轮 × 3 种子 × 20 回合 = 360 个下方初态
评估回合（18 个轮-种子检查点），**成功零次**，首次成功从未。如实入库。

**但第 32 课留下的问题被精化了三层**：① 在线数据有效（种子 0 首达 0→3→6→5，w=0 对照
恒 0）；② 数据仍只解决"到达"：首达 5/60 且全部落在轮 4–6（w 退火低位段），首达时刻
2.8–5.1 s 之后无稳定的下一段——与 32 课首达 2.04–2.12 s、34 课 1.22 s 同构：**到顶≠稳住**；
③ 均值路径全程无到达——学生 MLP 均值没有复现教师的"抓取→回中→稳尾"闭环路径，
稳定尾段缺的不是"被纠正过多少次"，而是**平滑连续函数逼近分段滞回控制器时的结构缺口**
（教师动作是 kick/能量/LQR 的分段连续函数，标注分布里 4%→11% 的 ±300 N 档就是该缺口
在数据上的形状）。

给教师轨迹（离线 BC 锚，33/60 首达），本课给学生状态+教师逐帧标签（在线聚合，5/60 首达），
成功全部为 0。加上预算探针（不是量）、课程实验（起态多样性必要非充分）、SAC（算法本身），
结论从"探索可终结吗？"收敛为三个确定的表述：

1. **探索层不完全是瓶颈**：外部先验（能量梯子/示教/档案/密集奖励/在线标签）都能把策略
   送上直立区（33/60、11/20、2/3、5/60），瓶颈不在"发现区域"。
2. **稳定层是独立且尚未解决的瓶颈**：所有学习路径都过不了 ±0.01 rad/s × 2 s 的验收尾段；
   在线纠错把"教师指令"直接喂给学生，也过不了——**该瓶颈不与数据来源相关，而与
   "单步 MSE 式的目标 + 连续 MLP 表示 + 固定探索 σ"这一组合相关**（假设，见 §6 边界）。
3. **两个未检验的疑犯**（下一步）：**表示容量**（ACT/扩散策略——动作块/去噪模型可表达
   更锐利的闭环反馈，直接替代"平滑均值逼近分段控制器"的结构缺口）与**训练↔评估分布 gap**
   （在线数据仍从"下方+抖动"来，评估从精确下方来，gap 比 29/35 课小但非零）。

## 6. 本课不能说明什么

- **w_BC 单点+单调度**：w_init=10.0、跨轮线性退火、轮内恒定；未试非零地板、指数退火或
  按 BC 损失自适应；"final round w=0 的交接点"意味着最后一轮数据只在纯 PG 下被吸收。
- **纠错预算小**：194,586 环境步 vs 29/32 课 500k/种子；每轮 15 更新 × 1 epoch（batch =
  8 回合的量）；学生从零初始化——"更多轮/更多更新/热启动"可能翻盘，本课未检。
- **单教师、单任务、单模型**：教师是确定性分段控制器；标注是离线重放（教师不与环境
  互动），无噪声/延迟/质量误差；不对真实硬件下结论。
- **探索 σ 固定**（learn_std=False，第 29 课惯例）；学生均值路径"未到达"与 σ 固定有关
  （若 σ 可学则均值可能不同），两类效应未分离。
- **20 回合/轮为有限样本**：5/60 首达、60/60 出界等都是 n 有限的计数；成功率 0 不隐含
  "不可能"。
- 第 29/32/34/35 课对照行引自其官方记录，本课未重跑；w_BC=0 档的 PPO 通路与第 29 课
  同一代码（单位梯度契约守卫），但未做整档逐位对照。
