# 第六课：看错了，也可能真的动起来

本课只学一个区别：**机器人真实的状态，不等于传感器报告的状态。**
继续使用同一倒立摆和 R=1 的 LQR，不换算法，不增加关节，也不与上一课的推力混合。

## 1. 从你熟悉的定位误差出发

想象你站着不动，地图上的定位点却在小范围跳动。这不一定是你在走，而可能是定位读数有误差。
如果机器人把每一次“定位点偏了”都当成必须纠正的真实位移，电机就可能开始动作。此后，它就真的动了。

本课的链条是：

```text
真实状态 s[k] → 加上读数误差 ε[k] → 测量值 z[k]
                                         ↓
真实状态 s[k+1] ← MuJoCo 物理运动 ← LQR 动作 u[k]
```

上一课的外力直接进入物理系统；这一课的噪声只进入控制器读数。仿真的位置、速度与失败判断始终保留真实值。
关于过程扰动与测量不确定性的区分，可参考 [MIT：Model Systems with Stochasticity](https://underactuated.mit.edu/stochastic.html)；从传感信息形成反馈是[输出反馈](https://underactuated.mit.edu/output_feedback.html)讨论的问题。本课尚未实现状态估计器。

## 3. 实验固定了什么？

- 同一 MuJoCo 模型、Q、R=1、K、输入范围和控制间隔；
- 严格竖直且居中的相同初态，初速度为零；
- 没有外部推力、延迟、漂移、模型误差或滤波；
- 每回合 250 个控制间隔，即 10 秒；
- 种子 200–219，各 20 回合；三个幅度共用每个种子的标准随机序列。

唯一改变的是测量噪声标准差的倍数：0×、1×、3×。

| 状态读数 | 1× 时的标准差 | 直观单位 |
| --- | ---: | ---: |
| 小车位置 | 0.002 m | 2 mm |
| 杆角度 | 0.002 rad | 约 0.115° |
| 小车速度 | 0.01 m/s | 1 cm/s |
| 杆角速度 | 0.01 rad/s | 约 0.573°/s |

标准差描述误差的典型尺度，不是误差上限。这里用均值为零的高斯分布，各通道、各时间步独立；单个有限回合的平均误差不保证恰好为零。3× 是标准差乘 3，方差则乘 9。
同一随机序列用于配对，使不同组主要相差幅度，减少抽样差异的干扰；但闭环运动发生改变后，三组测量值本身并不相同。

这些是人为设定的教学噪声，不是本机摄像头、编码器或真实机器人的实测规格。
尤其速度通道在这里被假设为直接可测且有独立噪声；实际若由位置差分求速度，误差会有不同的关联结构，本课不模拟那种传感链路。

## 4. 实测结果：都没倒，但质量并不相同

2026-09-02，完整 10 秒、每组 20 回合；下表是每回合指标的均值，三组均完成 20/20：

| 噪声幅度 | 真实位置 RMS 误差 | 真实倾角 RMS 误差 | 输入 RMS | 每步输入变化 RMS | 四状态同时处于容差内的时间占比 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 0× | 0 cm | 0° | 0 | 0 | 100% |
| 1× | 0.329 cm | 0.120° | 0.0527 | 0.0846 | 46.34% |
| 3× | 0.988 cm | 0.360° | 0.1582 | 0.2538 | 11.16% |

RMS 可以先理解为“不让正负误差相互抵消的典型幅度”：先平方、取平均，再开平方。这里的误差都相对目标状态计算。
“每步输入变化”是 `u[k]−u[k−1]`，不是对输入求时间导数；它帮助观察指令是否频繁变化，但不是电机磨损或耗电测量。
输入仍是 `u`，执行器小车水平力为 `100u N`，不是小车净受力。

容差沿用 `[0.02 m, 0.01 rad, 0.02 m/s, 0.02 rad/s]`。占比要求四个真实状态同时满足，不只看杆角度；它不是“失败概率”，也不是传感准确率。
持续噪声会不断打破严格稳定范围，所以这轮不继续追求“进入后永不离开的稳定时间”，改看真实误差、动作变化、容差占比和是否失败。
如果以后出现失败，短回合数据仍保留，但汇总均值只统计完整完成者，并必须同时报告完成数，避免把提前失败误判为动作更省。

这三组近似呈三倍关系，是当前局部、小噪声实验的结果，不保证更大噪声、输入饱和或不同模型仍如此。0× 的精确零来自理想模型与严格平衡点，不代表硬件能做到完全静止。

## 5. 用一个公式连接直觉

设测量值为 `z=s+ε`。在输入没有触及限幅时：

```text
u = −K(z−s*) = −K(s−s*) − Kε
                真正的纠偏    读数误差引入的输入
```

控制器不知道哪部分是测量误差。它只收到 z，没有偷看模拟器提供的 s 来纠正读数。
这里的 `ε` 是状态读数误差，不是执行器外力；不要直接把它当牛顿使用。

因此“反馈更强”“R 更小”不能脱离传感质量讨论。但本轮固定 R，先把测量误差的影响分离出来；不同时调 R 或加入新的滤波参数。

## 6. 到这里，该增加什么复杂度？

目前证据说明：有限范围噪声下仍未倒，但误差与动作变化增加了。它尚不能说明某个滤波器一定必要或一定更好，因为我们还没有真实传感数据、响应速度要求或允许的误差上限。
本轮到“测清影响”结束，不继续给倒立摆增加通用配置系统或复杂估计器。滤波与延迟作为以后有明确任务需求时的专题，不能仅凭曲线平滑就判定更好。

完成本课的三个辨别——真实状态、传感读数、控制动作——后，下一项目主题转向**平面双关节机械臂**：

1. 先给两根杆的长度、关节角、正方向和参考坐标系；
2. 从关节角算末端位置，核验解析计算与仿真一致；
3. 再让末端到达一个可达目标，最后增加有种子的随机目标。

这将直接连接你的 GIS 坐标变换与空间几何基础。它仍为 2 自由度，但从倒立摆的 1 个驱动改为 2 个关节驱动，学习问题变成“关节空间如何映射到任务空间”。第三关节留到需要研究冗余姿态时再加。

## 7. 复现、数据对齐与验收

在项目目录使用一个尚不存在的结果目录：

```powershell
uv run python -m embodied_learning.experiments.lqr_measurement_noise --output results/lqr_noise_my_run
```

输出包括：

- `summary.json`：噪声标准差、Q/R/K/A/B、模型哈希、版本、种子、逐回合与汇总指标；
- `trajectories.npz`：真实状态 `states`、测量值 `measurements`、实际使用噪声 `noise`、动作 `controls`、结束标志；另保存每个种子的完整标准随机序列；
- `comparison.png`：预先选定 seed=200 的三幅对照图。

数据对齐不能错一拍：`states` 有 N+1 行，其他逐动作数组有 N 行。`measurements[k] = states[k] + noise[k]`；从这一读数生成 `controls[k]`，再推进到 `states[k+1]`。最后状态没有额外测量，不能凭空补一个传感值。

噪声实验只在控制器前加一个小的读数包装器，复用原有 `run_episode`；不改 MuJoCo 真实状态、不改环境终止阈值、不改旧控制器，不新增依赖。后续按学员要求补充的慢放入口只读实验归档，旧多 R 和外力慢放入口仍保留。
测试验证零噪声与旧流程完全一致、即使读数超阈值也仍按真实状态判定失败、噪声不直接移动物体、相同样本配对、时间对齐、限幅、可复现性和拒绝覆盖旧结果。

验证命令：`uv run --locked pytest -q`、`uv run --locked ruff check src tests`、`uv run --locked ruff format --check src tests`。本轮 70 项测试通过。历史 R=1 文件和 `monocular-depth/` 保持原状；没有提交或推送 Git。
