# 第二次实验：PD 反馈控制

实验日期：2026-08-10

2026-09-02 校正：旧版把控制输入 `u` 标成了 N，忽略了执行器 `gear=100`；下文已更正单位，历史结果图片/JSON 未覆盖。关节角零点也不完全等于物理竖直，真实竖直约为 `-0.001667 rad`，详见第三课。原 PD 算法与原始数值保留作基线。

## 本课问题

随机动作与当前状态无关，所以倒立摆很快失败。本课让动作由摆杆的角度和角速度决定：

```text
当前状态 → PD 控制器 → 水平力 → 新状态
```

## 先从物理直觉理解

本课简化地把目标关节角取为 `0 rad`，接近但不完全等于物理竖直。

- 摆杆偏得越多，需要越强的纠偏动作，这就是比例项 P。
- 摆杆倒得越快，需要越早“刹车”，这就是微分项 D。

如果只看角度，不看角速度，就像只知道汽车距离停车线还有多远，却不知道汽车正在以多快的速度冲过去。相同距离下，不同速度需要不同制动力。

## 控制公式

本模型经过正负方向实验后采用：

```text
u = Kp × pole_angle + Kd × pole_angular_velocity
u = clip(u, -3, +3)
实际小车执行器水平力 F = 100 × u N
```

使用参数：

| 参数 | 数值 | 作用 |
| --- | ---: | --- |
| `Kp` | 40 | 根据当前倾角纠偏 |
| `Kd` | 1 | 根据倾倒速度抑制振荡 |
| 最大控制输入 | 3 | 经 gear=100 对应最大水平力 300 N |

当角度为 `+0.1 rad`、角速度为 0 时，本地方向实验显示：

| 控制输入 u（实际水平力） | 下一步角度 | 结果 |
| ---: | ---: | --- |
| `-3`（`-300 N`） | `+0.1480 rad` | 倾倒加剧 |
| `0 N` | `+0.1024 rad` | 继续自然倾倒 |
| `+3`（`+300 N`） | `+0.0566 rad` | 角度被纠正 |

因此这里的正角度需要正方向作用力，公式前面不加负号。符号不是通用结论，它取决于模型怎样定义坐标轴和动作方向。

## 公平对比方法

- 随机动作和 PD 控制使用同一个 MuJoCo 模型；
- 使用相同的 20 个初始随机种子；
- 每个回合最多运行 200 步；
- 每步 0.04 秒，因此测试窗口为 8 秒；
- 摆角绝对值超过 `0.2 rad` 时判定失败。

## 对比结果

| 指标 | 随机动作 | PD 控制 |
| --- | ---: | ---: |
| 成功回合 | 0 / 20 | 20 / 20 |
| 成功率 | 0% | 100% |
| 平均回合长度 | 6.85 步 | 200 步 |
| 最短回合 | 3 步 | 200 步 |
| 平均绝对关节角（相对关节零点） | 0.10619 rad | 0.000184 rad |
| 最大绝对关节角 | 0.32928 rad | 0.00592 rad |
| 均方根控制输入 u | 1.75075 | 0.03053 |

本次记录中 PD 的控制输入 RMS 更小。但策略失败时会提前结束，统计时长不同；这不能直接当作同等任务下的能量效率比较，输入平方也不等于机械功。

## 这还不是完整控制

当前 PD 只观察摆杆角度和角速度，没有控制小车位置：

- 200 步测试中，所有回合都能扶住摆杆；
- 小车最大已经漂移约 0.634 m；
- 把窗口延长到 500 步后，20 个回合都在 265～306 步之间失败；
- 长期评估的平均回合长度为 280.3 步，小车最大漂移约 1.004 m。

因此准确结论是：

> 角度 PD 能在短时间内稳定摆杆，但不能同时保证小车回到中心。

## 与 GIS 空间思维的连接

只控制摆角，相当于只约束一个要素的方向，却不约束它在空间中的位置。一个系统可以满足局部方向条件，同时不断偏离整体空间目标。机器人控制必须明确：我们究竟要控制哪些状态，以及哪些误差可以暂时接受。

## 理论对应（Embodied-AI-Guide）

在 [Embodied-AI-Guide](https://github.com/TianxingChen/Embodied-AI-Guide) 的地图上，本课位于 Control 篇 6.2.1 经典控制：以误差为输入的比例-微分反馈，关心超调、振荡与稳态误差——本课指标表背后的正是这些概念。经典控制并不因为“基础”而失效，但它的适用边界在本课数据里已经露出来了。

方向实验是经典控制落地的第一课：角度 `+0.1 rad`、角速度为零时，`-300 N` 使下一步角度恶化到 `+0.1480 rad`，`+300 N` 把它压回 `+0.0566 rad`。反馈极性由模型坐标与执行器方向的定义决定，不能靠背诵“负反馈”三个字，必须实测符号。

对比表给出基准方法的价值：同样 20 个种子，随机动作 0/20、平均 6.85 步，PD 20/20、200 步跑满；输入 RMS 从 1.75075 降到 0.03053。同时讲义提醒：失败方提前结束导致统计时长不同，输入平方也不等于机械功——把指标的适用范围写清楚，比“赢了”本身更重要，这也是 Benchmarks 评测的基本素养。

“这还不是完整控制”一节指向 6.2.2 现代控制·最优控制的动机：500 步延长测试全部在 265～306 步之间失败、长期平均 280.3 步、小车最大漂移约 1.004 m。杆的角度没倒，小车却漂走了——当多个状态通过动力学耦合、单误差反馈顾不过来时，就需要把全部状态纳入统一的代价函数去权衡，这正是下一课 LQR 的事。

## 思考题

   提示：回看“控制公式”一节的实测表与“符号不是通用结论”一句。
2. PD 的输入 RMS（0.03053）比随机动作（1.75075）小两个数量级。能否据此介绍“PD 更省电”？写出你会使用的措辞，以及要谈能耗还需补什么实验。
   提示：对比表下方关于统计时长与“输入平方不等于机械功”的提醒。
3. 200 步内小车最大漂移约 0.634 m，延长到 500 步后全部在 265～306 步之间失败，而失败前摆角一直是好的。从 PD 的结构（只用角度与角速度）解释这种失败为什么是结构性的，而不是偶然。
   提示：“这还不是完整控制”一节与长期评估的 280.3 步、1.004 m。
4. 只保留 P、去掉 D（Kd=0），根据“汽车冲过停车线”的类比预测摆杆行为；如果要实测，哪些条件必须与本次 20 个种子的协议一致？
   提示：“公平对比方法”一节的种子数、窗口、步长与失败阈值。
