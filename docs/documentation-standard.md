# 讲义、实验、编号与主页维护标准

2026-10-09 归并已有要求。依据：[第一阶段指标要求](02-phase-1.md)、[演示验收规范](26-experiment-review-2026-09-05.md)、[导航路线原交付标准](learning-history.md#原-nav-交付标准2026-09-27后续归并)及决策日志 D-2026-09-28-01/02。最新用户要求是按阶段与研究方向组织，全面去重并补引；不取消历史课程身份。

## 每份实验讲义的固定结构

| 项目 | 必须回答什么 | 不能用什么代替 |
| --- | --- | --- |
| 承接问题 | 上一实验哪种现象未解释，本次只检验什么 | 泛泛的算法简介 |
| 变量表 | 符号、通俗含义、单位、来源、改变它影响什么 | 只有符号和数值 |
| 原理 | 物理直觉 → 信息流/计算 → 必要公式；定义新量 | 公式堆砌、借真值完成算法步骤 |
| 对照设计 | 固定/改变项、组别、种子、开发/留出、门槛和停止条件 | 更换好种子、同时改多个因素却归因单个算法 |
| 数据与图 | 来源、有效/失败分母、均值/尾部、时间与输入代价；哪项回答问题 | 总奖励、无接触或单项测试代替任务完成 |
| 图文讲解 | 指标图、代表轨迹、必要 RGB/3D；图例单位、颜色一致，真实/估计/规划分开 | 只挑最好轨迹、RGB 回放当视觉闭环 |
| 机制与边界 | 支持的机制、未排除解释、负例、修复、适用条件 | 模型内自洽当实机精度或安全保证 |
| 理论与交付 | 原始来源及本地适配、3–5 思考题、复现、测试和真实窗口证据、下一项 | 模型名称、教程目录或代码存在当已复现论文 |

基础控制至少记录奖励、角度/位置误差、稳定时间、超调、控制输入或能量和一个失败；后续按任务增加停稳、接触、误报、覆盖率、恢复代价等。没有记录的指标注明未测，不从别的批次拼齐。

## 编号、阶段与版本

F1–F6 为基础阶段；NAV / MAN / DINO 为方向。方向实验 ID 稳定，迭代使用 R01 等；路线图阶段 S0 等表达依赖。课号、文档号、研究阶段、运行批次是不同字段。

保留课号 1–56、63–73、文件名、CLI 和结果目录；57–61 文档已对应 52–56 课，62 是基准。09-28 的“恢复新课程”决定保留。后续先写方向、问题、实验 ID 与阶段门槛，不预先排 74–76；需要新教学单元时说明新目标再分配课号，并更新[对照表](experiment-index.md)。

运行用新目录。保存场景/模型/策略版本、实际源码和配置哈希；工作区有相关未提交改动时不能只写 HEAD。开发、固定输入、留出闭环、独立物理重放、软件测试与真实窗口分别记批次。摘要、图和结论指向同一版本；决策日志只追加，撤回说明原因。渲染/解码通过不等于算法或硬件验收。

## 哪种内容放在哪里

| 内容 | 唯一主要维护位置 | 其他页面怎么使用 |
| --- | --- | --- |
| 三方向最新结论与限制 | README 当前证据表 | 路线图链接主报告，不再复制历史成绩串 |
| 基础课程与方向编号 | experiment-index.md | 主页保留六阶段与方向入口 |
| 详细算法、数据、失败 | 每份讲义与 benchmark 摘要 | 主页写一条结论、图册按版本保留 |
| 全部旧图文 | experiment-gallery.md / learning-history.md | 主报告保留必要机制图，避免主页加载全部图片 |
| 下一阶段与进入条件 | 对应方向 roadmap | 不在别的方向重复维护它的进展 |
| 原始文献与采用关系 | references.md + 讲义就近补引 | Guide 作知识地图，原论文/官方文档作机制来源 |
| 运行命令与环境 | running-experiments.md + 专项复现节 | 主页只放最小启动，外部资产依赖写明 |
| 理解待办 | learning-checklist.md | 不复写数十条“已完成”成绩 |

“主要维护位置”不禁止讲义再次给出支撑机制的数字；需要消除的是无版本、无目的、难同步的复写。历史报告保留当时成绩，页首标明其快照属性。

## 引用与状态

每个机制链接原论文、原作者教材或官方实现；注明是本地实现、简化适配、直接调用、机制参考还是未运行候选。引入新的方法就在相关段补引，不把参考文献堆在主页。书写作者/标题/年份，仓库引用写上实际权重、固定版本或运行报告；最新上游文档不能证明本机已升级。

DAPG 式示教不能写成完整原始 NPG；最小多峰块策略不能写成完整 ACT/CVAE 或 Diffusion Policy；检索/重置档案不能写成论文完整鲁棒化；模拟图像回放不能写成真实视觉定位。跨平台结果必须明确身体、传感器和先验权限。

## 更新时的验收

先读最新决策与当前来源，再做结构、数字、重复、编号、引用、内部路径、锚点与命令依赖检查；核对新克隆可用范围，并实际渲染主页。代码或配置改变按影响范围运行相关测试；仅文档调整不伪造一次新全仓验收。无法确认的历史外链或材料标为待核，不把链接通达当复现证据。
