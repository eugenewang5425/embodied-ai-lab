# 第九课：到达终点，不等于沿直线到达

本课沿用第八课的水平平面 2R 机械臂：40 cm + 30 cm 两根杆、两个力矩电机。只加入路径参考与 Jacobian，不增加自由度、噪声、碰撞或学习算法。

## 先看，再读公式

在项目根目录运行：

```powershell
uv run python -m embodied_learning.arm_path_demo --results results/arm_path_2026-09-02
```

默认打开第二页，暂停、0.25×。11 秒仿真按此速度约播放 44 秒；这只改变回放速度，控制步长仍为 0.02 s。

1. 选择“关节角平滑插值”，播放到仿真约 4 秒。紫色实际路径偏离灰色规定直线，但最后仍能到终点。
2. 切换“Jacobian 直线路径”（切换后回到起点并暂停），再播放到约 4 秒。观察路径和右侧“偏离线段”数值。
3. 橙圆是此刻规定的位置，橙叉是最终目标。末端即使在线上，也可能走得太快或太慢，因此还要看“时间跟踪误差”。
4. 下方蓝/橙/绿曲线分别对应只给终点、关节插值、Jacobian，使用同一纵轴。虚线预览全程，实线表示已播放部分；绿色贴近零不等于没有数据。
5. 切到第一页，先点 `0°, 0°`，再点 `90°, 0°`。两次都希望末端向世界 +X 以 2 cm/s 移动，比较绿色预测箭头和右侧读数。

支持播放/暂停、单步 +0.02 s、拖时间轴、0.1×/0.25×/0.5×/1×、回起点。空格播放，右箭头单步，Home 回起点，Esc 退出。第一页是静态几何探针，滑块直接设姿态；第二页才是真实电机力矩驱动的 MuJoCo 记录。探针不会改变已保存轨迹。

## 与已有知识的连接

第八课解决的是：给末端一个坐标，算出关节角，再由 PD 推动到达。

现在的问题类似 GIS 中“两个点之间画线”和“规定沿这条线行走”的区别：终点相同，并没有规定中途经过哪里，更没有规定何时经过。

先记住一句话：**Jacobian 告诉我们，在当前姿态下，两个关节分别转多快，会合成怎样的末端速度。**

如果已经理解正运动学 `p = f(q)`，Jacobian 就是它对关节角的局部变化率。不是新的物理定律，也不是取代电机控制的黑箱。[Modern Robotics 第五章](https://modernrobotics.northwestern.edu/nu-gm-book-resource/velocity-kinematics-and-statics/)用同样的 2R 例子解释了这一速度关系。

## 三组对照，分别在改变什么？

| 方案 | 中途的关节目标 | 时间安排 | 电机如何执行 |
| --- | --- | --- | --- |
| 只给终点 | 一开始就给最终 IK 角度 | 没有规定到达时刻 | 第八课原样的关节 PD |
| 关节角插值 | 从初始角度平滑过渡到最终角度 | 8 s 移动，3 s 停留 | 跟踪移动目标的关节 PD |
| Jacobian 路径 | 从末端直线速度逐步生成关节参考 | 同样的 8 s + 3 s | 与插值组相同的关节 PD |

所有组从 `q=(-40°,80°)`、静止开始，末端初始约 `(53.62,-6.43) cm`，终点 `(35,30) cm`，两个电机上限均为 ±0.25 N·m。KP=(12,8)，KD=(2,0.6)，物理步长 0.002 s，控制步长 0.02 s；XML 模型完全沿用第八课。

比较“关节角插值”和“Jacobian”时，时间安排、控制增益、目标速度项与力矩限制相同，主要区别是参考路径在哪个空间定义。只给终点组到达更早，不应因其没有追踪规定时间点就说原控制器不好；它承担的任务不同。

### 实际测得的结果

误差统计窗口为 0–8 s，包含两端，共 401 个真实状态样本，按时间等权。

| 方案 | 最大偏离有限线段 | 偏离线段 RMS | 同时刻位置误差 RMS | 末端停稳 | 路径验收 |
| --- | ---: | ---: | ---: | --- | --- |
| 只给终点 | 76.154 mm | 20.346 mm | 229.538 mm（非其控制目标） | 通过 | 不通过 |
| 关节角插值 | 46.241 mm | 25.956 mm | 26.398 mm | 通过 | 不通过 |
| Jacobian | 0.197 mm | 0.106 mm | 0.773 mm | 通过 | 通过 |

路径验收：完整完成 11 s，移动期最大偏离 ≤2 mm，同时满足末端停稳。停稳验收：移动结束后，直到记录末尾连续至少 0.5 s 满足末端误差 ≤2 mm、每个关节角误差 ≤0.01 rad、每个关节速度 ≤0.02 rad/s，且无物理失败。不是只检查最后一帧。

到有限线段的距离会把越过端点也计为误差；不是只算到无限延长直线的垂直距离。到同时刻规定点的距离还会计入领先或落后。

Jacobian 组电机峰值约 `(0.02514,0.01303) N·m`，550 步中没有力矩饱和；关节插值组也无饱和。只给终点组有 108 步至少一个电机达到上限。以上均为这条固定路径、当前理想模型的结果，不是硬件精度或普遍成功率。

## 公式只需要分清三层

第一层是几何：

```text
x = L1 cos(q1) + L2 cos(q1 + q2)
y = L1 sin(q1) + L2 sin(q1 + q2)

J(q) = [ -L1 sin(q1)-L2 sin(q1+q2)    -L2 sin(q1+q2) ]
       [  L1 cos(q1)+L2 cos(q1+q2)     L2 cos(q1+q2) ]

[dx/dt, dy/dt]ᵀ = J(q) [dq1/dt, dq2/dt]ᵀ
```

每一列表示只让对应关节以 1 rad/s 转动时的末端速度；单位是 m/rad。q2 仍是相对第一根杆的角度，所有末端坐标/速度都在世界 XY 系。

第二层是生成平滑参考。令 `s=t/8` 限制在 [0,1]，进度为 `h=10s³−15s⁴+6s⁵`。首尾速度、加速度为零。直线参考为 `pd=p0+h(pgoal−p0)`。

在独立的几何参考 `qr` 上，每 0.02 s 计算：

```text
v = d(pd)/dt + 4 [pd - f(qr)]
dqr/dt = J(qr)ᵀ [J(qr)J(qr)ᵀ + λ² I]⁻¹ v
qr_next = qr + 0.02 × dqr/dt
```

这里 λ=0.02 m/rad。计算中解线性方程，不显式求矩阵逆。再等比例缩放整个速度向量，使各关节参考速度不超过 1 rad/s；此案例没有触发缩放。

这叫阻尼最小二乘（DLS）：在尽量满足 `J dq = v` 的同时，惩罚过大的关节速度。它对应最小化 `||J dq−v||² + λ²||dq||²`。这里的“阻尼”是数值正则项，不是仿真关节的物理摩擦。

第三层才是实际电机控制：

```text
torque = clip(KP × wrap(qr-q_actual)
              + KD × (dqr/dt-dq_actual/dt), ±0.25 N·m)
```

MuJoCo 用力矩推进状态，不会把实际角度直接改成参考角度。Jacobian 计算使用的是 `qr`，实际状态反馈在内层关节 PD 中；本实现不是“直接测实际末端误差的任务空间伺服器”，也没有假装电机能瞬间实现给定速度。

对当前 2R，沿直线逐点做解析 IK 也能生成参考。学习 Jacobian 的意义在于理解速度、姿态和奇异性的关系，而不是声称这么简单的机械臂非用它不可。

## 为什么伸直时会遇到限制？

在 `q=(0°,0°)` 时：

```text
J = [ 0    0  ]
    [ 0.7  0.3]
```

不管如何组合两个有限关节速度，当前瞬间的 X 速度都是 0，Y 速度可以不是 0。两个关节贡献的速度方向重合了，而不是两个电机消失了。[Modern Robotics 的奇异性说明](https://modernrobotics.northwestern.edu/nu-gm-book-resource/velocity-kinematics-and-statics/)将这种可产生速度方向减少的位形称为奇异位形。

这里特意请求沿 +X 继续向外走：机械臂已经达到最大长度，因此该请求还越过了工作空间边界。即使改为向内，恰好伸直这一瞬间仍没有一阶径向速度；可以先弯曲，在后续有限运动中进入内部，不能把瞬时限制误解成永远无法改变 X。

保持 q1=0，希望 X 速度为 +2 cm/s，静态探针记录：

| q2 | 直接求逆得到的 dq2 | DLS 得到的 dq2 | DLS 预测的 X 速度 |
| --- | ---: | ---: | ---: |
| 30° | -0.220 rad/s | -0.208 rad/s | 1.895 cm/s |
| 10° | -0.667 rad/s | -0.437 rad/s | 1.313 cm/s |
| 1° | -6.684 rad/s | -0.124 rad/s | 0.0373 cm/s |
| 0.1° | -66.845 rad/s | -0.0126 rad/s | 0.00038 cm/s |
| 0° | 不可逆 | 0 | 0 |

表中只列 dq2 和预测 X 分量，完整的两关节速度、预测 Y 分量及速度残差在 summary.json。它们是运动学预测，不是电机实测速度。接近伸直时直接逆解可能要求极大的速度；DLS 稳住了数值，却也牺牲了所要求的速度。**不会数值爆炸，不等于完成任务。**

最小奇异值可以先理解为“最难运动的方向还剩多少速度转换能力”；到 0 时有方向缺失，不必这节课就掌握完整 SVD 推导。

## 理论对应（Embodied-AI-Guide）

本课在 [Embodied-AI-Guide](https://github.com/TianxingChen/Embodied-AI-Guide) 的 6.3.2 运动学与动力学里，把上一课“位置级”的 FK/IK 推进到“速度级”：Jacobian `J(q)` 是 `p=f(q)` 对关节角的局部变化率，每一列是对应关节以 1 rad/s 转动时的末端速度，单位 m/rad。49 个姿态上解析 J 与中心差分、MuJoCo `mj_jacSite` 的最大元素差分别约 `9.77e-11` 和 `2.22e-16 m/rad`——工具箱里的雅可比与本课手写的公式是同一个东西。

本课的核心证据是：参考生成方式决定路径质量。同一台机械臂、同一组 PD 增益、同一力矩上限，只改“中途给什么参考”，0–8 秒对规定线段的最大偏离分别为 76.154 mm（只给终点）、46.241 mm（关节插值）、0.197 mm（Jacobian 直线路径），同时刻位置误差 RMS 为 229.538、26.398、0.773 mm。终点相同不等于路径相同——把“经过哪里、何时经过”写进参考是运动学规划层的事，与执行层 PD 的好坏无关。

伸直姿态的数据把奇异性落到实处：`q=(0°,0°)` 时 J 的 X 行全零，可产生的速度方向少了一个。DLS 对照表显示 q2=1° 时直接逆解要求 dq2=-6.684 rad/s，阻尼最小二乘把它压到 -0.124 rad/s，代价是预测 X 速度只剩 0.0373 cm/s——“不会数值爆炸，不等于完成任务”。λ=0.02 的正则与 1 rad/s 限速是数值方法与任务需求的折中；冗余分解、奇异鲁棒逆等更系统的处理属于 6.2.3 与后续课题。

分层诊断思想同样值得带走：只给终点组 108 步有力矩饱和却到达并停稳，Jacobian 组 550 步无饱和——饱和是现象不是结论；按“参考误差/执行误差/力矩/奇异值”逐层检查，才能把问题归到正确的层。这与 Benchmarks 的指标设计原则一致：每个指标只回答它对应层的问题。

## 思考题

1. 三组 0–8 秒最大偏离 76.154/46.241/0.197 mm，电机、PD 增益、动力学完全相同。用“三组对照，分别在改变什么？”表指出：差异来自哪一列？
   提示：对比表中“中途的关节目标”一列。
2. 只给终点组的“同时刻位置误差 RMS”高达 229.538 mm，但讲义标注“非其控制目标”。若评测报告只有这一列，对这个方案公平吗？为它写一组公平的指标。
   提示：“三组对照，分别在改变什么？”一节的“它承担的任务不同”与“末端停稳：通过”一列。
3. q2=0.1° 时直接逆解要 dq2=-66.845 rad/s，DLS 只给 -0.0126 rad/s、预测 X 速度 0.00038 cm/s：两个答案分别“错”在哪里？为什么说 DLS“稳住了数值，却也牺牲了所要求的速度”？
   提示：“为什么伸直时会遇到限制？”一节的 DLS 对照表与最小奇异值一句。
4. 只给终点组有 108 步力矩饱和、Jacobian 组 550 步无饱和，但前者的末端停稳也通过了。力矩饱和能当“方案失败”的判据吗？应该去哪一层找原因？
   提示：“实际测得的结果”小节与第十课“力矩饱和只是一个现象，不是自动判定失败的规则”。
5. 直线参考的进度用 `h=10s³-15s⁴+6s⁵` 而不是线性 `h=s`：算出两种进度在 s=0 与 s=1 处的速度，说明平滑起止对“时间跟踪误差 RMS 0.773 mm”有什么贡献。
   提示：“公式只需要分清三层”一节“首尾速度、加速度为零”与 8 s 移动 + 3 s 停留的时间安排。

## 这次学习的停止点

请试着回答：关节各自平滑变化，为什么末端不一定走直线？“在线上”和“准时经过”有什么不同？伸直时数值稳定，为什么仍可能执行不了所需方向？

下一小步才是有固定种子的多目标/多路径评估：先筛查整条路径可达，再看哪些姿态和速度导致失败。不把噪声、碰撞与随机目标同时加入。只有需要冗余姿态选择时才升级 3R；当前不需要为本课引入强化学习或大型仿真平台。
