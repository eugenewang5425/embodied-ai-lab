# 导航阶段小结：从“位置估得准”走到“身体能安全完成任务”

日期：2026-09-27。范围：[专题 64](64-closed-loop-navigation.md)、[专题 65](65-map-separation.md)及[专题 66](66-campus-patrol.md)、[专题 67](67-body-aware-obstacle-avoidance.md)、[专题 68](68-scan-based-map-repair.md)，必要时回接更早的运动学、相机和配准实验。本页是阶段复盘，不占专题编号。

## 1. 这阶段真正推进了什么

最初的问题是“机器人是否知道自己在哪里”。进入街区后，问题变成了一串互相影响的环节：位置估错会把雷达点投错；图画错会误导定位与规划；规划中心能通过，车角可能过不去；不碰撞也可能一直停着；算法宣布到达，真实位置还可能差一点。

如今已有三条可复用的实验链：

```mermaid
flowchart LR
    S[雷达与米制深度] --> X[按安装外参转到车身]
    X --> B[完整身体和刹停扫掠]
    B --> L[观测记忆与重新找路]
    L --> U[运动指令]
    O[历史扫描与轮子读数] --> C[扫描约束校准运动尺度]
    C --> H[重算历史轨迹与地图]
    H --> F[冻结地图后的独立巡检]
    U --> E[实际到点 / 碰撞 / 停滞评分]
    F --> E
```

第一条是专题 66 的定位影响闭环；第二条是专题 67 的观测、机身、避障；第三条是专题 68 的历史修图。窗口已经统一接入，**算法控制链尚未将后两条合成一套完整系统**。展示在同一个窗口不代表已经完成全栈融合。

## 2. 把各课结论放回自己的实验条件

**这不是一个可以直接按成功率排名的榜单。** 机器人尺寸、传感器、路线长度、目标门限、地图来源和规划权限不同。例如 67 课定位均值为零只是有意移除定位误差，不能拿来击败 64/68 课 PF；64 课是任务集合的 12 回合，68 课是 3 轮各 8 点，两种分母也不同。

## 3. 同一类算法为什么换环境就变样

### 3.1 误差有没有足够路程积累

轮子每段只多报一点，在短房间任务中可能还没累积到影响规划；长距离加多次转角后，历史朝向错一点，就会使远处墙点横向错很多。比如 8 m 处目标，1° 朝向误差产生的横向量级约为 `8×sin(1°)=0.14 m`。

这解释了“同样 2%”不能只看百分比：第 15 课还是单侧轮模型，64/66/68 课是平移与转角公共刻度模型。须看总路程、总转角、测量更新频率和任务余量。房间到街区的差异符合这个机制，但没有同一路线长度、同观测条件的严格消融，因此仍是机制解释，不能声称已经量化各因素的独立贡献。

### 3.2 环境是否提供了能区分方向的几何

贴着一面长墙向前移动，雷达与墙的距离几乎不变。算法可以确定“离墙多远”，却不一定知道“沿墙走了多远”。封闭房间有前后墙，街角有不同朝向，信息才更完整。

专题 68 提供了直接证据：无噪声平行走廊可以在平移误差约 3.89 cm 时仍获得近零残差，而封闭房间的已知小运动可恢复到数值精度。加入 3 cm 噪声，当前退化门还会误接受走廊，说明噪声可能把数学矩阵“装成满秩”。

因此收紧专题 65 旧解释：**发散起点分散只能说明没有观察到单一固定热点，不能排除局部重复几何、可观测性不足或它们与随机采样的交互。** 已有数据仍支持“加粒子没有解决本批失稳”，不支持“已经证明完全与几何无关”。

### 3.3 障碍是不是穿过传感器的观察范围

普通箱体穿过 32 cm 的雷达扫描平面，雷达绕行有效；14 cm 路障在下面，42–57 cm 横杆在上面，同一雷达逻辑直接失效。增加地图分辨率、粒子数或控制器算力，不能补出原本没有的高度观测。

深度补了这些高度，但相机还有下方盲区。专题 67 低路障在 0.4–0.6 m 采样处当前帧没有障碍点，过去的观测可以维持判断；从未见过的障碍仍没有这份保证。未来要把“已证实自由”“已观测障碍”“未知”分开，尤其不能以没有点当作免费通行证。

### 3.4 对身体的近似是否适合通道

开阔环境中把机器人当圆通常不会改变能否通过；窄路中就可能决定任务成败。专题 67 矩形车宽 44 cm，而规划膨胀半径最终取整到 50 cm，相当于要求至少约 1 m 的通路。

同一融合算法在开阔/街区样本中完成18回合，在窄路样本中拒绝9回合。独立几何路径却保留约6.64cm间隙。这个反差直接定位到规划近似，而不是传感器没看见，也不是车身必然装不下。

开阔和街区样本成绩相同也值得记录：建筑虽增加了三维视觉复杂度，但未约束绕障通道，算法面对的决策难度几乎没变。以后环境扩展应按**通行宽度、可观测方向、遮挡、重复结构和动态变化**设计，不只增加建筑模型数量。

### 3.5 评价口径是不是覆盖了任务最后一步

专题 68 修后图种子 1 的平均误差约 12.7 cm，看起来不错，但某次到点实际距离 46.09 cm，超过 45 cm门限，最终只能记7/8。准确图种子0只错5.49cm却遇到不合法规划起点。

由此应同时看：真实到点、错误宣布、碰撞、停滞、拒绝、失败时长、有效输出覆盖、计算延迟。平均定位误差主要描述估计质量；它不能代替任务验收，也不能给早早失败的回合自动加分。

## 4. 当前能力边界

| 已有实测证据 | 仍缺的关键证据 |
| --- | --- |
| 仿真相机/LiDAR 与身体统一坐标，8类夹具、留出靶点、独立渲染深度对拍 | 真实尺寸、载荷制动、安装误差、时延测量和硬件接触 |
| 同步深度/LiDAR 可以驱动静态新障碍绕行 | 连续原始 RGB 保存、视觉定位、丢帧与未知区处理、动态清除 |
| 历史扫描可估计固定运动尺度，重建更一致的地图 | 通用位姿图、时变打滑、错误回环、地图版本更新与回退 |
| 统一窗口能展示不同方法实际运动和失败 | 67 新身体与68修后地图的完整算法集成、留出布局验证 |
| 固定批次、数据哈希、因果命令、原记录保留 | 新布局和更多传感器失效条件下的可靠泛化 |

原始输入、源码哈希和全部结果见[基准摘要](benchmarks/navigation-studies-67-68-v1.json)。17项新增针对性测试覆盖已知答案、扫描退化、记录边界和实际窗口操作；它们证明相应实现行为，不把测试条数写成算法有效性的证据。

## 5. 下一阶段按什么顺序做

以下是建议安排，尚未执行；本次完成67、68课后停在此处，不自动跨入全部后续课程。

### A. 先解决已经找到的局部机制

1. **窄路规划**：固定专题 67 观测、车身、控制器和6cm余量，只比较圆形膨胀与含朝向的多边形足印规划。既检查窄路新增到达，也回归普通箱体/低障碍/横杆，防止为通行而碰撞。
2. **到点判据**：固定专题 68 地图与PF，比较单一估计距离阈值，与位置不确定度余量、连续停留和停止速度联合判据；单独报告拒绝/超时增加的代价。保持真实45cm门限。
3. **无路恢复**：区分起点因小估计偏差落进膨胀区、真实通道被堵、定位可能错位。起点修复要有真实身体安全约束，不能随意“吸附”到另一侧穿墙。

建议准入：已知失败夹具修复，原来成功样本无新增碰撞；旧失败不得因换门限消失。每项先1个回合，再固定小批，只有机制稳定才扩展。

### B. 把局部避障与修后地图接起来

统一车身、传感器频率和观测记录后，做一个2×2消融：原图/修后图 × 旧停车/观测绕行。所有组使用相同机器人和目标；同一算法版本锁定后运行，不能让一组用55cm矩形身体、另一组用25cm圆盘然后直接比较。

输出从“定位均值”扩展为真实到点、误报到点、接触、最小间隙、无进展时间、地图切换次数、局部/全局轨迹一致性。冻结原记录，单独生成新协议。此时才回答：两项收益是否能够同时保留，是否出现全局定位修正让局部障碍跳动的问题。

### C. 补齐连续 RGB-D 和更困难的输入

从60秒短片段开始测RGB、深度、雷达、里程计同步保存的体积和处理耗时，明确采样时间、输出时间、控制可用时间。先查掉帧和外参，再引入视觉里程计。专题 67 低分辨率解析深度是几何验证入口，不能代替这一阶段完整采集。

随后按故障各开一项：相机被遮挡、深度无效、轮子短时打滑、外参小偏差、帧延迟、可移动障碍。优先观察是否能知道自己“不知道”，并安全减速/停车，而不是任何时候都输出很确定的路径。

### D. 地图长期变化与新布局

在固定尺度修图以外，再引入时变误差和多会话轨迹，接入成熟扫描/位姿图系统作外部对照。环境变化必须先分辨位置误差与真实增删，保存新旧图、证据、版本切换和回退日志。官方框架的研究入口见[地图修复规划](campus-map-repair-plan.md)，目前未完成这些成熟系统的复现。

最后用未参与阈值设计的布局验收：非对称房间、长平行走廊、有重复建筑的街区、窄门、多高度障碍、跨时段停放车辆。旧布局继续作回归，不改称盲测。只有这一层通过，才逐步讨论实采和低速实机。

## 思考题

1. 要检验“街区失败主要因为路更长”，应怎样改变路线而尽量保持几何信息不变？
2. 如果一种方法零碰撞但从不出发，它对本项目算不算有效？你会用哪两个指标同时限制它？
3. 在矩形足印规划实验中，为什么不能顺便调小余量或改相机高度？
4. 位置修正后周围点云整体跳动，应该动 `map` 与 `odom` 的关系，还是让局部控制中的墙瞬移？怎样保存证据验证？
5. 如果修后图在三轮里比准确图到点更多，怎样追加实验才能区分统计波动、规划表示和真正的算法收益？

## 阶段结论

本阶段最有价值的变化是能把失败定位到具体环节：雷达的高度盲区、身体扫掠、历史观测记忆、圆形规划近似、长期落点形变、到点判据。下一步按这些机制逐个消融，再组合验收。更多传感器、更大的场景、更低的平均误差，都需要通过真实任务结果证明它们各自带来了什么。
