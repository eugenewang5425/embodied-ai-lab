# S288 小恐龙巡检实验小结（2026-10-09）

保留原 19 个 S288、刚性尾巴与 V07 ONNX 动作策略，增加彩色相机、ToF 测距和单目深度，完成了有预布标记的园区闭环巡检仿真。**最终压力配置完成 8/8 点、99.60 m、430.18 s；新增深度在固定障碍配对试验中提前 80 ms 发出停车指令，但没有改变正常整圈轨迹、耗时或定位误差。**

## 承接什么问题

历史“盲走”仍有本体状态反馈，但缺少环境测距与巡检点确认。此次工作把已有行走能力接入“走向目标 → 看见当前标记 → 停稳并停留 → 保存 RGB → 下一个点”的任务状态机，再单独检查密集深度能否补充原 RGB＋ToF 方案。

三层证据分别报告：旧盲走/IMU 外环研究、当前 RGB＋ToF 巡检基准、当前同条件下新增深度的贡献。旧航向实验与新园区场景不同，不能换算成盲走到巡检的成功率提升，也不能把 IMU 收益归给新增深度。

橙色 ToF 点是软件把径向测距经估计外参转成光轴 Z 后投影的标记，红色矩阵是 64 测区距离显示；940 nm 测距光不会成为肉眼可见的红色激光点。密集彩色图来自实际深度模型推理，MuJoCo 深度缓冲另存为独立评分输入。

## 对照结果

| 问题与条件 | RGB＋ToF 基准/原始深度 | 最终深度确认分支 | 结论 |
| --- | --- | --- | --- |
| 整圈：种子 73、15 ms 指令延迟、10.8 V、80% 暂定扭矩边界、ToF +5% | 8/8；99.60 m；430.18 s | 同样 8/8；动作 trace 完全一致 | 深度没有提高本轮到点率、效率或定位精度 |
| 短程：种子 72、相同降额配置 | 3/3；4.181 m | 3/3；动作 trace 完全一致 | 正常短程行为保持一致 |
| 障碍：种子 83、24 cm 高障碍、ToF +11% | 1.98 s 发停车指令 | 1.90 s；停后净位移 4.84 cm、实际路径 12.47 cm；末速度 0.140 mm/s | 提前 80 ms 发出指令；指令时间不等于身体停止时间 |
| ToF 失效：种子 81 | 2.12 s 发停车指令 | 2.12 s；动作 trace 完全一致 | 深度没有解除未知停车 |
| 相机失效：种子 82 | 2.20 s 发停车指令 | 2.20 s；动作 trace 完全一致 | 深度没有解除陈旧停车 |
| 冻结画面近场 0.15–4 m：UniDepth | 同一 17 帧原始 AbsRel 82.2% | 校正后 14.5%；接受 17/19 留出帧 | 支持本数据集的尺度校正收益，不是巡检成功率 |
| 同一输入：Depth Anything V2 Hypersim Small | 同一 16 帧原始 AbsRel 87.9% | 校正后 14.6%；接受 16/19 留出帧 | UniDepth 根据开发组误差与耗时选为闭环候选 |

冻结数据共 39 帧，开发 20、留出 19，来自相同世界与轨迹。AbsRel 为每帧环境像素平均后再跨帧平均，排除机器人、天空及测距点附近区域；失败校正帧不冒充有效结果。UniDepth 留出远场 4–20 m 校正 AbsRel 仍为 44.1%，近场增益不代表所有形状和远场尺度可靠。基准和最终整圈位置误差 P95 都为 0.433 m、最大 0.684 m。

## 失败怎样改变了实现

1. **写盘拖慢结果：** 压缩输出单次约 122 ms，首轮短程 0/126 深度结果可用于控制。改为保存未压缩数组和低成本显示输出，处理最新已交付帧，并把实际处理耗时加入交付延迟。
2. **天空误判：** 初版整圈只完成 1/8，t=94.02 s 误停。加入基于估计姿态的物理地平线过滤；1,119 张冻结输出的反事实检查保留旧输入与评分。
3. **侧墙误判：** 地平线版只完成 2/8，t=113.94 s 再次误停。增加同角域 ToF 双分区及偏差不确定性确认；2,107 张冻结输出再次检查，再运行完整新闭环，最终 8/8。

整圈最终 3,898 次深度中，3,857 次接受尺度校正、41 次按未知处理；67 帧密集候选没有测量确认，248 帧排除地平线以上候选。最终没有新增误停车，仍不能据此说模型没有形状误判。旧版 0.72 s 障碍停车只属于已被替换的分支，本轮最终收益采用 1.90 s 对 1.98 s。
