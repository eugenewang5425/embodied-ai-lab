# 第69课第四轮预登记：定位误差与真实执行延迟

日期2026-09-30，起始提交496aadf。第三轮同比例制动在精确定位、立即执行下45/45余量合格，但最小外扩分离量只有5.25mm。本轮测边界，不调整控制器、不删除异常回波，不把70/71合入，也不新增课号。

## 固定条件与独立变量

沿用第三轮`coupled`控制器、先验地图、55×44cm身体、58cm高度、逐边6cm余量、传感器噪声、10Hz圆弧积分与0.2秒刹停预测预留。原八个算法源文件保持不变。

- 位置误差：估计值的世界y坐标恒加±0.5、±1、±2、±4cm，x和朝向不改。正号指地图上方，不是随车转动的左侧。它是受控恒定位置误差，不是轮径误差或漂移模型。
- 朝向误差：估计朝向恒加±0.5、±1、±2、±4度，位置不改。角度归一化到±π；正号逆时针。不是把整幅地图和目标一同旋转。
- 执行延迟：0.1、0.2、0.3、0.4秒，分别排队1–4帧。传感器无延迟，定位无偏差；队列保留请求的期望速度和制动标志，执行器到期后基于当前真实执行速度按原加速度限制响应。保护制动、到点制动和失败制动都走同一队列，不能偷偷立即停车。控制器知道当前执行速度，但不读取未来队列。
- 零扰动为共同参照。任何回合只改一个因素，不从单变量扫描推断组合误差的容限。

## 到点和终止不能偷看真值

任务端用估计位置到目标的距离进入原25cm停车圈、更新进展及判超时。真实位置只用于传感器生成、离线评分和接触终止。估计到点且执行器停稳并排空有运动意图的队列，才算宣布完成；真实停点是否在25cm圈内另外评分。若制动后估计仍在圈外，记越界；若估计完成但真实不在圈内，记误报。零扰动分支必须与第三轮完全复现，以说明该接口没有额外改好基线。

## 批次及留出纪律

开发仅窄路/普通箱体/种子0，七条件：零、y±1cm、朝向±1度、延迟0.2/0.4秒；用于检查接口和已知答案，不调控制参数。

正式冻结后：

1. 旧版桥接：三环境×三高度×原种子0/1/2的零扰动27回合，与第三轮同比例组逐数组核对（计时数组除外）。
2. 主扫描：原窄路×三高度×新种子8/9/10×21条件（零＋8个位置＋8个角度＋4个延迟）=189回合。三个种子不是九个独立种子；8/9/10此前未用于本项目窄路调参。
3. 环境参照：开阔/街区×普通箱体×种子8×六条件（零、y±4cm、朝向±4度、延迟0.4秒）=12回合。同条件对比用于解释环境间表现，只代表一个种子。
4. 0.50m负例：普通箱体×种子8×五条件（零、y±4cm、延迟0.2/0.4秒）=5回合。应原地拒绝；初始外扩足印不合法单列，不能算成行驶造成违规。

合计233回合。正式后不因结果改变等级、种子、控制或余量；保留失败。只有确认实现错误时才能另命名保存修正批次并解释。

## 评分、验收与停止点

分别统计宣布到达、真实到达、误报、实体接触、外扩余量、停稳、任务状态、实际动作、请求/执行帧、延迟期间位移、完整尾段时间与距离。安全完成要求真实到达、无接触且全程采样外扩分离量>0；不以没有碰撞替代余量验收。

独立重积分动作，逐帧验证命令队列时间、执行器加速度/同比例刹停、注入误差、末帧进入速度和队列排空；角点投影审计<=1cm车角位移采样的车身/外扩扫掠。有限采样不是连续安全证明。保存源码、协议、原始数据与哈希。

图表按有符号等级展示成功和余量，允许非单调结果；只报告“本批测试点”，不把最大成功等级插值成认证安全阈值。冻结选例为窄路普通箱体种子8；轨迹使用零扰动及对应组绝对等级最大条件，失败例另外标注选择规则。

复用窗口按五个条件组显示（y正/y负/朝向正/朝向负/延迟），一键同步相机、三维、雷达落点、真值/估计轨迹、目标和数据。曲线显示请求与实际执行并解释符号、单位和来源；零参照可在不同视图复用，统计不能重复计数。

完成233回合、受影响测试、quick、Ruff、独立审计、实际图像与Tk窗口验收、讲义/思考题/README/路线图后提交推送。本轮只报告边界，观测来源置信度与恢复另立对照。

## 正式冻结前记录

开发七例保存于`results/navigation_robustness_probe1`：零扰动到达且余量合格，与第三轮对应全部既有数组一致（计时除外）；y±1cm与朝向±1度均无路终止；延迟0.2秒无路但余量仍正，延迟0.4秒发生实体接触，接触终帧保留非零进入速度，不伪称停稳。上述结果不触发调参或缩小范围。四项已知答案测试包含队列时序、加速度、偏差符号/角度环绕、估计到点而真实未到的评分及接触终止。此后冻结两个新执行模块及八个旧算法源文件，运行登记的233回合。
