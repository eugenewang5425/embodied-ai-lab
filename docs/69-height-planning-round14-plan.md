# 第69课第十四轮：规划也必须保留障碍高度

2026-10-01。承接第十三轮独立验证失败，不覆盖原批次。

## 原因与单变量

第十三轮种子33悬空杆最终候选，22.5s判无路。重建本帧之前的观测记忆，发现相对车身坐标`(0.29349,0.23914,0.50020)m`的回波：它在2cm外扩底盘的俯视范围内，但高于底盘30cm，也在上部支架/相机的横向范围之外。真实三维停车检查仍约12.26cm间隙。起点放松使当前姿态可行，下一搜索步却立即被压平后的回波挡住，只扩展一个节点。

本轮只把规划中新观测的高度保留到部件检查：底盘、支架、相机分别按各自三维盒体与实测点核对；额外2cm仍只加在XY。未知高度的先验占据格仍当完整墙，不能因相机没看到就宣布它安全。二维图只作展示/搜索启发，不能替代三维可行性检查。物理停车、地图清除、采样、控制、延迟、速度、真实车身、接触门限、到点和超时全部沿用冻结第十三轮。

使用私有加载的第十三轮回合引擎复用完整传感器/驱动/评分生命周期，仅替换接收先验和传感器点的规划控制器。私有引擎不修改共享模块或存档源码；输入接口没有真实新障碍、离线绕行链或未来帧。原二维候选保持为配对参照。

开发只用已见0种子四类与33种子悬空杆；失败与成功均另存。本轮正式使用首次出现的37、38、39、40、41。三布局：原街区；西移宽障碍`[5.2,6.2]×[5.3,6.5]m`；北移障碍`[5.9,6.6]×[5.55,6.75]m`。两个新布局未用于开发。每布局四高度仍为0—0.14、0.42—0.56、0—1、0.75—0.89m，先验建筑、起终点相同。
