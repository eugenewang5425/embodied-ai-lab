## 1. 先分离口径，再做2×2

旧预测按0.04秒采样减速，实际命令每0.1秒更新；失败末帧直接写零而没有执行刹停。本轮不覆盖旧档，增加“旧版参照”组，控制行为沿用第二轮组合组；所有组都将失败后剩余减速真实执行并评分。参照组在旧终止帧之前的既有数组必须逐位一致（终止帧命令与新增制动尾段单列）。

主实验共同采用与10Hz执行一致的离散刹停预测，既检查立即制动，也检查继续保持0.2秒后制动的包络；车角空间采样不超过1cm。四组为：独立减速/原速度、同比例减速/原速度、独立减速/曲率限速、同比例减速/曲率限速。预测与执行使用各自同一个减速器。“共同口径修正”与“减速方式收益”通过旧版参照分别报告。

## 2. 固定变量与候选参数

55×44cm身体、6cm逐边外扩、精确里程计、雷达/深度噪声、先验地图、矩形规划、原曲线沿用、切线反馈增益、速度上限0.6m/s和1rad/s、线/角加减速度0.8m/s²和1.8rad/s²全部不变。没有真值参与控制。

同比例制动：用T=max(|v|/0.8, |ω|/1.8)，每帧速度乘max(0,1−0.1/T)，使非零的ω/v保持且两项均不超过原减速度限制；纯直行/纯转动也必须停稳。只在请求停车时启用，不能偷偷修改正常跟踪转向。

曲率限速：未来路线距离H=0.35+0.2|v|+v²/(2×0.8)米内取最大绝对曲率K，以v_cap=min(0.6,sqrt(0.04/max(K,1e−9)))设置名义线速度上界。0.04m/s²是预设教学横向加速度预算，未经实机标定；仅相应调整v×κ前馈，不改变反馈增益和横向归一速度。记录上界与实际速度，限速后未立即降到上界的过程也必须评分。

先在种子0/2存档相同触发帧、同一位姿和观测上做两种刹停的短程反事实，并检查运动解析解、加减速度和实际扫掠。开发只允许窄路/普通箱体/种子0、2；种子1作为已知搜索失败诊断，不用于调参。正式与留出结果出现后不再改参数。

## 4. 评分与停止点

分开报告到达、实体接触、外扩余量违规和完成且全程余量合格（采样门槛）。到点仍为真实距离<25cm且上一帧线速度<0.05m/s；继续刹至线/角速度均为零，若尾段滑出目标圈或接触则不算完整完成。失败触发原因、开始制动帧、制动尾段位移/时长/接触独立保留。没有找到路不是证明物理无路；负例与普通失败分开。

所有动作须对应下一帧真实位姿；最后零命令只允许出现在已经实际停稳或接触后终止的位置。碰撞后停止运动学回合而不模拟穿透。统计最小实体/外扩间隙、违规帧/回合、到达耗时和制动次数。计算时间分首次规划、后续规划、整步控制P95/P99/最大值，仍不宣称硬实时。

若仍失败，保留而不缩小安全余量。新的实时搜索预算或跟踪增益将改变独立因素，本轮只诊断、另行登记，不能混在本轮收益中。旧控制源码保持，新入口与预测/执行模块独立；用基线前缀对拍检查接口兼容。受影响完整选择集、quick、Ruff、源码哈希和实际窗口读图验收后提交推送。
