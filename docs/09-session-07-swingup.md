# 第七课：倒下以后，为什么要先摆起来，再扶稳？

## 先看结论

这次不是把 LQR 的力调大，而是把任务分成两段：**离直立很远时摆起；靠近直立且速度合适时，用已有的 LQR 扶稳并回到中心。** 推倒后可以再切回摆起。

新实验保留原来的 MuJoCo、两个自由度和一个小车电机，没有加入强化学习或大型仿真框架。摆杆铰链始终没有电机，小车移动通过动力学耦合给杆增加或减少能量。

## 这次确实改变了哪些物理条件？

| 条件 | 原平衡实验 | 新摆起实验 |
| --- | --- | --- |
| 任务 | 直立附近保持平衡 | 下方启动 / 被推倒后再次摆起 |
| 杆的关节限制 | ±90° | 无角度限位，可完整转动 |
| 角度失败条件 | 原始关节角绝对值超过 0.2 rad | 移除角度失败条件 |
| 小车轨道 | ±1 m | ±2.5 m；每步检测到 `abs(x) >= 2.4 m` 则失败 |
| 电机 | 输入 ±3，传动系数 100 | 不变，电机水平力最大 ±300 N |
| 自由度 / 驱动数 | 2 / 1 | 仍为 2 / 1 |
| 控制周期 | 0.04 s | 不变；内部物理步长 0.02 s，RK4 |

轨道扩展是为了给当前能量摆起方法留移动空间；调试时原 ±1 m 行程会发生越界。这**不是证明所有摆起方法都需要更长轨道**。新实验的正下方摆起最大位移约 1.788 m，确实用到了额外行程。

新 XML 独立保存，原模型、原 PD/LQR/随机扰动/测量噪声实验及学员的 R=1 结果不改。新旧任务边界不同，不能直接把存活时长当作同任务性能对比。

还保留非有限状态、数值警告及速度边界：`abs(v)>20 m/s` 或 `abs(omega)>40 rad/s` 会失败；默认观察 30 s 到期截断。行程检查发生在每个 0.04 s 步末，可能已经越过 2.4 m，甚至接触软关节限位，**不是严格的避碰安全保证**。没有地面、杆车碰撞或真实硬件安全系统。

## 角度先不要混淆

物理直立的参考关节角约为 `theta_ref=-0.001666665 rad`。定义 `alpha=theta-theta_ref`：

- `alpha=0°`：直立；
- `alpha=-120°`：左下方；`+120°`：右下方；
- `alpha=±180°`：正下方。

负角度不等于在下方。判断在不在下方要看 `cos(alpha)<0`，也就是杆端是否低于铰点。

## 摆起到底怎样工作？

想象用手前后移动秋千的支点：你不是直接把摆杆拧到目标角度，而是在适当时机移动小车，把能量传给它。

这里使用一个简单的能量指标：

```text
E = 0.5 * I * omega² + m*g*l*cos(alpha)
E_target = m*g*l
```

`l` 是铰点到杆质心的距离，`I` 是杆绕铰点的转动惯量。当前模型的目标能量约 14.770 J；静止下垂约 -14.770 J，需要增加约 29.539 J。这里的零势能选在质心与铰点同高的位置；不是电机耗电量，也不包含小车平动能量。

摆起模式先决定期望的小车加速度：

```text
a_des = 1.2*(E-E_target)*omega*cos(alpha) - 6*x - 3*v
```

第一项根据能量差和摆动方向决定怎样推；后两项限制小车持续漂走。`a_des` 限在 ±20 m/s²；这些有量纲系数是本教学模型的调试参数，不是通用常数。

再由 MuJoCo 中当前姿态的质量矩阵、重力和阻尼，把期望加速度换成电机力，并限制在 ±300 N。这只是两自由度动力学的计算，没有轨迹优化器。外部扰动并不提供给控制器，所以受扰动或电机饱和时，真实加速度可以偏离 `a_des`。

为什么这个方向能补能？在当前“0° 向上”的约定下，杆的能量变化包含 `-m*l*a*omega*cos(alpha)`。只看理想能量项、忽略阻尼和限幅时，上述反馈会把能量误差向零推。加入小车回中项、阻尼、限幅、采样和轨道后，不再具有任意初态都能成功的保证，必须做真实仿真验证。

恰好静止下垂时 `omega=0`，能量项也是零，所以加一个有界的小车启动加速度打破对称；这是真实施力，不是直接改角度或瞬移。

思路参考 [MIT Underactuated Robotics 的 cart-pole 能量整形与 LQR 切换](https://underactuated.mit.edu/acrobot.html)。该教材的部分公式取向下为零，我们的实现取向上为零，因此不能不改符号直接照搬。

## 什么时候交给 LQR？

进入 LQR 需要同时满足：

- `abs(alpha)<0.3 rad`（约 17.2°）；
- `abs(omega)<2 rad/s`；
- `abs(x)<0.8 m`，`abs(v)<1.5 m/s`。

LQR 使用原来的 Q 和 R=1，但在线性化新模型后设计。角度按最近的直立方向归一化，避免转过整圈后把 `2*pi` 当成巨大误差。

进入以后不会刚越过 0.3 rad 就退出；只有偏离超过 0.5 rad（约 28.6°）才返回摆起。这种不同的进入/退出阈值叫“滞回”，用于减少边界附近反复切换。

**切入 LQR 不等于已经稳定。** 稳定验收仍要求位置、角度、车速、角速度分别在 `[0.02 m, 0.01 rad, 0.02 m/s, 0.02 rad/s]` 内，并持续到记录末尾且至少 2 s。角度误差按最近一圈计算；强扰动后的恢复计时从外力结束算起。

## 这次保存的真实结果

固定模型、固定参数、每场景 30 s；这六个是经过调试的确定性教学场景，不是随机鲁棒性成功率测试。

| 场景 | 结果 | 从 t=0 起的稳定时刻 | 最大小车位移 |
| --- | --- | --- | --- |
| 正下方静止 -180° | 成功摆起并回中 | 4.76 s | 1.788 m |
| 左下方静止 -120° | 成功 | 5.52 s | 1.863 m |
| 右下方静止 +120° | 成功 | 5.52 s | 1.863 m |
| 从直立受 +400 N、持续 0.4 s | 推到下方后恢复 | 15.24 s | 1.978 m |
| 从直立受 -400 N、持续 0.4 s | 对称验证成功 | 15.24 s | 1.978 m |
| 从直立受 +600 N、持续 0.4 s | 5.44 s 触发行程失败，不重置续跑 | 未恢复 | 2.665 m（失败步末） |

正下方场景于 1.68 s 交给 LQR，4.76 s 才满足全部稳定标准。

向右 +400 N 场景的关键片段如下；力是该时刻即将执行的 0.04 s 区间的值：

| 仿真时间 | 杆的真实方向角 | 电机力 | 外力 | 控制模式 |
| --- | --- | --- | --- | --- |
| 5.00 s | 0° | 约 0 N | +400 N | LQR |
| 5.04 s | -3.5° | -300 N | +400 N | LQR |
| 5.16 s | -31.1° | -241.2 N | +400 N | 摆起 |
| 5.32 s | -92.6°，已在下方 | -93.9 N | +400 N | 摆起 |
| 5.40 s | -129.3° | -201.7 N | 0 N，扰动结束 | 摆起 |

因此不是等扰动结束才调节：10 个受推控制步中，9 步的电机力与外力方向相反。第一次受推前状态仍在平衡点，反馈没有预知扰动，下一次采样才开始反向抵抗。过程中最大方向偏离约 175.9°；11.92 s 重新进入 LQR，15.24 s 稳定，即扰动结束后约 9.84 s。

电机力与外力之和不等于所有作用在小车上的水平力；杆的耦合作用和阻尼仍在动力学中。
