# 第73课第二轮：接近路径与夹爪开口中心

## 开发阶段

固定第73课模型、0.3N·m夹爪限矩、4cm/50g方块、摩擦1.0、目标区域、21.2s阶段时长和原评分。开发用已见位置(22,1.5)/(22,5.5)cm、朝向0°。分离原关节路径与空间直线、TCP与实际开口中心两个因素；实际开度只读取当前关节状态，校准不读取未来物体运动。在线逆解不可达直接记失败，保存全部失败。

开发v3a八例：原策略1/2；空间路径、开口中心加关节位置路径、空间路径加开口中心各2/2。开口中心组也使用规定倾角插值及在线逆解，不能将它与原策略的差异全部归因于XY偏移。正式v3b固定最终候选为空间路径＋当前实际开度的开口中心补偿。接近高点保留原关节插值；从下降至撤离，世界XYZ和倾角分别按五次曲线插值，再求关节目标；高度不按两指均值补偿，避免活动指抬高导致向桌面压入。原策略按原关节请求运行，保持可逐值核对的桥接。

## 正式阶段

候选在开发后冻结。另用X={20.5,22.5,23.5}cm、Y={-2.5,3.5,7}cm与初始朝向{-15,0,+15}°，共27条件；原策略和最终候选配对54回合。中间X三Y三朝向另加空夹及偏5.5cm对照18回合，共72回合。开发案例不计入正式分母。位置和朝向只在初始化设置，之后物体运动必须来自物理推进。

## 评分与验收

保持原标准：抬升≥10cm，保持段连续≥1s、双指力>0.02N、非手指支持<0.02N；松开撤离后连续≥0.5s，XY≤2.5cm、桌上高度±3mm、速度<2cm/s、角速度<0.2rad/s、夹爪>0.9rad、双指无有效力。报告全部27条件，不删逆解拒绝或单侧接触失败。报告500Hz手指峰值与手臂其他接触，不把仿真成绩写为视觉抓取或实机表现。正式后独立逐2ms重放输入、状态、力与评分，并检查第一视角/3D/统计同步和文字布局。
