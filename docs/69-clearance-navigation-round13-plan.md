# 第69课第十三轮：停车匹配后，为择路保留误差空间

2026-10-01，承接第十二轮。用户要求稳定通过后继续机械臂。

## 开发依据和三个因素

第十二轮开发种子0箱体：物理预测避免原85.94N接触，但停在约8.4mm真实几何间隙处，后来噪声点把当前身体判占据，仍未到达。该失败另存，不覆盖第十一轮。

比较三组：原运动学预测；仅物理停车预测；物理停车预测＋择路2cm余量。第三组只在规划选路中将身体外扩2cm，保留测量/跟踪误差空间。传感器、地图更新、跟踪、安全检查实际身体、质量/力限、0.2m/s、0.2s排队与接触门限均相同。这个择路参数不是原6cm必过验收线；真实评分仍允许轻擦，不缩小身体。

2cm是开发候选：雷达测距噪声5mm、深度3mm，原反例朝向误差约2.4°会让最远角点移动约1.6cm。它是有限仿真范围的经验预算，不保证任意误差。先在固定种子0四种障碍检验，另保存每版源码和结果。

开发a版箱体无接触，但真实最小约1.8cm时，2cm择路外扩把当前起点判占据，不能退出。b版将额外择路空间在离当前起点20cm内逐渐恢复到2cm，仅在当前身体已处于偏好余量内时启用；每个姿态仍检查完整真实身体，身体实际占据观测点时仍拒绝。这个变化单独保留a版失败，解决“离墙较近就无路”的人为起点限制。

## 正式案例冻结登记

开发仅使用种子0。正式首次使用32、33、34、35、36，不含原反例0或第十一轮29—31。障碍足印分别为原街区`[5.6,6.4]×[5.4,6.6]`、东移`[6.3,7.1]×[5.45,6.55]`、偏南宽箱体`[5.7,6.9]×[5.2,6.4]`（单位m），先验建筑和起终点保持不变。每个布局分别放入低障碍0—0.14m、横杆0.42—0.56m、箱体0—1m、可穿过高横杆0.75—0.89m。地图与扫描由对应场景生成，没有把真值障碍传给控制器。

正式共87回合：原布局×四种高度×32—34种子×三组=36个配对回合；最终候选另加原布局35、36的8回合，以及两种新布局×四高度×五种子的40回合；最后另加三例0.30m宽封闭入口负例。最终候选因此有60个可达正例和3个真正不可达负例；负例不进入到达率分母。三组配对用于比较机制，额外布局只测最终候选的稳定性，不能拿其不同分母直接比较算法优劣。

离线采样绕行链在十二个布局/高度组合均有0.18m最小身体间隙，说明存在几何通路；该链仅供独立评分，不参与规划，也不保证动态控制能走完。负例入口0.30m小于车身最小宽度0.44m，只能正确拒绝，不能靠缩小车身通过。

按固定案例逐回合独立进程运行，默认正式并行3个工作进程，每个独立模型、随机流与存档。并行只减少批次等待时间，不改变模拟时间或控制队列。回合耗时记录实际墙钟，受并行竞争影响。恢复中断时必须校验源码、登记和已有存档哈希，再复用已完成回合。

## 留出门槛

三个足印/位置布局×四种高度条件×五个新种子，共60回合最终候选。全部要求真实到达、实际停稳、接触符合原40N/5mm/连续0.5s口径，零误报。可达场景无路、停车、超时仍是失败；不可达负例另列。至少原布局保留三组配对，区分停车和择路收益。

现有失败与开发种子0不计入留出成功率。若留出失败，保留整个批次，进一步改动用新的开发和验证登记，不把已见种子继续叫未见。真实几何/离线绕行链只评分，控制器只拿先验、传感器和测得速度。
