# 第二十一课：它说到了，小车真的停到目标了吗？

这一课的任务是：从已知起点出发，让车轴中心停进绿色目标区。目标区半径固定为 **3 cm**，不要求最终车头朝向，不要求整个车身装进这个小圆。

区别于上一课：轮速不再由时间表预先安排。控制器每 0.04 s 根据估计位置重新计算左右轮速，动作会改变下一步的实际位置，也会改变接下来测到的数据。这是移动小车的第一个目标点反馈闭环。

## 1. 先打开画面，认清任务

在项目目录的 PowerShell 中运行：

```powershell
uv run python -m embodied_learning.goal_demo
```

默认暂停、0.25×、近目标、样本 #0，读取 `results/goal_reaching_2026-09-03/`。这是**本次新生成的 Python 闭环运动学轨迹回放**，不是第二十课的 ROS 消息回放，不会启动实车或新的 ROS 节点。

左右是两次独立实验：

- 左侧紫色车用“纯编码器里程计”决定动作。
- 右侧橙色车用“编码器＋每 2 s 的地标校正”决定动作。
- 实色车体／点是仿真实际位置，灰色虚线／空圈是该车的估计位置。
- 绿色目标圆按真实尺寸绘制；绿色三角形是已知地标，不是障碍物。

操作顺序：

1. 点“播放”，看车根据目标方向转向、接近、减速；下方显示即将施加的左右轮速。
2. 点“看停车结果”，暂停到两组都结束，并自动放大目标附近。看实际车轴中心在不在绿色圆内。
3. 点“看停偏样本”，自动寻找当前目标中下一例纯里程计误判的样本。样本号明确显示；不是换了控制器或偷偷换误差门限。
4. 切换“远目标”，比较长距离后实际停偏的情况。两个目标都可查看全部 20 个样本。

“起点”会退出局部放大并从头暂停。两组结束时间不同时，先结束的一组只保持最后画面，不继续产生传感器数据或恢复控制。

## 2. 小车如何决定怎样走？

控制器只拿到估计位姿 `(x̂, ŷ, θ̂)` 和目标 `(xg, yg)`，不接收仿真真值。

```text
目标－估计位置
      ↓
距目标多远 ρ？目标相对车头偏向哪边 α？
      ↓
算前进速度 v 和转向速度 ω
      ↓
换成左右轮速度 → 实际运动 → 新编码器／地标读数
                                      ↓
                               更新估计，再算动作
```

基本规则：

- 若目标方向偏离车头超过 60°，先原地转向，不朝错误方向前进。
- 方向接近后，一边转向一边靠近；离目标越近，前进越慢。
- 距离使用估计值。如果估计位置错了，动作和停车判断也可能错。

计算为：

```text
ρ = sqrt((xg − x̂)² + (yg − ŷ)²)
α = wrap(atan2(yg − ŷ, xg − x̂) − θ̂)

若 |α| > 60°：v = 0
否则：v = min(0.25, 0.7ρ) × cos(α)
ω = clip(2α, −1.2, +1.2)

左轮速度 = (v − 0.15ω) / 0.05
右轮速度 = (v + 0.15ω) / 0.05
```

轮半径仍为 0.05 m，轮间距 0.30 m。若任一轮超过 6 rad/s，两轮按同一个比例缩小，保持原请求的转弯曲率。速度直接进入原来的无打滑运动学积分，没有新增力矩、电机惯性或加减速模型，因此这里的“停稳”不是刹车动力学验证。

这是有限速的简单比例反馈，不是路径规划算法；没有障碍物时直接朝目标驶去，不处理碰撞或移动目标，也不声称对任意情形都有收敛保证。

## 3. “它认为到了”和“真的通过”必须分开

**控制器宣布到达：** 估计距离不超过 2 cm，并连续尝试零轮速停车 0.4 s；期间估计离开范围会重新计算动作。宣布到达后本次任务结束，不再继续观测。最长 40 s，超时明确失败并发出终止零轮速。

**实验独立验收：** 已宣布到达，且最后 0.4 s 的实际车轴中心始终在半径 3 cm 内。真实位置只用于传感器生成和这个验收，绝不拿来触发控制器的到达条件。

所以存在三种不同结果：

- 认为到达，实际也在圈内：通过。
- 认为到达，实际停在圈外：误判到达。
- 在时限内没完成到达判断：超时。

2 cm 是控制器的估计停车门限，3 cm 是独立的任务验收范围。两者在实验前固定，不因结果不理想而放宽。没有要求每个有噪声样本都通过。

## 4. 比较时，哪些相同，哪些会不同？

固定两个目标：近目标 `(1.6, 0.8) m`，远目标 `(4.8, 1.2) m`；起点均为 `(0, 0, 0)`。每个目标 20 个种子、两种定位，共 80 回合。

两组使用同一个控制器、同一轮速限制和验收门限。沿用第十七至十九课的传感器假设：

- 右轮原读数固定多报 2%，修正系数仍由独立四段测距标定数据拟合。
- 右轮每区间再叠加标准差 0.008 rad 的零均值噪声，左轮不加噪声。
- 三个已知地标每 2 s 测距测角；标准差分别为 0.01 m 和 0.01 rad。
- 地标融合仍是先用轮子预测、观测到来时直接重置，不增加滤波器。

配对种子在相同时刻使用相同的噪声抽样；编码器与地标使用分开的随机数流，防止抽样顺序互相影响。**这不意味着读数相同或真车轨迹相同**：定位结果一旦不同，控制动作、实际运动和接下来的理想测量也会不同。这正是闭环与旧的固定轨迹回放的区别。

原来的逐区间编码器噪声在停车期间也存在。这是延续旧课的教学模型，不是对真实编码器噪声的实测描述。地标仍假设身份、地图坐标和安装参数已知，没有遮挡、量程限制或异常值模型。

## 5. 实际结果：有帮助，但没有消除停偏

2026-09-03，固定种子基数 0、每目标 20 次：

| 目标 | 定位方法 | 实际通过 | 误判到达 | 平均最终距离 |
| --- | --- | --- | --- | --- |
| 近目标 | 只靠轮子 | 16/20 | 4/20 | 2.505 cm |
| 近目标 | 轮子＋地标 | 20/20 | 0/20 | 1.146 cm |
| 远目标 | 只靠轮子 | 5/20 | 15/20 | 7.095 cm |
| 远目标 | 轮子＋地标 | 11/20 | 9/20 | 2.553 cm |

全部 80 回合都宣布到达，没有超时；但这不等于实际任务全部通过。最长回合 34.40 s，所有轮速都在 ±6 rad/s 内。

近目标样本 #0：纯里程计认为距目标 1.919 cm，实际 2.236 cm；融合认为 1.942 cm，实际 0.140 cm，两组均通过。这个单次的毫米级误差不代表硬件精度或长期能力。

远目标样本 #0：纯里程计实际停偏 9.162 cm，融合实际停偏 3.256 cm，两组都误判到达。地标噪声、观测间隔和停车决策共同限制了结果，不能把“用了地标”当作可靠到达的保证。

这些是有限样本下的模型内结果，不是总体成功率，也不是统计显著性结论。

## 理论对应（Embodied-AI-Guide）

在 [Embodied-AI-Guide](https://github.com/TianxingChen/Embodied-AI-Guide) 的地图里，本课是（4）Algorithm 篇·Robot Navigation 的前置：导航栈 = 定位 + 规划 + 控制，本课第一次把估计位姿接进控制律（estimation-driven control），让定位质量第一次被表达为任务指标——实际停在不在圈内。此前的十七至二十课都在回答"估计得怎么样"，本课回答"估计错了会怎样"。

数字给出了直接的因果证据：同一控制器、同一 2 cm 门限，只换定位方法，远目标实际通过从 5/20 升到 11/20、平均最终距离从 7.095 cm 降到 2.553 cm。反过来看，纯里程计组远目标 15/20 误判到达，正是前面各课的预告：第十九课长直行 32 s 纯里程计全程平均误差已达 3.822 cm 且随路程增长，走约 4.9 m 再刹车，停车偏差越过 3 cm 验收圈并不意外。第十七课"均值 2.52 cm、单次最差 10.16 cm"的分布，在这里变成了任务层面的失败率。

"它认为到了"与"真的通过"的分离是估计理论的核心议题：控制器只能在**估计空间**做判断（估计距离 ≤2 cm），验收必须在**真实空间**独立进行（最后 0.4 s 实际位置在 3 cm 圈内）。远目标 #0 两组都误判到达（纯里程计实际偏 9.162 cm、融合偏 3.256 cm）说明：哪怕用了绝对观测，估计误差依然存在并进入停止条件。本课的门限是常数，还没有表达"估计有多不确定"——把不确定性传播进决策，是后续概率机器人方法的动机。

控制律本身（v = min(0.25, 0.7ρ)·cos α、ω = clip(2α, ±1.2)）属于（6）Control 篇·控制理论基础（6.2.1 经典控制）的限幅比例反馈：离目标越远越快、方向偏差大时先原地转向。它没有路径规划、没有避障、也没有收敛性证明——指南 Robot Navigation 条目里的全局规划、局部避障、轨迹跟踪都建立在这个最小闭环之上。本课的诚实边界同样要记住：80 回合全部"宣布到达"不等于 80 次任务成功；2 cm/3 cm 两个门限实验前固定，不因结果不理想而放宽。

## 7. 本课只要解释清楚这件事

为什么两个控制器都显示“距目标不到 2 cm”，实际停车结果却不一样？

答案应区分：传感器读数 → 估计位置 → 控制判断 → 实际运动 → 独立验收。下一步是否增加滤波、观测确认或停止策略，要针对本课的失败原因选择一个变量；不同时升级复杂导航、打滑或新的物理引擎。

针对“为什么不把估计距离继续降到零”的问题，已增加[本课补充实验：停车门限对照](23a-session-21-stopping-tolerance.md)。只比较 2 / 1 / 0.5 cm，不改变原默认值；原 80 回合结果保留，也不新增课程阶段。
